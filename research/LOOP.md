# モデルを改善するループ

固定するのはCONCEPT、情報の境界、証拠の扱い方です。人間モデルの実装・評価実験・科学的仮説は、それぞれ独立に改訂します。実行時にLLMは不要です。調査・仮説・実装・考察にはLLMを利用します。

## 一回の手順

1. **問いを登録**: decisions/TEMPLATE.mdをコピーし、説明したい現象、根拠、仮定、旧版の問題、反証条件を書く。
2. **評価を固定**: protocol、シード、対照条件、主要指標、許容悪化量を結果を見る前にコミットする。評価器のコードもハッシュで固定する。
3. **基準版を記録**: `npm run evaluate -- --out outputs/baseline.json`。既存の基準版があれば使い、評価基準の変更時は旧モデルも新しい評価器で再評価する。
4. **変更する**: 一度に一つの仮説を実装。人間の挙動を変える場合はモデル版を上げる。学習器と評価器を同時に調整しない。
5. **比較する**: `npm run evaluate -- --baseline research/baselines/v0.2.0-core-v1.json --out outputs/candidate.json`。同じ評価器・protocol・シードでの差分だけを比較する。旧0.1.0との比較には`v0.1.0-core-v1.json`を使う。
6. **判断を残す**: 採用/保留/棄却、測定結果、悪化、限界、次の問いを記録しGitHubへ保存する。採用は自動化しない。

`npm run evaluate -- --check` は工学的基準の未達があれば終了コード1、`--baseline ... --check` は未達または許容範囲を超える悪化で1です。通常実行は未達でもレポートを保存します。形式不正・比較不能・非有限値はエラーです。

JSONと同名のMarkdownレポートを出力します。全フレームの実験履歴はoutputsに置き、Gitにはprotocolとコンパクトな基準測定値を残します。報告には各シード・各対照の値、指標の観測件数、モデルと評価器のハッシュ、初期パラメータ、版、ソース、実行環境を含みます。

## 最初の評価群

| 群 | 操作と対照 | 測るもの | 言えないこと |
| --- | --- | --- | --- |
| 警戒 | 同じ視覚入力で無害/危害/遠距離、遷移学習率0、危害後の無害期間 | 同一の近距離プローブで危険度、離隔と接近の効用差 | 相手の悪意、現実の恐怖や信頼 |
| 予測 | 全条件に同じ移動系列、途中で方向を反転。学習率0と比較 | 更新**前**の距離変化予測のMAE、反転後の誤差減少 | 自分の行動の因果効果、一般的な計画能力 |
| 身体 | 空腹/疲労/寒さを別々に高め、自律行動あり/世界への行動適用なし | 最終20ステップの要求量差、健康、死亡、行動回数 | 人間の生理の精度、対処技能の獲得 |

警戒と予測は受動的な刺激提示です。位置や痛みは実験者が指定し、本人の選択は提示系列を変えません。通常の世界の衝突則を使わず、知覚・身体フィードバック経路を切り分けます。プローブは身体条件をそろえ、遷移学習率を0にして実施します（視認回数など全記憶の凍結ではありません）。本人に安全/危険や正解のラベルを渡しません。

身体の評価は既存worldで閉ループ実行します。対照は知覚と意思決定を残し、世界へ渡す行動だけを観察に置き換えます。身体が死亡した場合は意思決定・生理更新を止め、死亡を明示します。健康・非有限値の異常で合格を出しません。

学習率0は距離予測と近接証拠の更新の対照です。音の分類・資源記憶・視認回数は止まらないので「学習を全部止めた個体」とは呼びません。

## 通常worldの評価群（world-v1）

| 操作と対照 | 測るもの | 言えないこと |
| --- | --- | --- |
| 資源配置（共有/分離）×初期距離（6u/18u）×身体要求（既定/高い）の8条件、600ステップ、二人とも同じモデル。旧版・候補・候補の寄与無効を同じシードで実行 | 接触痛の起きるステップ割合（主要、共有配置）、危険度平均、最低健康、身体要求の負担、生活技能の割合、相手を見ているときの離隔割合、距離予測の誤差、条件別の行動分布 | 近接の多寡の良し悪し、片方だけ候補の混在条件、人間の社会行動への妥当性 |

閾値は旧版だけを開発シードで測って尺度を確かめてから固定し、候補の結果は閾値固定前に見ません。分離配置は二人がほとんど出会わないため主要効果の判定から外し、副作用の対照として全項目に含めます。`npm run study:world`で実行し、[判断0004](decisions/0004-normal-world-m1.md)に初回の結果があります。

| 近距離で接触痛あり/なしの履歴を60ステップ与え、相手の記憶を保持/消去/入れ替え。危害後に強制近接96ステップ、または自由行動120ステップ（食料共有/分離） | 同じ身体・知覚のプローブでの危険度と離隔対接近の評価差、危害推定、近接での証拠増加量、自由行動中の離隔・近接・接触 | 人間の信頼・恐怖・愛着、相手側の反応の途中変化、追跡IDがない場合の再認識 |

## 評価の扱い

- 各チェックの判定は**シード平均の工学的閾値**。根拠はこのプロジェクトの要求と設計仮説で、人間データから推定した数値ではありません。合格数を人間らしさの総合点にしません。
- シードごとの対照差を単位に平均・標本SD・ブートストラップ区間を計算します。各ステップを独立サンプルとして数えません。区間はこの乱数条件でのばらつきの目安で、人間集団への信頼区間や多重検定済みの有意差ではありません。
- 開発シードと確認シードは分離します。この初回では調整せず両方を実行します。一度結果を見た確認シードは、以後は既知の回帰チェックです。新しい仮説の外部確認には、新しいシードと未使用の環境/実測データが必要です。
- 不足・NaNを0や合格へ変換しません。評価器・protocol・世界・知覚契約・乱数生成器が違う結果は比較を拒否します。世界を変える場合も、比較する両モデルを同じ世界で再実行してください。測定値が良くなるように閾値を後から動かす場合は、別protocolとして登録します。
- 比較レポートは改善/悪化/許容範囲を示します。改善があっても、他の能力の悪化、説明力、仮定の増加を検討するまで自動採用しません。

## 理論と実証

初回は工学的な検証です。研究と結びつける際は、原論文、対象（人間/動物/理論モデル）、実験課題、取得可能データ、対応させる変数、再現できない点を記録します。

参照候補: Keramati & Gutkin (2014), [Homeostatic reinforcement learning for integrating reward collection and physiological stability](https://elifesciences.org/articles/04811), DOI 10.7554/eLife.04811。恒常性と行動選択を結ぶ理論的出発点として参照しています。現モデルはこの論文の実装や再現ではなく、今回の係数・閾値・評価データの根拠にもしていません。原論文の詳細レビューと人間の行動データへの対応づけは未完了です。
