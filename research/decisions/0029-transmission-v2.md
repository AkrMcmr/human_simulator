# 0029 / 採用を割合で測る（transmission-v2）

- 状態: 第1・第2ラウンド実行済み・**採用は4群すべてで成立、5項目としては未成立（示唆に留まる）**。第2ラウンド（16シード×2群）でも確認群は5項目達成、開発群は新参者の種類依存（0.018、閾値0.03）だけを外した。2ラウンド4群で、採用率の利得は0.55 / 0.70 / 0.66 / 0.47（対照はすべて0.05以下）、在来の収束4/4、任意性3/4、新参者の副作用3/4、新参者の種類依存2/4（−0.028 / 0.072 / 0.018 / 0.064、4群平均0.03＝閾値と同じ）。新参者の理解面の指標はSD 0.13〜0.22で16シードでも分解能が足りない。ここで一度止め、次の性質へ進む。第1ラウンドの記述: 候補の採用率の利得は**0.551 / 0.699**（在来が収束したシードでは0.58〜0.91、収束しなかった開発群の2シードは定義により0）。対照はすべて0付近（生得−0.013 / 0.002、真似なし0.000 / 0.039）。何も知らない新参者の食料の声は、聞ける条件では在来の声の中に6〜9割落ち、聞けない条件では1割前後——**任意の慣習が教えなくても新参者に伝わる**ことを示す。開発群では新参者の副作用（−0.121）と種類依存（−0.028）と在来の任意性（0.080、閾値0.08にわずかに届かず）が未達。閾値は変えず、16シード×2群の第2ラウンドで再現を測る。コミットb0ff162で固定してから実行した。
- 背景: [判断0028](0028-transmission.md)で、何も知らない新参者が集団の食料の声で得をし、声の種類が役に立つことは両群で示されたが、**産出の採用**の指標（音なしの距離 − 音ありの距離）は、音なし条件で在来も新参者も声が収束せず重心が目録の平均に潰れるため、採用に対して逆向きに偏っていた。
- 変更（評価器のみ）: 採用率＝新参者の後ろ3分の1の食料の声のうち、**音あり条件の在来3人の声の重心**から0.15以内にある割合。採用率の利得＝聞ける新参者（音あり）の採用率 − 聞けない新参者（音なし条件の新参者の声を、同じ音あり条件の重心で判定）の採用率。基準を一つの実際に形成された声に固定するので、重心の潰れによる偏りがない。世界・介入・他の4項目は0028のまま。
- 候補と対照: 0028と同じ（候補`convention-contrast-0.10.0-experimental.2`。対照は生得の声＝新参者も同じ声なので採用率は両条件とも高く差は0付近、真似なし＝差0付近、既定）。
- 仮説と反証条件（閾値はパイロット後に固定。暫定: 在来の収束0.12・任意性0.08、採用率の利得0.3、新参者の副作用−0.02、新参者の種類依存0.03）:

  - H2: 生得の声と真似なしは採用率の利得が0付近。
