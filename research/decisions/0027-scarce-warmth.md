# 0027 / 暖かさを希少にした世界での2文脈の声（lexicon-v2）

- 状態: 登録（prospective）。protocol・テストをコミットし、パイロット（候補を含めない）で尺度を見て閾値を固定してから、未使用シードで測る。
- 背景: [判断0026](0026-transient-warmth.md)の診断。暖かい場所が2か所・半径3.5で見つけやすく、聞いた声の出所を訪れると何の声でも暖かい場所が見えるため、暖かさの出所評価が分類を選別できず、寒さの利益もない。食料について[判断0014〜0018](0014-referential-foraging.md)で学んだとおり、声の種類に指示対象が割り当てられるには、その対象について**知っている個体と知らない個体**が生じる世界が要る。
- 変更（課題の世界のみ。モデル・評価器の定義は0025〜0026のまま）: 暖かい場所を1か所・半径2.5にし、300ステップ周期で8か所を巡らせる。環境寒度を0.8にして、寒さが健康の閾値（0.85）に近づく——暖かさは希少で価値がある。食料は変えない。
- 候補と対照: `lexicon-0.11.0-experimental.2`（一過性の暖かさ文脈、候補）、`lexicon-0.11.0-experimental.1`（持続する文脈）、`convention-contrast-0.10.0-experimental.2`（1つの声）、`human-0.2.0`。
- 仮説と反証条件（evaluator: lexicon-v2、9項目。閾値はパイロット後に固定: 食料側の収束0.12・任意性0.08、暖かさ側の収束0.25・任意性0.08、区別0.40、特異性0.35、後ろ3分の1の空腹の種類依存0.03・寒さの種類依存0.12・空腹の副作用−0.02）:
  - H1: 候補が9項目を両群で達成すれば「経験と真似だけで、2つの文脈に別々の任意の声が集団ごとに共有され、形成後に聞き手が両方を手掛かりに使う（語彙の最小形）」と呼ぶ。
  - H2: 1つの声の対照は暖かさ側を達成しない。持続する文脈は発声量が過大で食料側が崩れる（0025の再現）。
  - H3（報告のみ）: 候補の寒さの利益（音なし − 音あり の後ろ3分の1の寒さ）が正になる——暖かさについて声が手掛かりとして働く最初の証拠になる。
  - 反証の主な筋: (a) 暖かい場所が希少すぎて誰も暖まらず、暖かさの文脈がほとんど起きない（パイロットで確認し、起きなければ周期や半径を候補の実行前に調整して記す）。(b) 暖かさの声は収束するが区別されない。(c) 収束しても寒さの利益がない。
- 開発条件・確認条件: 開発48001–48008、確認49001–49008。パイロット48101–48104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol lexicon2 --split development --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --model lexicon-0.11.0-experimental.1 --model lexicon-0.11.0-experimental.2 --out outputs/lexicon-v2-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（48101–48104、候補は含めない。[結果](../results/lexicon-v2-pilot.md) / [JSON](../results/lexicon-v2-pilot.json)）: 寒さは後ろ3分の1で0.55〜0.78と高く、暖かさは希少になった。1つの声の対照の暖かい場所での声は9〜71回と少なく、暖かさ側の帰無は区別0.22（最大0.39）・特異性0.15（最大0.20）・寒さの種類依存0.07（最大0.13）。区別と寒さの種類依存の閾値をこの帰無の最大の上（0.40・0.12）へ上げ、他は据え置いた。閾値の固定は候補の実行の前。
