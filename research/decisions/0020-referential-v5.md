# 0020 / 種類の利用を「費用の回避」で測る（referential-v5）

- 状態: 第1・第2ラウンド実行済み・**未成立（示唆に留まる）**。2ラウンド×2群＝4群で、候補の空腹の種類依存は4群すべてで閾値を越え（0.032 / 0.038 / 0.049 / 0.078）、対照は盲目1群・連動なし1群のみ。しかし空腹の副作用は候補で2群のみ達成（−0.028 / +0.066 / +0.011 / −0.035）で、4項目を同じラウンドの両群で達成したことはない（確認1・開発2で4項目達成）。4群の副作用の平均は+0.004で、真の効果が0付近の指標を8シード（SE≈0.03）で−0.02のゲートに掛けているため、判定は偶然に左右されている。事前登録どおり閾値は変えず、**第3ラウンドは1群16シード**（34001–34016 / 35001–35016）で分散を下げて再現を測る。第1ラウンドの記述: 候補は確認群で4項目すべてを達成し、開発群では空腹の副作用だけを外した（−0.028、閾値−0.02）。**空腹で測った種類依存は候補だけが両群で達成**（0.032 / 0.038）し、対照はどちらも両群では達成しない。事前登録の「両群で4項目」は満たさないので成立とは呼ばない。ゲートは変えず、未使用シードの第2ラウンド（32001–32008 / 33001–33008）で再現を測る。コミットb9bbf72で固定してから実行した。
- 背景: [判断0019](0019-referential-v4.md)の診断。4人の世界では、声を追えば誰かは食料にいるので、種類で追う相手を選んでも「到着」は早まらない。種類の利益は、食料のない声を追って群がる費用を避けることに現れた（音ありの空腹平均: 盲目0.49、候補0.39＝音なしと同じ。でたらめ特徴で候補の空腹が0.45/0.42へ悪化）。また候補の64個体すべてが食後の声の分類を正に学んでいた。
- 変更: 評価器のゲートのみ。世界・モデル・指標の定義は変えない。種類依存を**空腹の平均**（でたらめ特徴 − 音あり）で測り、到着の短縮・方向依存・空腹の副作用と組み合わせる。到着で測る種類依存は報告のみに落とす。
- 候補と対照: `eating-voice-referent-0.8.0-experimental.3`（候補）、`food-call-referent-0.8.0-experimental.3`、`eating-voice-blind-0.8.0-experimental.2`、`human-0.2.0`。
- 仮説と反証条件（evaluator: referential-v5。閾値: 到着の短縮≥0.10、方向依存≥0.10、**空腹の種類依存≥0.03**、空腹の副作用≥−0.02。閾値の根拠はprotocolの`thresholdBasis`）:
  - H1: 候補が4項目を開発・確認の両群で達成すれば「声の種類を手掛かりに追う相手を選び、食料のない声を追う費用を避ける受け手側の合図利用が成立」と呼ぶ。
  - H2: `eating-voice-blind`は空腹の副作用で未達（群がる費用）、空腹の種類依存は両群では達成しない。`food-call-referent`は空腹の種類依存が閾値未満（状態連動の声だけでは分類の境界が弱い）。
  - 反証: 候補の空腹の種類依存がどちらかの群で0.03未満。0019で観察した0.062/0.040はSD 0.05〜0.13の中の値なので、反証の可能性は十分ある。その場合は「種類の利用は示唆に留まる」と記録し、指標の分散を下げる設計（実行長、シード数）を次に検討する。
- 開発条件・確認条件: 第1ラウンド、開発30001–30008、確認31001–31008。いずれも未使用。
- 本人に渡さないもの: 条件名、音の意味、正解、介入の有無、相手の内面、食料の出現位置。
- 実行コマンド: `npm run study:referential -- --protocol v5 --split development --model human-0.2.0 --model eating-voice-blind-0.8.0-experimental.2 --model food-call-referent-0.8.0-experimental.3 --model eating-voice-referent-0.8.0-experimental.3 --out outputs/referential-v5-development.json`（確認は`--split validation`）。
- 結果ファイル・ハッシュ: [開発結果](../results/referential-v5-development.md) / [JSON](../results/referential-v5-development.json)、[確認結果](../results/referential-v5-validation.md) / [JSON](../results/referential-v5-validation.json)。ソースb9bbf72（未コミット変更なし）。第1ラウンド開発30001–30008・確認31001–31008は観察済み。
- 改善と悪化・代替説明: 候補: 到着の短縮0.545/0.559、方向依存0.585/0.582、**空腹の種類依存0.032/0.038**、空腹の副作用−0.028/+0.066。盲目: 空腹の種類依存0.081/−0.065（片群のみ）、空腹の副作用−0.120/−0.065（群がる費用、両群未達）。連動なしの出所評価: 種類依存0.014/−0.023、副作用−0.046/+0.005。既定: 種類依存0.005/0.015。H2はそのまま成り立つ。候補の音ありの空腹平均は0.420/0.358で、音なし0.393/0.424と同程度かそれ以下、でたらめ特徴0.453/0.396より低い。開発群の副作用−0.028は8シード中5シードが負で、閾値をわずかに外した。代替説明「候補が単に音を追わない」は到着の短縮0.55で否定。代替説明「でたらめ特徴で空腹が悪化するのは分類のでたらめさによる追従の増加」は、それ自体が「種類で追う相手を選んでいる」ことの裏返しであり、否定ではない。ただし種類依存のSDは0.065〜0.068で、閾値0.03との差は小さい。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録の「4項目を両群で達成」を満たさず未成立。ただし種類依存は候補だけが両群で達成し、これまでの5つの課題（v1〜v5）で初めて「声の種類の利用」が事前登録のゲートを両群で越えた。閾値を緩めることはせず、同じゲートを未使用シードの第2ラウンドで再現するかを測る。第2ラウンドで両群4項目を達成すれば成立と呼び、達成しなければ「示唆に留まる」と記録して分散を下げる設計へ移る。
- 限界と次の問い: 成立しても「聞き手が生得的に区別できる声の種類を、経験から食料と結びつけて使う」ことの確認であり、発し手が声を選んだり、音の目録が慣習として収束したりする言語の核心には届かない。全員同じモデル。食料の出現位置は固定列。次: 第3ラウンド（同じゲート、16シード×2群）。並行して、**発し手側の費用**の問い（[判断0021](0021-caller-cost.md)）: この世界で食後の声は他者を自分の食料へ呼び寄せるので、発し手にとっては費用である。声の結果を学ぶ発し手は黙るはずで、そうなら合図が安定するには発し手側の利益（安全・互恵）が世界に必要になる。
