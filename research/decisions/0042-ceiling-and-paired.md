# 0042 / 上限対照と対比較: 聞き手の寄与だけを測る（valence-v6）

- 状態: ラウンド1終了、**未成立**。候補は産出側の4項目（良い声の収束・任意性・悪い声の収束・区別）を**初めて両群で**達成したが、聞き手の寄与（対比較）は+0.5 / −0.9回で無し。上限対照の毒の利益は0.13 / 0.88回で、H1の1.0回に届かない——**この世界では完全な警戒声でも防げる毒が閾値未満**。以後は世界を変える（[判断0043](0043-mirror-by-production.md)）。
- 背景: valence-v2〜v5の5ラウンドで一貫した像がある。産出側——良い食料の声と悪い食料の声が別の音として共有される——は繰り返し成立する（v2両群、v4確認群、v5の聞かない対照0.31）。しかし聞き手側——声のおかげで毒に当たる回数が減る——は一度も出ていない。v5（[判断0041](0041-restrained-disgust.md)、開発群）では控えた嫌悪の声（36回/実行）でも音ありの毒に当たる回数は音なしより多い（3.0 vs 2.6）。原因の候補は3つ。(a) **良い声が人を食料へ集める副作用**: 1つの声の対照は音ありで毒に当たる回数が6.1（音なし2.3）。音なし対音ありの比較は、この副作用と悪い声の便益を混ぜて測っている。(b) 悪い声の機会（36回）が真似と理解の学習には少ない。(c) この世界では声で防げる毒がもともと少ない（各個体は各毒の場所で1回しか当たらず、後ろ3分の1の毒に当たる回数は3前後）。
- 設計の変更:
  1. **対比較**（`assessPaired`、protocolの`paired`）: 同じシード・同じ条件で「参照モデル − 候補モデル」の実行指標を比べる。ここでは「聞かない対照（同じ声を出すが聞いた悪い声を採餌に使わない）− 候補」の音ありの毒に当たる回数（後ろ3分の1）。産出は同じなので、差は聞き手の寄与だけ。良い声の副作用は両者に等しく乗る。これが(a)への答え。
  2. **上限対照**`valence-alarm-ceiling-0.12.0-experimental.5`（`"alarm"`）: 悪い文脈（毒・嫌悪）では必ず同じ生得の音（開き0.1・共鳴0.1）を出し、その音に近い（0.18以内）音を聞けば学習なしで出所を避ける。完全に共有され完全に理解された警戒声で、この世界で防げる毒の上限を測る。候補ではない（言語の成立とは呼ばない）。上限対照の毒の利益（音なし − 音あり）が1.0回に届かなければ、世界の側で測れないと判断する。これが(c)への答え。
  3. 候補`valence-onset-fast-0.12.0-experimental.5`（`"onset-fast"`）: experimental.4の嫌悪の声の間隔を50→10ステップに縮める（v4の毎ステップ＝900回の洪水と、v5の36回の間）。聞かない対照`valence-onset-fast-private-0.12.0-experimental.5`。これが(b)への答え。
- 課題（valence-v6）: 世界はvalence-v5と同一（テストで同一性を確認）。モデルは既定・上限対照・聞かない対照・候補。
- 閾値: v5の7項目を据え置き。対比較「聞き手の寄与」は1.0回（毒に当たる回数の尺度と同じ根拠）。成立には7項目と対比較の両方を両群で達成すること。上限対照の差（上限対照 − 候補）は報告のみ。
- 仮説と反証条件:
  - H1: 上限対照の毒の利益は1.0回以上（世界で声が毒を防げる）。届かなければ、以後のvalence課題は世界を変える（毒の場所を増やす、人数を増やす、最初の一口の費用を上げる）まで候補を測らない。
  - H2: 候補は対比較で1.0回以上（聞き手の寄与がある）。聞かない対照より毒に当たる回数が少ない。
  - H3: 候補の悪い声の発話は実行あたり100〜200回で、餓死は起きず、良い声の収束は0.15前後に戻る。
  - 反証の主な筋: (a) 上限対照でも1.0回未満→世界の限界。(b) 上限対照は達成するが候補は対比較で0付近→理解の学習（自分の悪い声の分類）が間に合わない。(c) 候補の嫌悪の声が再び採餌を押しのけ、空腹の副作用が悪化。
- 開発条件・確認条件: 開発80001–80008、確認81001–81008。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence6 --split development --model human-0.2.0 --model valence-alarm-ceiling-0.12.0-experimental.5 --model valence-onset-fast-private-0.12.0-experimental.5 --model valence-onset-fast-0.12.0-experimental.5 --out outputs/valence-v6-development.json`（確認は`--split validation`）。

  - 産出側: 候補は良い声と悪い声の両方が収束し（0.14 / 0.13）、区別0.41 / 0.33（16シードすべて0.23以上）。**「2つの価値を持つ声が集団ごとに別々に共有される」産出の4項目を両群で達成したのはvalence系で初めて**。嫌悪の声は実行あたり68 / 86回（上限対照の生得の警戒声は0.00の収束——音なしでも同じ音に決まっているため、定義上0）。
  - 聞き手側: 対比較は+0.5（8シード中5で正）と−0.9（1シードで−5）。候補の音ありの毒に当たる回数は音なしより多い（3.6 / 4.4 vs 2.5 / 3.0）。空腹の副作用は−0.08 / −0.12で、聞いた声で場所を避ける費用（誤警報）が出ている。
  - **上限対照**: 生得の固定した警戒声と生得の理解でも、毒に当たる回数の利益は0.13 / 0.88回（実行全体では5.4 vs 6.8、4.5 vs 7.0で2〜4割減）。後ろ3分の1で1.0回という閾値は、完全な警告でも届かない。H1は開発群で反証: この世界（4人・毒3つに1つ・500ステップで腐る・味覚嫌悪で各個体は各毒の場所で1回しか当たらない）では、声で防げる毒の総量が小さすぎて聞き手の寄与を測れない。上限対照のでたらめ特徴の条件では8実行中7〜8件が死亡——でたらめな音が警戒声の形に当たると無毒の食料も避けて餓死する（誤警報の費用の極端な形）。
  - 診断（毒当たりの種類、開発シードで追加実行、`research/results/valence-v6-diagnostic-development.{json,md}`。観察済みシードの再利用で、ゲートには使わない）: 8シードの合計で、上限対照の音ありの毒当たり43件は「その場所で最初」22件、「警告なし」2件、**「警告を聞いた後」19件**。候補は56件のうち最初20件、**警告後36件**。世界に余地がないのではなく、**警告が届いた後に食べている**。さらに4シードを個体の状態まで追うと（scratch）、上限対照の警告後7件はすべて「嫌悪の記憶はあるが空腹0.95以上の非常時上書きで食べた」、候補の警告後12件は9件が「嫌悪の記憶ができていない（自分の悪い声の分類が無いか一致しない）」、3件が非常時。非常時（空腹0.95以上）は全個体・全時刻の11〜15%に達する。結論: 上限対照を抑えているのは**飢え**、候補を抑えているのは**理解の不成立**。H1の「世界の限界」は情報の限界ではなく食料の限界で、世界の食料の量を増やして再測定する（[判断0043](0043-mirror-by-production.md)）。
- 採否と判断者・理由: 未成立（Claude）。産出側の成立は記録に残し、聞き手側は世界の限界により判定不能とする。事前の取り決めどおり、以後のvalence課題は世界を変えてから候補を測る（[判断0043](0043-mirror-by-production.md)）。対比較と上限対照は評価器の標準装備として残す。
- 限界と次の問い: 上限対照は生得の警戒声で、任意性も学習もない。対比較は同じシードでも乱数の系列がモデルごとに分岐するので、差にはシード内の揺れが乗る。4人・同じモデル。組み合わせ（文法）はない。
