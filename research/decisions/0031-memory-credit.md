# 0031 / 出所の評価に場所記憶を使う（lexicon-v2 第2ラウンド）

- 状態: 実行済み・反証（revise）。場所記憶による出所評価と持続する学習文脈を足しても、暖かさ側は収束0.129 / 0.129（閾値0.25）、特異性0.175 / 0.193（0.35）、区別0.169 / 0.158（0.40）で未達。食料側は収束0.125 / 0.123・任意性0.090 / 0.106と保たれ、寒さの利益は0.053 / 0.056とわずかに正だがゲートではない。事前登録の反証条項に従い、**2文脈（語彙）の系統は本セッションで打ち切る**（0025〜0027・0031で4ラウンド連続未成立）。コミット8ce93f2で固定してから実行した（実行時の未コミット変更はdocs/digest/index.htmlのみで、モデル・評価器のハッシュには影響しない）。
- 背景: [判断0027](0027-scarce-warmth.md)の診断。(1) 暖かい場所は300ステップで消えるため、聞いてから出所を訪れるまでに消えていることが多く、暖かさの出所評価が負に偏る。(2) 一過性の文脈は音の場を守るが、温まりつつある時間が短く「暖まっている時に聞いた声」の標本が足りない。持続する文脈は学習に有利だが発声が過大で食料側を崩す。
- 候補`lexicon-0.11.0-experimental.3`（0.11.0-experimental.2に3つの変更）:
  1. 聞いた声の出所を訪れたとき、その場に**今見えている**食料・暖かさだけでなく、**自分の場所記憶**（300ステップ以内に見た、残量>0.01の食料・暖かい場所）が出所の3u以内にあれば、それを見たものとして評価する。消えた暖かい場所も、最近そこにあったなら暖かさの証拠になる。人間の判断が使える情報は本人の記憶だけで、世界の状態は覗かない。
  2. 暖まっている時に聞いた声は、体が温まった後も（暖かい場所にいる間は）暖かさの文脈として数える（学習は持続）。
  3. 暖まった直後の呼び声と暖かさの声の産出は、体がまだ寒いうちだけ（産出は一過性。0.11.0-experimental.2と同じ）。学習と産出を分けることで、標本を増やしつつ音の場を埋めない。
- 対照: `lexicon-0.11.0-experimental.2`（一過性、記憶なし）、`convention-contrast-0.10.0-experimental.2`（1つの声）、`human-0.2.0`。
- 仮説と反証条件（evaluator: lexicon-v2、9項目、閾値不変: 食料側の収束0.12・任意性0.08、暖かさ側の収束0.25・任意性0.08、区別0.40、特異性0.35、後ろ3分の1の空腹の種類依存0.03・寒さの種類依存0.12・空腹の副作用−0.02）:

  - H2: 暖かさの出所評価が正に付く分類が増え（報告のみ、事後診断）、暖かさ側の収束と特異性が0.11.0-experimental.2より上がる。
