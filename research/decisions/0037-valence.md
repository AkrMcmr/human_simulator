# 0037 / 良い食料の声と悪い食料の声（valence-v1）

- 状態: ラウンド1終了、**未成立**（両群で7項目中4項目）。良い声と悪い声は両群で対照より明確に分かれたが、聞き手の毒の利益は後ろ3分の1で0付近。診断は世界設計の副作用（下記）。次は食料が腐って消える世界0.6.0で同じ候補を測る（[判断0038](0038-valence-rot.md)）。
- 背景: 2文脈（食料・暖かさ）の系統は7ラウンド（[判断0025](0025-lexicon.md)〜[0036](0036-fine-hearing.md)）で「機能する第2の声」に至らなかった。文脈が身体状態（食べている・暖まっている）で分かれる設計では、暖かさ側の真似の元・出所評価・聞き手の必要のどれかが常に弱かった。ここでは**同じ「食べる」文脈の中で結果が正反対になる**指示対象を世界に置く: 見た目は同じで食べると健康を失う毒の食料。良い食料の声は成立済みの機構（[判断0024](0024-convention-v2.md)）で共有されるはずで、問いは「悪い食料の声」が別の音として共有され、聞き手が毒を避けるかに絞られる。機能の圧力は痛み（健康の喪失）の回避で、見た目では分からないので声にしか頼れない——情報の非対称がもっとも強い設計。
- 世界の変更（契約0.3.0: `PhysicalEffect.poison`を任意項目に追加。世界0.5.0: 食料に`toxic`、出現列に`toxicEvery`。既定の挙動は不変で、毒のない世界では`poison`は付かない）。人間の身体: 毒の摂取は健康を摂取量×0.15だけ減らす（量2.0の毒を一人で食べ切ると健康−0.3。空腹は普通に満たされる）。既定モデルは毒を学ばない。
- 候補`valence-0.12.0-experimental.1`（`packages/human/src/valence.ts`）: 文脈は「良い」（毒なしの摂取直後）と「悪い」（毒の摂取直後）。聞いた声の出所を覚え、その3u以内で**食べたとき**の結果（毒か否か）で分類を良い／悪いに評価する（見ても分からないので、食べた結果だけが証拠）。良い文脈では良い声を、悪い文脈では悪い声を真似、互いに0.3以上離し（[判断0033](0033-explicit-separation.md)の分離）、どちらでもない時は両方を避ける。聞き手: 空腹で食料を知らなければ、悪い推定が0.3を超える分類の声は追わず、良い推定が最良の声を追う。悪い声（悪い推定>0.3）が聞こえたら、その出所の3u以内にある食料の記憶を消す。自分が毒を食べた場所も記憶から消す。状態連動0.2。
- 対照: `convention-contrast-0.10.0-experimental.2`（良い声だけ。毒を学ばないので、方向だけでどこまで毒を避けられるかの帰無）、`human-0.2.0`（毒を避けられない）。
- 課題（valence-v1）: referential-v5の世界（4人・食料3か所が移り変わる）で、初期の食料の1つと、現れる食料の2つに1つを毒にする。空腹の指標は後ろ3分の1。
- 評価器の追加: 毒の摂取量（全体・後ろ3分の1）、悪い食料の声（毒の摂食直後の声）の散らばりと重心、良い声と悪い声の重心間の距離、毒の利益＝（音なし − 音あり）/音なし、毒の種類依存＝（でたらめ特徴 − 音あり）/音なし（いずれも後ろ3分の1）。良い食料の声は毒でない摂食直後の声に限る（毒のない世界では従来と同じ）。
- 仮説と反証条件（閾値はパイロット後に固定。暫定: 良い声の収束0.12・任意性0.08、悪い声の収束0.12、良い声と悪い声の区別0.25、毒の利益0.2、毒の種類依存0.1、空腹の副作用−0.02）:
  - H1: 候補が7項目を両群で達成すれば「経験と真似だけで、良い食料の声と悪い食料の声が集団ごとに別々に共有され、形成後に聞き手が毒を避ける（2つの価値を持つ語彙の最小形）」と呼ぶ。
  - H2: 1つの声の対照は良い声の収束・任意性を達成するが、悪い声の収束・区別・毒の利益は達成しない（毒の食料も「良い声」で呼んでしまう）。既定は毒の利益0。
  - 反証の主な筋: (a) 毒の摂食が少なすぎて悪い文脈が起きない（パイロットで確認）。(b) 悪い声は出るが収束しない（毒の場所は尽きるまで短い）。(c) 収束しても聞き手が使えない（毒の利益0付近）。
- 開発条件・確認条件: 開発70001–70008、確認71001–71008。パイロット70101–70104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol valence --split development --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --model valence-0.12.0-experimental.1 --out outputs/valence-v1-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（70101–70104、既定と1つの声の候補、`research/results/valence-v1-pilot.{json,md}`）: (1) 毒の摂食は起きる——音なしで全体7.5–12単位、後ろ3分の1で3.1–6.0単位。反証の筋(a)は成立しない。(2) 1つの声の候補は良い声の収束0.17・任意性0.10を達成し、「悪い声の収束」も0.14を示す。同じ声を毒の摂食直後にも出すためで、この項目は単独では区別の証拠にならない。区別（重心間距離）は0.065（最大0.16）で、良い声と悪い声を分ける決定的な項目は区別0.25。(3) 1つの声の候補の毒の利益は−0.23、毒の種類依存は−0.33。方向だけの声は毒の場所へも人を集める（H2の予測どおり）。既定は毒の利益0.03・種類依存0.00。(4) 既定の空腹の副作用は−0.11（音があると悪化）、1つの声の候補は+0.06。(5) 健康が0に達する実行がある（毒の食料4を一人で食べ切ると健康−0.6）。死亡は毒の摂食を止めるので、毒の利益を過小に見せうる。閾値: 暫定の7項目はすべて帰無の分布の上にあり、そのまま確定した（protocolの`thresholdBasis`）。

  - 区別: 候補は開発8シード中7シードが0.26以上（1シード0.04）、確認は8シード全部が0.11以上・6シードが0.20以上。1つの声の対照は最大0.26（開発1シード）を除き0.1未満。**同じ「食べる」文脈の中で、結果の良し悪しに応じた2つの声が集団ごとに分かれて共有された**のは本プロジェクトで初めて（暖かさの系統7ラウンドでは到達しなかった）。ただし確認群の平均0.213は事前の閾値0.25を下回り、成立とは呼ばない。
  - 毒の利益: 後ろ3分の1では両群とも0付近。しかし実行全体の毒の摂食は音ありで減っている（開発 5.67 vs 音なし9.41、確認 7.25 vs 9.80）。分けて見ると、**前3分の2の毒の摂食は開発4.92→1.33、確認5.12→2.60と半分以下**に減り（音なし比）、開発8シード中4・確認8シード中2では前3分の2の毒がゼロ。後ろ3分の1は4.33 vs 4.50、4.64 vs 4.68で減らない。既定の毒の利益0.265（開発）は死亡（音あり2件）で摂食が止まった偶然で、確認では0.010。
  - 診断（結果を見てからの解釈で、事前の反証の筋(c)とは別）: 世界0.5.0では食料の出現は「尽きたとき」にしか起きない。集団が毒の食料を避けると、その場所は尽きずに残り、3枠の生きた食料が毒で埋まっていく。前3分の2で毒を避けた集団は、後ろ3分の1で毒しか食べるものがなくなり、空腹で食べる。毒の回避が世界の側で罰される設計で、後ろ3分の1の毒の利益はこの世界では測れない。これは候補の欠陥ではなく評価環境の欠陥として扱う（事前の窓を後から全体に変えて成立と呼ぶことはしない）。
- 採否と判断者・理由: 未成立（Claude、所有者の方針「言語が生まれるまで改善を続ける」の下で）。ゲートは緩めない。候補`valence-0.12.0-experimental.1`はそのまま、世界を「食料は一定時間で腐って消え、次の場所に現れる」（世界0.6.0、`foodSpawn.lifetime`）に変えた第2ラウンドを新しいシードで事前登録する（[判断0038](0038-valence-rot.md)）。
- 限界と次の問い: 毒の帰属は「その場で食べて分かる」に限り、見ただけの判別はない。4人・同じモデル。組み合わせ（文法）はない。区別0.25の閾値はパイロットの帰無（最大0.16）から置いたもので、候補の確認群0.213は帰無より明確に上だが閾値には届かず、区別の大きさは聴覚分類の幅0.18と分離幅0.3の間に落ちる。毒の利益は死亡（健康0）で摂食が止まると過小・過大どちらにも振れる。
