# 0040 / 嫌悪の声: 毒の場所を見たときに出す悪い声（valence-v4）

- 状態: ラウンド1終了、**未成立**（候補は開発群で7項目中2項目、確認群で6項目）。嫌悪の声は機会を取り戻し、確認群では良い声・悪い声・区別・毒に当たる量の減少まで揃ったが、開発群では声の洪水と餓死で破綻した。次は控えた嫌悪の声と毒3つに1つの世界（[判断0041](0041-restrained-disgust.md)）。
- 背景: valence-v3（[判断0039](0039-taste-aversion.md)、開発群）で味覚嫌悪は毒の摂食を全条件で約75%減らした（音なしでも11.6→2.2単位）。個体学習が強く、毒に当たる機会は実行あたり185ステップ→8〜14ステップに減った。**悪い声は「毒に当たっている間」にしか出ない設計なので、機会が消えて悪い声は形成されない**（悪い声の収束0.03、区別0.138、8シード中4シードで後ろ3分の1の悪い声がゼロ）。さらに毒の利益の比率尺度は分母（音なしの後ろ3分の1≈1.0単位、下限0.05）が小さく、シードごとの値が−60などに振れて使えない。動物の警戒声は噛まれた時ではなく危険を**見た**時に出る。ここでも悪い声の機会を「毒の場所の食料を見て嫌悪する」状態に広げる。
- 候補`valence-disgust-0.12.0-experimental.3`（`packages/human/src/valence.ts`、`decideValence(..., "disgust")`）: experimental.2（味覚嫌悪）に次を加える。(1) 嫌悪の場所（600ステップ以内）の3u以内に食料が見えていると「嫌悪」状態（`lastDisgust`）になる。嫌悪は声の文脈として「毒に当たった」と同じ悪い文脈（悪い声の真似、聞いた声を悪い文脈で覚える）で、食料の声と同じ大きさの発声の衝動（`callUrge`）を与える。食事の結果としては数えない（覚えた音の出所の良し悪しの評価は食べた結果だけで行う）。(2) 理解は産出を映す: 聞いた音が、自分が悪い声として真似る分類と同じで良い声の分類ではないなら、その出所を嫌悪の場所として覚える（experimental.2の「学習した悪い推定>0.3」の規則も残す）。ただし自分が良い声として真似る分類の音はどちらの規則でも警告と扱わない——valence-v3で味覚嫌悪モデルの良い声の収束まで崩れた（0.145 / 0.040）のは、悪い推定が良い声の分類に漏れて良い声を聞いた場所も避けたためと疑われる（[判断0039](0039-taste-aversion.md)）。産出と理解が同じ表象（良い／悪い→声の対応）を共有する。
- 対照`valence-disgust-private-0.12.0-experimental.3`（`"disgust-private"`）: 嫌悪の声は同じように出すが、聞いた悪い声を採餌に使わない（出所を避けない、悪い分類の声を追わないこともしない）。候補との差が「聞き手の悪い声の利用」。既定・1つの声・味覚嫌悪（experimental.2）も同じシードで走らせる（experimental.1はv2/v3で測定済みのため外す）。
- 評価器の変更（`research/studies/referential-v1.ts`）: 悪い食料の声＝毒の摂食直後**または**その判断でlastDisgust>0の声（他モデルはlastDisgustが未定義なので値は不変）。毒の利益（単位）＝音なし − 音あり の後ろ3分の1の毒の摂食量（食料単位）、毒の種類依存（単位）＝でたらめ特徴 − 音あり。比率の2尺度は報告のみに下げる。
- 課題（valence-v4）: 世界はvalence-v2/v3と同一（テストで同一性を確認）。
- 閾値（候補を走らせる前に固定）: 良い声の収束0.12・任意性0.08・悪い声の収束0.12・区別0.25・空腹の副作用−0.02はvalence-v1から据え置き。毒の利益（単位）0.3: v3開発群の味覚嫌悪モデルの音なし後ろ3分の1≈1.0単位の約3割、1口0.04単位×7〜8口。毒の種類依存（単位）0.15。私的（聞かない）対照が毒の利益（単位）を達成した場合は成立と呼ばない。
- 仮説と反証条件:
  - H1: 候補は7項目を両群で達成する。嫌悪の声で悪い声の機会が戻り（悪い声の発話が実行あたり数十回以上）、悪い声が収束し、聞いた悪い声で出所を避けるので毒が減る。
  - H2: 聞かない対照は悪い声の収束・区別を達成する（産出は同じ）が、毒の利益（単位）は0.3未満。味覚嫌悪（experimental.2）は悪い声の収束・区別を達成しない（v3と同じ）。
  - 反証の主な筋: (a) 嫌悪の声が出ても収束しない（嫌悪状態の個体どうしが同じ場所にいる機会が少なく、真似の元がない）。(b) 収束しても毒の利益（単位）が0.3未満なら、味覚嫌悪の後に残る毒（各個体の各毒の場所での最初の一口）は声で防ぎきれない。(c) 空腹の副作用が−0.02を下回るなら、誤警報（良い声と悪い声の分類が重なる）で無毒の食料も避けている。
- 開発条件・確認条件: 開発76001–76008、確認77001–77008。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence4 --split development --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --model valence-aversion-0.12.0-experimental.2 --model valence-disgust-private-0.12.0-experimental.3 --model valence-disgust-0.12.0-experimental.3 --out outputs/valence-v4-development.json`（確認は`--split validation`）。

  - 嫌悪の声は機会を取り戻した: 悪い声の発話は実行あたり音ありで914 / 729回（味覚嫌悪は15 / 10、音なしの嫌悪モデルは240 / 247）。**多すぎた**。嫌悪の場所の食料が見えている間は毎ステップ発声の衝動があり、食料の声は147 / 212回に減り（他モデル200〜260）、後ろ3分の1の空腹は開発で0.83（音なし0.61）、死亡は開発の音ありで8実行中5件、でたらめ特徴では8件・7件。
  - 開発群と確認群の食い違い: 確認群では候補が7項目中6項目（毒の種類依存（単位）−0.025だけ未達）、開発群では2項目。差の中心は良い声の収束（−0.281 vs 0.165）で、開発群の3シードで音ありの良い声の散らばりが音なしより0.7以上大きい（餓死した実行で声がばらける）。餓死の有無で結果が反転しており、判定に耐えない。
  - 聞かない対照は両群で悪い声の収束と区別を達成した（嫌悪の声の産出だけで2つの声は分かれる）が、良い声の収束は落ち、毒の利益（単位）は0.19 / −0.87。候補との差（確認群で0.455 vs 0.190）は聞き手の利用の兆しだが、既定モデルでも1.095が偶然に出る尺度（1か所を食べ尽くすと4単位、1口0.04単位）で、証拠としては弱い。
  - 味覚嫌悪の集団は音なしでも空腹0.61〜0.73・死亡1〜2件、でたらめ特徴で3〜6件。**食料の半分が毒の世界は、毒を避ける集団には過酷すぎる**（v3でも同じ）。
  - 良い声の分類を警告にしない保護は、確認群で良い声の収束を戻した（0.165。v3の味覚嫌悪は0.04）が、開発群の餓死は防げなかった。
- 採否と判断者・理由: 未成立（Claude）。閾値は緩めない。確認群の6項目は記録に残すが、開発群の破綻と餓死による反転から、成立の根拠にはしない。次は (1) 嫌悪の声を自分が毒に当たった場所に限り50ステップに1回に抑え、(2) 毒を3つに1つに減らして餓死をなくし、(3) 毒の尺度を「毒に当たる回数（個体×毒の場所）」に変える（[判断0041](0041-restrained-disgust.md)）。
- 限界と次の問い: 嫌悪は場所に結びつく。「自分の悪い声と同じ分類」の理解は、聴覚分類の幅0.18の中で良い声と悪い声が重なると誤警報になる。4人・同じモデル。組み合わせ（文法）はない。
