# 0011 / 自由worldでの最小合図の診断（signal-world-v1）

- 状態: 実行済み。既定0.2.0・受信側候補ともに開発・確認の両群で合図は未成立（予測どおり）。protocol・研究コード・閾値をコミット1e02e15で固定してから実行した。発し手候補（[判断0012](0012-signal-sender.md)）も同じ実行で測った。
- 目的: [中期目標M3](../../docs/MIDTERM_GOALS.md)の「聞き手の反応が音への介入で変わる」「発し手が予測する反応に応じて発声を変える」「その関係が未使用試行でも維持される」を、二人が自由に動く通常worldで別々に測る。[判断0008](0008-signal-readiness-m3.md)と[0010](0010-sound-association.md)の制御課題の続き。
- 根拠: 工学的仮説。音に意味・正解・成功ラベルを与えない。
- 測り方: 資源共有・初期距離6u・900ステップ、二人とも同じモデル。聞き手側は、音源を視認して聞いた音ごとに（音の特徴を実験者側の3×3区分に置いたラベル, 聞き手のその判断での行動: 接近/離隔/その他）の対を集め、相互情報量から区分ラベルを200回並べ替えた平均を引いた超過量を求める。発し手側は（音を出した時の相手との距離区分 near/mid/far, 出した音の区分）で同じ計算。対照は音なし（伝達だけを止める）と、聞こえる音の特徴を毎回でたらめな値に置き換える介入（頻度と音量は保つ）。
- 仮説と反証条件:
  - 聞き手（listener-association）: 音ありの超過量がでたらめ音より0.03 bit以上大きい。聞き手の行動が音の種類に依存することを意味する。
  - 聞き手・維持（listener-holdout）: 600ステップ以降の窓でも同じ差が0.03以上。
  - 発し手（speaker-selection）: 距離区分と出す音の区分の超過量が0.03以上。
  - 副作用（need-side-effect）: 音があることで身体要求の負担が0.02以上増えない。
  - 4項目を開発・確認の両群で達成したときだけ「声を手掛かりにした距離調整の最小合図が成立」と呼ぶ。分類数や発声回数は数えない。
- 予測: 既定0.2.0は発し手が音を一様に選ぶため発し手項目は未達、聞き手も音の新奇性への反応は種類に依存しないため未達と予測する。受信側候補は制御課題では対応を学んだが、自由worldでは分類が最大16個に分かれて種類ごとの経験が少なく、聞き手項目の達成は不確実。両モデルとも「未成立」の記録になる見込みで、それが発し手候補の比較基準になる。
- 閾値の決め方: パイロット14101–14104で既定と受信側候補を測り、超過相互情報量が両者とも±0.03以内の雑音であることを確認して0.03に固定した。パイロットはゲートに使わない。
- 開発条件・確認条件: 開発14001–14008、確認15001–15008。いずれも未使用。
- 本人に渡さないもの: 条件名、音の意味、介入の有無。
- 結果ファイル・ハッシュ: [開発結果](../results/signal-world-v1-development.md) / [JSON](../results/signal-world-v1-development.json)、[確認結果](../results/signal-world-v1-validation.md) / [JSON](../results/signal-world-v1-validation.json)。ソース1e02e15（未コミット変更なし）。ハッシュは各Markdownの冒頭。
- 改善と悪化・代替説明: 聞き手の超過相互情報量（音あり−でたらめ音）は既定で−0.007/−0.014、受信側候補で−0.008/−0.011（開発/確認、閾値0.03）。後半窓も同様。発し手は既定−0.001/0.007、受信側候補−0.000/0.005。副作用はなし。一人あたりの発声は900ステップで約100回、聞いた回数は約100回。受信側候補は自由worldでは相手の音を4〜10の分類に分け、経験4件以上の分類は2〜5個にとどまる。代替説明「並べ替え基準が不適切」は、完全依存の人工データでlog2(3)bitを返し独立データで0を返すテストで否定した。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録した規則に従い、既定モデルと受信側候補について「自由worldでは声を手掛かりにした距離調整の最小合図は未成立」と記録する。確認できた段階は、音の分類、新奇音への注意、制御課題での音と結果の関連学習・利用（[0008](0008-signal-readiness-m3.md)、[0010](0010-sound-association.md)）まで。閾値・課題は変えない。
- 限界と次の問い: 相互情報量は相関の強さで、意図や理解ではない。3×3区分は実験者側の便宜で、個体の分類とは別。二人とも同じモデルの条件のみ。
