# 0004 / 通常worldで予測政策候補の効果と副作用を測る（M1）

- 状態: 通常worldで支持（開発・確認とも全ゲート達成）。既定化はレビュー待ち。protocol・研究コード・閾値をコミット24eb0d1で固定してから実行した。
- 旧モデルとソース: human 0.1.0（`human-0.1.0`）。候補は`predictive-0.2.0-experimental.1`、寄与無効は`predictive-ablated-0.2.0-experimental.1`。三つとも`packages/simulation/src/models.ts`の登録簿から名前で選ぶ。
- 根拠: 工学的仮説。[0003](0003-prediction-to-policy.md)の制御課題では距離を実験者が操作しており、二人が内生的に動く通常worldでの効果と副作用は未確認だった。[中期目標M1](../../docs/MIDTERM_GOALS.md)の必達条件に従う。
- 仮説と反証条件: 候補は、学習した行動別の距離変化から危険度の低下を見積もって効用に加えるため、資源を共有する配置では接触痛が起きるステップの割合を旧版より減らす。減らなければ「通常worldで機構が働かない、または働いても接触を減らさない」として反証する。副作用として、知覚危険度・最低健康・身体要求の累積負担・生活技能の割合・相手を見ているときの離隔割合・距離予測の誤差が許容幅を超えて悪化しないことを要求する。
- 変更するもの・追加する仮定: 人間モデルの計算は変えない。simulationに明示的なモデル選択（`ExperimentConfig.model`）と版記録を追加し、記録と再開で候補を既定版と誤読しないようにした。通常worldの比較研究`research/studies/world-v1.ts`と`npm run study:world`を追加した。
- 固定するprotocolと評価器: [`research/protocols/world-v1.json`](../protocols/world-v1.json)。資源配置（shared/separate）×初期距離（6u/18u）×身体要求（既定/高い）の8条件、600ステップ、二人とも同じモデル。評価器のハッシュは結果JSONに記録する。
- 閾値の決め方: 旧版だけを開発シード4001–4008の8条件で測って尺度を確認し、候補と寄与無効の結果を見る前に閾値を固定した。資源が分かれた配置では二人の視認が1〜11%で候補の寄与（同じ相手への行動別遷移4件以上で非ゼロ）が生じにくいため、主要効果は資源共有の4条件で判定し、分離配置は副作用の対照として全項目に含める。
- 開発条件・未使用の確認条件: 開発シード4001–4008、確認シード5001–5008。いずれも本リポジトリで未使用。開発群の結果を見て係数・閾値・条件を変えない。確認群を一度見たら以後は既知の回帰チェックとして扱う。
- 主要指標・閾値・許容悪化: 主要 `contact-harm` = 接触ステップ割合の旧版−候補 ≥ 0.01（共有配置、32対）。副作用は危険度平均 ≥ −0.01、最低健康 ≥ −0.01、要求負担 ≥ −0.02、生活技能割合 ≥ −0.03、離隔割合の増加 ≤ 0.05、予測誤差 ≥ −0.02（8条件、64対）。寄与無効は全条件・全シードで旧版と最終world・身体・行動系列・指標が一致。core-v1の10項目に未達・許容幅超過の悪化がない。
- 本人に渡さないもの: 条件名、相手の内面、伝達成功や安全のラベル。二人は自分の知覚と記憶だけで判断する。
- 判定: 主要と副作用の全達成なら「通常worldでの支持」として既定化の判断へ進める。主要のみ未達なら候補を保持したまま機構の再設計課題を登録する。副作用の悪化があれば保留し、既定モデルを置き換えない。
- 結果ファイル・モデル/評価器ハッシュ: [開発結果](../results/world-v1-development.md) / [JSON](../results/world-v1-development.json)、[確認結果](../results/world-v1-validation.md) / [JSON](../results/world-v1-validation.json)。モデルコード`7e59f260…`、評価器`d58a6e13…`、環境`834de171…`（完全な値は各Markdownの冒頭）。
- 改善と悪化・代替説明: 下表。接触痛が起きるステップの割合は共有4条件で約0.04〜0.05から約0.01〜0.02へ減り、接触力の合計は約6.0から約1.5へ減った。4u未満の割合・平均距離・離隔割合はほぼ変わらないので、過剰な回避で接触を避けたのではなく、至近距離（衝突1.1u未満）だけを避けている。代わりに摂食・保温の選択が各4〜5%減り、身体要求の負担が+0.003〜0.015増える（許容幅内だが実在する費用）。食料摂取量の合計は変わらない。発声が約8%増える（機構の直接効果ではなく、摂食・保温が減った分の再配分と考えられる。良し悪しとして扱わない）。分離配置では寄与がほぼゼロで、全指標が旧版と一致に近い。core-v1は全項目が許容幅内。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録した判定規則に従い「通常worldでの支持」とし、候補を保持したうえで**既定化を推奨**する。ただし[CONTRIBUTING](../../CONTRIBUTING.md)と[版管理](../../docs/development/VERSIONING.md)の通り既定モデルの置換はレビュー後の判断なので、このセッションでは既定human 0.1.0を変更しない。改訂サイクルCLIには`predictive-normal-world-m1`として登録し（結果を見た後の再評価なのでretrospective）、`retain-candidate`で記録した。
- 限界と次の問い: 二人とも同じモデルの条件のみで、片方だけ候補の混在条件は扱わない。人間データとの校正はない。開発・確認シード4001–4008、5001–5008は観察済みで、以後は回帰チェックとしてだけ使う。次の問い: (1) 既定化のレビュー。採用ならhuman 0.2.0として版を上げ、core-v1基準とUI/CLIの既定を更新する。(2) 摂食・保温が減る機構の分析（食料の周りで至近距離を避けるために生活行動を後回しにしているか）。(3) M2の履歴介入protocolの登録。
