# 0018 / 食料が移り変わる世界での繰り返しの発見（referential-v3）

- 状態: 登録（prospective）。世界0.3.0・protocol・研究コード・テストをコミットし、パイロット（候補を含めない）で尺度を見て閾値を固定してから、開発・確認の未使用シードで測る。
- 背景: [判断0017](0017-referent-learner.md)の診断。(1) 「初回摂食までの時間」は学習が進む前に決まり、種類の学習を検出できない。(2) 量1.0の食料は25ステップで尽き、その後は再生分をかじり続けて食後の声が「ほぼ空の食料」から出続けるため、聞き手は食後の声を正しく「追う価値なし」と学んだ。声の指す先は世界の経済が決める。
- 世界の変更（世界0.3.0、既定の挙動は不変）: 食料の再生率を設定可能にし（省略時は従来の0.003）、`foodSpawn`を与えると、食料が閾値以下に尽きたとき、その場所は「空」として見え続け（記憶の修正ができるように）、決まった位置列の次の場所に新しい食料が現れる。乱数は使わない。量が1を超える食料を許す（1以下の食料の上限は従来のまま）。設定の検証（量0〜20、位置は舞台内、列は1〜64か所）を追加。
- 課題（referential-v3）: 食料1か所（量2）から始め、尽きると12か所の列の次に量2が現れる。再生なし。視界5u・聴覚24u・二人は20u離れて開始。実行3000ステップ。パイロット前の追跡で、量4・2400ステップでは出現が1〜2回だったため、量2・3000ステップで1実行あたり数回の発見が起きるようにした。
- 主要指標「到着遅れ」: 食料ごとに、先に食べた個体の初回摂食から、もう一人がその食料を初めて食べるまでのステップ（上限300、未到着は上限）を上限比で表し、先の発見が終了300ステップ前までに起きた食料について平均する。発見のたびに情報の非対称（知っている個体と知らない個体）が生じる構造そのものを測る。空腹平均と接触は副作用の項目として残す。
- 仮説と反証条件（evaluator: referential-v3。閾値はパイロット後に固定: 到着の短縮≥0.10、方向依存≥0.10、種類依存≥0.05、空腹の副作用≥−0.02、接触の副作用≥−0.01）:
  - H1: 候補`eating-voice-referent-0.8.0-experimental.3`が5項目（到着の短縮、方向依存、**種類依存**、空腹の副作用、接触の副作用）を開発・確認の両群で達成すれば「声の種類を手掛かりに食料へ向かう受け手側の合図利用が成立」と呼ぶ。
  - H2: `eating-voice-blind`（種類を使わない）と`food-call-referent`（食後の声が音として分かれない）の種類依存は両群で閾値未満。候補だけが達成することが、種類の利用の証拠になる。
  - 反証: 候補の種類依存がどちらかの群で閾値未満。原因候補: 出所の記憶（90ステップ・12件）が到着まで持たない、食料が尽きる前に着けない、分類の粒度。
  - 副次予測（報告のみ）: 候補の食後の声の分類の推定は正になる（0017では−0.7〜−1.0だった）。
- 開発条件・確認条件: 第1ラウンド、開発26001–26008、確認27001–27008。パイロット26101–26104。いずれも未使用。
- 本人に渡さないもの: 条件名、音の意味、正解、介入の有無、相手の内面、食料の出現位置。
- 実行コマンド: `npm run study:referential -- --protocol v3 --split development --model human-0.2.0 --model eating-voice-blind-0.8.0-experimental.2 --model food-call-referent-0.8.0-experimental.3 --model eating-voice-referent-0.8.0-experimental.3 --out outputs/referential-v3-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（26101–26104、候補は含めない。判定に使わない。[結果](../results/referential-v3-pilot.md) / [JSON](../results/referential-v3-pilot.json)）: 世界は厳しく、空腹平均は0.6〜0.9、1実行の出現は0〜5回。既定は到着の指標が0（方向を使わない）。盲目的な定位（食べる声＋盲目）は到着の短縮0.49・方向依存0.55と大きいが、空腹は0.09悪化し（26104では二人が互いの声を追って一つも食料を見つけられず、両者とも空腹0.98）、接触も増える。連動なしの出所評価は到着の短縮0.31・方向依存0.34、種類依存−0.035（でたらめ特徴のほうがやや良い）。**種類依存は非利用者で−0.035〜−0.007**なので、閾値0.05はその外側にある。閾値の固定はこの観察の後、候補の実行の前。
