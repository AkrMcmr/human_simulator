# 0030 / 慣習は作った個体が全員入れ替わっても残るか（generations-v1）

- 状態: 登録（prospective）。評価器の一般化・protocol・テストをコミットし、パイロット（候補を含めない）で尺度を見て閾値を固定してから、未使用シードで測る。
- 背景: [判断0029](0029-transmission-v2.md)で、何も知らない新参者が集団の任意の食料の声を聞いて真似て身につけること（産出の採用）が4群すべてで成立した。言語の慣習は個体より長く生きる。次の問いは、**それを作った個体が誰も残っていない**集団に、同じ声が残っているか。
- 介入（観察者側）: convention-v2の世界を3600ステップ走らせ、1200・1600・2000・2400ステップ目にA・B・C・Dを順に何も知らない個体に入れ替える。2400以降、最初の4人は誰もいない。入れ替えは400ステップおきなので、常に3人の在来と1人の新参者がいる状態を経て、全員が2世代目以降になる。
- 評価器の追加: 入れ替え前（800〜1200）の集団の食料の声の重心（入れ替え前の声）。**系統の連続**＝0.3 −（入れ替え前の声の重心と、後ろ3分の1（2400〜3600）の声の重心の距離）。後ろの声が収束していない（散らばり>0.15）か、どちらかの声がなければ0。収束・任意性・空腹の2項目は後ろ3分の1（全員入れ替わった後）で計算する。
- 候補と対照: `convention-contrast-0.10.0-experimental.2`（候補）。対照: `eating-voice-referent`（生得の声。距離はほぼ0で連続は0.3付近だが、任意性で落ちる——連続だけでは慣習と言えないことを示す）、`convention-no-imitation`（収束しないので連続0）、`human-0.2.0`。
- 仮説と反証条件（閾値はパイロット後に固定: 収束0.12・任意性0.08、系統の連続0.15（距離0.15以内）、後ろ3分の1の空腹の種類依存0.03・副作用−0.02）:
  - H1: 候補が5項目を両群で達成すれば「集団の任意の食料の声は、それを作った個体が全員入れ替わった後も、真似の連鎖だけで同じ声として残り、機能する（慣習の世代を越えた持続）」と呼ぶ。
  - H2: 生得の声は連続を達成するが任意性で落ちる。真似なしは収束せず連続0。
  - 反証の主な筋: (a) 全員入れ替わる過程で声が漂って別の場所に落ちる（収束はするが連続0）。(b) 新参者が続くと収束が崩れる。(c) 声は残るが機能しない。それぞれ記録する。(a)は言語の変化（drift）に相当し、それ自体が興味深い。
- 開発条件・確認条件: 開発56001–56008、確認57001–57008。パイロット56101–56104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol generations --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model convention-no-imitation-0.10.0-experimental.1 --model convention-contrast-0.10.0-experimental.2 --out outputs/generations-v1-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（56101–56104、候補は含めない。[結果](../results/generations-v1-pilot.md) / [JSON](../results/generations-v1-pilot.json)）: 生得の声は連続0.24〜0.26で任意性0.01（H2どおり）。真似なしは後ろの声が収束せず連続0。入れ替え前の窓の食料の声が4回しかないシードがあり（重心なし→連続0）、候補でも同じことが起きうる。暫定の閾値をそのまま固定した。閾値の固定は候補の実行の前。
