# 0005 / 経験履歴と記憶介入が危険度と行動評価を変える（M2）

- 状態: 実行済み。P1・P2の7項目を開発・確認シードの両方で達成。protocol・研究コード・閾値をコミット0bac5dcで固定してから実行した。モデルの変更・既定化は含まない。
- 対象モデルとソース: 既定human 0.2.0（`human-0.2.0`）。参照として旧0.1.0を同じ測定にかける。候補比較ではなく、既定モデルの現象確認。
- 根拠: 工学的仮説。[中期目標M2](../../docs/MIDTERM_GOALS.md)の「同じ現在の身体・知覚に対し、異なる経験履歴が行動へどう影響するか、記憶への介入を含めて検証する」に従う。人間の信頼・愛着・恐怖の再現ではない。
- 仮説と反証条件:
  - P1（履歴が知覚評価を変える）: 近距離で接触痛を受けた履歴は、同じ身体・同じ知覚のプローブで危険度と離隔対接近の評価差を上げる。相手の記憶を消すと差は消え、二人の記憶を入れ替えると差の向きが反転する。差が0.15未満、消去後も差が残る、入れ替えで反転しない、のいずれかで反証。
  - P2（回避が更新機会を奪う）: 危害がなくなった後、相手が近くに居続ける強制近接では危険度が下がる。自由行動では、食料が別で回避できる配置だと近接での証拠更新が減り、危険度が強制近接より高く残る。食料を共有する配置では身体要求が回避を上書きして更新が続く。強制近接で0.10未満しか下がらない、分離配置で強制近接との差が0.05未満、共有配置の証拠増加が分離配置を10以上上回らない、のいずれかで反証。
- 変更するもの・追加する仮定: 人間モデルの計算は変えない。実験者が履歴形成（60ステップ、距離2u、危害条件は確率0.5で接触痛0.03）、記憶介入（保持/消去/入れ替え）、強制近接96ステップ、自由行動120ステップ（食料共有/分離）を操作する研究コード`research/studies/history-v1.ts`と`npm run study:history`を追加。記憶の消去・入れ替えは実験者による介入で、本人に理由やラベルは渡さない。安定した追跡ID`B`を前提にする簡略化を明記する。
- 固定するprotocolと評価器: [`research/protocols/history-v1.json`](../protocols/history-v1.json)。評価器のハッシュは結果JSONに記録する。
- 閾値の決め方: パイロットシード6101–6104でhuman 0.2.0と0.1.0の尺度を確認してから固定した。パイロットの結果はゲート判定に使わず、パイロットで見た値（P1の差約0.38、強制近接の低下約0.25、分離配置の差約0.19、共有−分離の証拠増加約59）は開発・確認の結果と別に報告する。初稿の設計（自由行動が食料共有のみ）ではP2の差が約0.02と小さかったため、パイロット段階で「回避できる配置」を追加し、共有配置は「身体要求が回避を上書きする」という別の予測に切り替えた。この設計変更はパイロットに基づく。
- 開発条件・未使用の確認条件: 開発6001–6008、確認7001–7008。いずれも未使用。
- 主要指標・閾値: `history-risk` ≥ 0.15、`history-policy` ≥ 0.15、`erase-removes` ≥ −0.02、`swap-reverses` ≥ 0.15、`forced-recovery` ≥ 0.10、`free-fixation-separate` ≥ 0.05、`shared-keeps-updating` ≥ 10。判定は0.2.0の値。
- 探索的（判定しない）: 身体要求が高いと予測効用による履歴依存が小さくなるか、近接証拠の増加量と危険度の低下量の対応、旧0.1.0との同じ測定。
- 本人に渡さないもの: 条件名、介入の有無、相手の内面、安全/危険のラベル。
- 判定: 全達成ならP1・P2を「確認済みの機構」としてSTATUSへ記載し、M2の残り（観察画面での経験→予測→判断→結果の表示）へ進む。未達の項目は反証として残し、次の仮説を選ぶ材料にする。モデルの変更・既定化の判断は含まない。

- 改善と悪化・代替説明: 下表と補足。P1は0.1.0と0.2.0で完全に同じ値になった。履歴形成中は相手が動かないので距離変化の学習がなく、プローブでの予測効用が0になるためで、設計どおり。P2の「回避が更新機会を奪う」は分離配置で明確で、危害履歴の個体は120ステップ中2.5u未満に入ったのが開発で平均5ステップ、確認で平均3ステップ、8シード中5シードは一度も入らず危険度は変わらなかった。少数でも近接があったシード（8〜19ステップ）では危険度が0.08〜0.13下がり、近接証拠の量と低下量が対応している。共有配置では約72ステップ近接し、低下は強制近接とほぼ同じ。代替説明として「分離配置では単に相手が見えない」を確認したが、視認割合は88〜100%で、見えていて近づかない。もう一つの補足: 記憶の忘却は事前分布（危害推定0.5）へ戻る向きなので、無害履歴の個体は近接がないと危険度がわずかに上がる（分離配置で−0.0003〜−0.003の「低下」）。これは現行の忘却の仮定の性質で、無害の記憶も接触がなければ薄れることを意味する。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録した判定規則に従い、P1「経験履歴が同じ知覚に対する危険度と行動評価を変え、その差は相手の記憶に由来する（消去で消え、入れ替えで反転）」とP2「危害がなくなった後の更新は近接の機会に依存し、回避できる配置では警戒が残る。食料の共有が身体要求を通じて回避を上書きし更新を保つ」を、既定モデルhuman 0.2.0で確認済みの機構として記録する。人間の信頼・恐怖・愛着の再現とは呼ばない。
- 限界と次の問い: 相手は新規個体で、履歴の非対称（片方だけが危害を受けた）を扱う。相手側の反応の途中変化はまだ扱わない。人間データとの校正はない。探索的な「身体要求が高いと履歴依存が小さくなる」は、予測効用の項では成立（評価差0.018→0.004）したが評価全体では成立しなかった（0.247→0.233）。履歴依存の大半は危険度×警戒の直接項で、身体余裕は予測効用の項だけを弱める。これは「身体の余裕が警戒を弱める」という仮定への反例として記録する。次の問い: (1) 観察画面で経験→予測→判断→結果をたどれる表示（M2の残り成果物）。(2) 相手の反応が途中で変わる条件（危害→無害、無害→危害）と、忘却が事前分布へ戻る仮定の見直し（無害の記憶も薄れる性質を保つか）。(3) M3の最小合図protocol。
