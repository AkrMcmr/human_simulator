# 0034 / 暖まる機会と非対称の両方を持つ世界（lexicon-v3）

- 状態: 実行済み・反証（revise、系統を閉じる）。暖かい場所での声は1実行300〜880回と十分になり（H2成立）、分離ありは分離なしより区別・特異性がわずかに高い（0.229 / 0.222 vs 0.205 / 0.209、0.193 / 0.204 vs 0.190 / 0.189。H3は弱く成立）が、暖かさ側の4項目はどれも閾値に届かない（収束0.096 / 0.161、任意性0.072 / 0.125、区別≤0.229、特異性≤0.204、寒さの種類依存0.054 / 0.039）。事前登録どおり、2文脈（語彙）の系統は本セッションでこれを最後とする。コミット727ad10で固定してから実行した。
- 背景: [判断0033](0033-explicit-separation.md)の診断。分離の規則は開発群で2つの声を別の領域に置いたが、確認群では暖かい場所で声が出る機会が乏しく測れないシードが半数。lexicon-v1（暖かい場所2か所・半径3.5・周期400・寒度0.6〜0.7）は機会は多いが情報の非対称がなく、lexicon-v2（1か所・半径2.5・周期300・寒度0.8）は非対称はあるが機会が少ない。
- 変更（課題の世界のみ）: 暖かい場所2か所・半径2.5・周期300・環境寒度0.8。食料・モデル・評価器・指標は変えない。
- 候補と対照: `lexicon-0.11.0-experimental.4`（分離あり、候補）、`lexicon-0.11.0-experimental.3`（分離なし）、`convention-contrast-0.10.0-experimental.2`（1つの声）、`human-0.2.0`。
- 仮説と反証条件（evaluator: lexicon-v3、9項目。閾値はパイロット後に固定、暫定はlexicon-v2の値）:
  - H1: 候補が9項目を両群で達成すれば「語彙の最小形」と呼ぶ。
  - H2: 暖かい場所での声の回数が両群のすべてのシードで後ろ3分の1に5回以上あり、暖かさの重心が取れる（機会の確保）。
  - H3: 分離ありは分離なしより区別・特異性が高い（0033の再現）。
  - 反証: 暖かさ側のどれかが両群で閾値未満。本セッションでの2文脈の系統はこれで最後とし、結果を所有者に報告する。
- 開発条件・確認条件: 開発64001–64008、確認65001–65008。パイロット64101–64104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol lexicon3 --split development --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --model lexicon-0.11.0-experimental.3 --model lexicon-0.11.0-experimental.4 --out outputs/lexicon-v3-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（64101–64104、候補は含めない。[結果](../results/lexicon-v3-pilot.md) / [JSON](../results/lexicon-v3-pilot.json)）: 1つの声の対照でも暖かい場所での声が110〜246回あり、機会は確保された（H2の前提）。暖かさ側の帰無は区別0.13（最大0.23）・特異性0.09（最大0.19）・寒さの種類依存0.04（最大0.18）で、lexicon-v2の閾値の下。閾値は据え置きで固定。閾値の固定は候補の実行の前。
- 結果ファイル・ハッシュ: [開発](../results/lexicon-v3-development.md) / [JSON](../results/lexicon-v3-development.json)、[確認](../results/lexicon-v3-validation.md) / [JSON](../results/lexicon-v3-validation.json)。ソース727ad10（未コミット変更なし）。開発64001–64008・確認65001–65008は観察済み。
- 改善と悪化・代替説明: 確認群では分離ありの候補の暖かさの声の散らばりが8シード中6シードで0.07〜0.13と小さく、**1回の実行の中では暖かさの声も一つに集まっている**。それでも収束の利得が0.16に留まるのは、音なし条件でも暖まっている時の声がやや集まる（状態連動0.2と、暖まった直後の呼び声が同じ身体状態で出る）ためで、聞き合うことによる上乗せが食料の声（0.12〜0.16）と同程度しかない。区別（0.22）と特異性（0.20）は、暖かさの声が「どちらの文脈でもない時の声」からも食料の声からも0.2程度しか離れないことを示す——分離の規則は0.3を狙うが、真似の元が揺れるため平均では届かない。**代替説明**「暖かさの文脈が足りない」は今回の回数で否定。「聞き手が使えないだけ」ではなく産出側の分離が不十分。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。反証（revise）。0025〜0027・0031・0033・0034の6ラウンドで暖かさ側は成立せず、閾値も一度も緩めていない。到達した最良は「1回の実行の中で暖かさの声も集まり、食料の声から0.2ほど離れる」段階で、第2の語と呼ぶには足りない。本セッションの2文脈の系統はここで閉じ、所有者に報告する。次に試す価値がある設計（いずれも新しい仮定）: 文脈ごとに別の産出目録、聴覚分類の解像度、分離幅を聴覚分類に合わせて学習する規則。
- 限界と次の問い: 4人・同じモデル。指示対象は2つ。組み合わせ（文法）はない。
