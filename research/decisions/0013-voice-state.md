# 0013 / 状態連動の声（ユーザー指定の初期能力）と最小合図の再検証

- 状態: 実行済み・反証（revise）。連動を入れても合図は未成立。実装とprotocolをコミット49b954dで固定してから、signal-world-v1の第2ラウンド（未使用シード）で測った。初期能力としての「状態連動の声」自体はユーザー指定として維持し、次の課題設計で使う。
- 根拠の種類: **ユーザー指定**（2026-09-20、[CONCEPT](../../docs/CONCEPT.md)の未決事項「どこまで生得的か」への回答）。連動の割合と特徴の対応は工学的仮定。人間の声と情動の連動（声の高さ・震えが情動状態と相関する）は動機づけだが、係数は実測に基づかない。
- 旧モデルとソース: 既定human 0.2.0。直前の候補`signal-sender-0.5.0-experimental.1`（[判断0012](0012-signal-sender.md)、連動なし）を寄与無効として使う。候補`voice-state-0.6.0-experimental.1`はその上に状態連動を加える。
- 機構: 発声時、選ばれた基準の音（従来の再利用/新規、または発し手の学習による選択）と、状態から決まる音を0.4:0.6で混ぜる。状態の音は、開き＝clamp(危険度×2)、共鳴＝身体要求の最大値。運動雑音はその後に従来どおり加える。本人はこの連動を知覚・制御しない。音に意味・正解・成功ラベルは与えない。
- 対照: `voice-state-only`（連動のみ、学習なし）、`voice-state-receiver`（連動＋受信側学習、発し手学習なし）、`signal-sender`（連動なし。寄与無効）、既定0.2.0。
- 仮説と反証条件（評価器はsignal-world-v1、閾値は[判断0011](0011-signal-world-m3.md)で固定した0.03 bitのまま）:
  - 発し手（speaker-selection）: 連動により「相手との距離→出す音の種類」の結びつきが0.03以上になる。危険度が距離に依存するため、これは連動の構成から予想される。達成しても「発し手が選んだ」とは呼ばない。
  - 聞き手（listener-association、listener-holdout）: `voice-state-receiver`と`voice-state`で0.03以上。連動だけの`voice-state-only`では0付近を予想する（学ぶ側がいない）。聞き手項目が受信側学習を持つモデルで達成されれば、「世界に構造があれば受信側の関連学習は自由worldで働く」が支持される。未達なら、種類ごとの経験不足か、聞き手の反応が接近/離隔以外に出ていることを疑い、次に記録する。
  - 発し手学習の寄与: `voice-state`と`voice-state-receiver`の差。差がなければ発し手の選択学習はこの段階で不要と記録する。
  - 副作用: need-side-effect ≥ −0.02。core-v1で既定との比較が許容幅内。
  - 「最小合図の成立」の宣言は4項目を両群で達成した`voice-state`または`voice-state-receiver`に限る。
- 追加する仮定: 連動の割合0.6、対応する特徴の割り当て（危険度→開き、身体要求→共鳴）、危険度の2倍でのclamp。いずれも未校正。
- 開発条件・確認条件: signal-world-v1 第2ラウンド、開発16001–16008、確認17001–17008。いずれも未使用。第1ラウンドは[0011](0011-signal-world-m3.md)で観察済み。
- 本人に渡さないもの: 条件名、音の意味、正解、相手の内面。
- 結果ファイル・ハッシュ: [開発結果](../results/signal-world-v1-round2-development.md) / [JSON](../results/signal-world-v1-round2-development.json)、[確認結果](../results/signal-world-v1-round2-validation.md) / [JSON](../results/signal-world-v1-round2-validation.json)。ソース49b954d（未コミット変更なし）。
- 改善と悪化・代替説明: 発し手の結びつきは`voice-state`で0.026/0.001（開発/確認）、他は−0.004〜0.010で、全モデル閾値0.03未達。聞き手は−0.011〜0.020で未達（`signal-sender`の確認群の後半窓0.037だけが閾値を超えたが、同じモデルの前半・開発群は0付近なので偶然の範囲）。副作用なし。**機構の診断**（開発シード16001、`voice-state-only`）: 発声時の危険度は中央値0.026、90%点0.115、身体要求は中央値0.27で0.20〜0.39の範囲。つまり声に漏れる「状態」がこの世界ではほとんど変化していない。無害な近接が続いて危害推定が0.02付近に落ちるため、距離が近くても危険度は上がらず、食料共有の配置では空腹も狭い範囲に収まる。結果として出す音は9区分のうち2区分（開き低×共鳴低/中）に約8割が集まり、距離区分との対応はほぼない。聞き手側も、音を聞いた直後の行動は約95%が接近・離隔以外（摂食・保温・観察・発声）で、測っている反応そのものが起きていない。代替説明として「連動の割合0.6が弱い」も考えられるが、状態の分布が狭い以上、割合を上げても区分の偏りは変わらない。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録した反証条件に該当し`revise`。反証されたのは「状態連動の声を入れれば、この世界で聞き手が学べる構造が生まれる」という仮説であって、初期能力そのものではない。原因は、**この世界に声で伝えるに値する状態の変化が存在しないこと**にある。危険はほぼなく、食料は目の前で共有され、空腹は狭い範囲で推移する。
- 限界と次の問い: 二人とも同じモデル。連動は開き・共鳴の2特徴に固定。次の一手は世界の側にある。声が伝える価値のある「状態の差」と、聞き手がそれを知らない「情報の非対称」を世界に作る。具体案: (1) 発し手だけが視認できる危害源（接触すると痛みを与える第三の個体や場所）を置き、危険度が実際に変動する条件。(2) 食料を散在させて聞き手の視界外に置き、空腹の差と食料の在処が声に漏れる条件。(3) 聞き手の反応の測り方を、接近/離隔だけでなく「発し手の方へ動く/食料の方へ動く」など課題に合わせて定義し直す。これらは新protocol（referential-v1）としてパイロット→閾値固定→登録の手順で進める。
