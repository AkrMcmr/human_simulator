# 0021 / 食後の呼び声は発し手にとって費用か（caller-cost-v1）

- 状態: 登録（prospective）。実装・protocol・テストをコミットし、パイロット（候補を含めない）で帰無の尺度を見て閾値を固定してから、未使用シードで測る。
- 背景: referential-v4/v5（[判断0019](0019-referential-v4.md)・[0020](0020-referential-v5.md)）で、聞き手は食後の声を「食料がある」と学び、種類で追う相手を選ぶことが4群すべてでゲートを越えた（成立条件は未達）。しかし発し手側は、食後の呼び声を**生得の効用（+0.45）**で出しているだけで、その結果を学んでいない。この世界では呼び声は他者を自分の食料へ呼び寄せ、食料は分け合うと早く尽きるので、**呼び声は発し手にとって費用**のはずである。言語の進化論で古くからある問い（正直な合図の費用と利益）を、この実験室で測れる形にする。
- 候補: `learned-caller-0.9.0-experimental.1`。出所評価＋食べる声（`eating-voice-referent`）に、次の学習を足す。食べている（直前に摂取があった）ステップで、声を出したか出さなかったかを記録し、60ステップ後の自分の空腹の変化（減れば正）をその選択に帰属する。両方の選択が3回以上溜まったら、食後の呼び声の効用を `1 + 4×(呼んだ後の空腹改善 − 黙った後の空腹改善)`（0〜2に制限）倍する。聞き手の反応・意味・成功ラベルは与えない。
- 対照: `eating-voice-referent-0.8.0-experimental.3`（固定の呼び声。同じ世界で音あり・音なしの呼び声回数の自然な差を示す）、`human-0.2.0`。
- 評価器（caller-cost-v1、世界はreferential-v5と同一）: 新しい指標「呼び声の抑制」＝（音なしの食後の呼び声回数 − 音ありの回数）/ 音なしの回数。音なし条件では声が届かないので呼ぶ費用がなく、音あり条件では他者が来る。同じ個体・同じシードの中での対比なので、モデル間比較を要しない。到着の短縮・空腹の副作用などは報告のみ。
- 仮説と反証条件（閾値はパイロット後に0.3で固定）:
  - H1: 候補の呼び声の抑制が開発・確認の両群で閾値以上。「呼び声の費用を学んで黙る」。
  - H2: 固定の呼び声の抑制は両群で0付近（学習しないので条件間で呼び声は変わらない。音ありで他者が来て食料が早く尽きる分、食べている時間が減って呼び声もやや減る可能性はあり、これが帰無の尺度）。
  - H3（報告のみ）: 候補が黙れば、音あり条件の到着の短縮は固定の呼び声（0.5前後）より下がる。**聞き手が種類を学べる声が、発し手の学習で消える**ことが確認されれば、合図が安定するには発し手側の利益（安全・互恵・血縁）が世界に必要だと結論し、次の設計へ進む。
  - 反証: 候補の抑制が閾値未満。原因候補: 呼び声の費用が小さい（食料量4は分け合っても足りる）、60ステップの窓が短い/長い、呼び声と黙りの結果差が空腹の雑音に埋もれる。
- 開発条件・確認条件: 開発36001–36008、確認37001–37008。パイロット36101–36104。いずれも未使用。
- 本人に渡さないもの: 条件名、音の意味、正解、介入の有無、相手の内面、食料の出現位置。
- 実行コマンド: `npm run study:referential -- --protocol caller --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model learned-caller-0.9.0-experimental.1 --out outputs/caller-cost-v1-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（36101–36104、候補は含めない。[結果](../results/caller-cost-v1-pilot.md) / [JSON](../results/caller-cost-v1-pilot.json)）: 固定の呼び声の抑制は0.079±0.074（0.01〜0.18）。学習なしでも音ありで呼び声がやや減るのは、他者が来て食料が早く尽き、食べている時間が減るため。1実行の食後の呼び声は300〜430回で、候補が学ぶ機会は十分ある。閾値0.3は帰無の最大値0.18の上で、暫定値のまま固定した。
