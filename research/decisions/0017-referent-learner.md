# 0017 / 声の出所を訪れて評価する聞き手（referent learner）

- 状態: 登録（prospective）。実装・テスト・protocol（第3ラウンドのシード）をコミットしてから、referential-v2の第3ラウンド（未使用シード）で測る。候補の結果は閾値固定前に見ていない（閾値は[判断0015](0015-referential-v2.md)のまま）。
- 背景: [判断0016](0016-eating-coupling.md)で、食後の声は音として分かれるのに、聞き手の結果学習が種類を拾えないことを診断した。原因は学習機会の希少さ: 選択的な聞き手は「空腹で食料の記憶がないときに声を追い、30ステップ後の空腹変化」だけから学ぶため、900ステップで0〜2標本しか得られない。
- 変更（聞き手側の学習機構のみ。発し手側・声の仮定は0016のまま）: 聞いた音を、その**出所の位置**（音源定位で得た相対位置＋自分の位置）と分類とともに最大12件・90ステップ覚える。その後、自分の位置が出所から3u以内に入ったとき、視界に食料（残量>0.01）が出所の3u以内にあれば分類を+1、なければ−1として学習率で更新し、その記憶は消す。追った結果ではなく「出所に何があったか」を学ぶので、偶然通りかかっても学べ、学習機会は聞いた回数に比例する。空腹（>0.4）で食料の記憶がないときの定位は、推定が正の分類を優先し、負なら15%の探索を除いて追わない。未経験の分類は50%で最も大きく聞こえた音を追う。
- 与えないもの: 音の意味、正解、条件名、相手の内面。食料の有無は本人が自分の視界で見たものだけ。
- 候補と対照:
  - `eating-voice-referent-0.8.0-experimental.3`（候補）: 食べている状態の連動＋食後の呼び声＋出所評価の聞き手＋状態連動の声＋学習。
  - `food-call-referent-0.8.0-experimental.3`（対照）: 同じ聞き手、食べている状態は声に漏れない。食後の声が音として分かれないので、出所評価は分類ごとに分離しないはず。
  - 比較対象（既観察の系統、第3ラウンドで再実行）: `human-0.2.0`、`eating-voice-blind-0.8.0-experimental.2`（同じ声、盲目的な定位）。
- 仮説と反証条件（evaluator: referential-v2、第3ラウンド、閾値不変）:
  - H1: 候補が5項目（初回摂食の短縮≥0.03、方向依存≥0.03、**種類依存≥0.02**、空腹の副作用≥−0.02、接触の副作用≥−0.01）を開発・確認の両群で達成すれば「声の種類を手掛かりに食料へ向かう受け手側の合図利用が成立」と呼ぶ。
  - H2: 対照`food-call-referent`と`eating-voice-blind`の種類依存は両群で0付近（<0.02）。候補だけが達成することが、聞き手の出所評価が種類の利用を生んだ証拠になる。
  - 反証: 候補の種類依存がどちらかの群で0.02未満。その場合の原因候補: 記憶の窓（90ステップ）内に出所を訪れる頻度、分類の粒度、食後の声を追っても食料がすでに食べ尽くされている（量1.0、再生あり）。
  - 副次予測（報告のみ）: 候補の`soundReferents`の標本数は選択的な聞き手の`orientOutcomes`より一桁多い。
- 開発条件・確認条件: referential-v2 第3ラウンド、開発24001–24008、確認25001–25008。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol v2 --round 3 --split development --model human-0.2.0 --model eating-voice-blind-0.8.0-experimental.2 --model food-call-referent-0.8.0-experimental.3 --model eating-voice-referent-0.8.0-experimental.3 --out outputs/referential-v2-round3-development.json`（確認は`--split validation`）。
