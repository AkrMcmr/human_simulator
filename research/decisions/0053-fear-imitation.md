# 0053 / 怖がっている間の真似: 危険の声の真似の文脈を広げる候補（predator-v5、所有者の選択）

- 状態: 登録（prospective）。候補`threat-cry-near-fear-0.13.0-experimental.5`と対照`threat-cry-fear-deaf-0.13.0-experimental.5`、protocol predator-v5、テストをコミットし、未使用シード（100001–100008 / 101001–101008）で4モデル（既定、候補、対照、predator-v3の上限対照）を測る。パイロットは省く（世界・上限対照は不変）。
- 背景と選択: predator-v4（[判断0052](0052-near-association.md)）で、届く範囲の連合の候補は聞き手の寄与を2ラウンド・4分割すべてで達成したが、危険の声の収束（0.12）と食料の声との区別（0.25）は4分割中2で、2語の語彙としては未成立だった。所有者は選択肢(a)「産出側の候補——叫びの真似の文脈を広げ、真似の機会を増やす」を選んだ。
- 診断の根拠: 危険の声の真似は「脅威が見えている間に聞いた声」に限られる。潜む捕食者（視界2u、追跡0.75）では脅威が見えているのは1〜9ステップで、その間に仲間の叫びを聞く機会は少ない。食料の声は「食べている間」（長い）に聞いた声を真似て安定して集まる（収束0.13〜0.14）。
- 候補の規則（`packages/human/src/threat.ts`、`imitation = "fear"`。知覚・叫び・声の選び方・届く範囲の連合はexperimental.4と同一）: 危険の声の真似の文脈を「怖がっている間」に広げる——脅威が見えている、見失ってから20ステップ以内（`FEAR.ticks`、逃走の長さと同じ値）、聞いた警告から逃げている間（`fleeFrom`が有効）。聞かない対照は同じ産出規則だが警告で逃げないので、第3の文脈は生じない。意味・正解・他者の内部状態は与えない。
- 仮説と反証条件:
  - H1'（産出）: 危険の声の収束0.12以上、任意性0.08以上、食料の声との区別0.25以上を開発・確認の両群で達成（predator-v4では収束0.146 / 0.123 / 0.071 / 0.094、区別0.388 / 0.281 / 0.195 / 0.230）。
  - H2''（理解）: 聞き手の寄与1.0回以上を両群で維持。
  - 残りのゲート（襲撃の利益2.0、空腹の副作用−0.02、食料の声の収束0.12）も両群で達成した時に限り「経験と真似だけで、食料の声と危険の声が集団ごとに別々に共有され、聞き手が危険の声で襲撃を避ける（2つの指示対象を持つ語彙の最小形）」と呼ぶ。
  - 反証の主な筋: (a) 警告から逃げている間に聞くのは警告そのものなので真似は集まるが、食料の声が混じって区別が縮む。(b) 怖がっている間の真似が食料の声の慣習を乱す（食料の声の収束が落ちる）。(c) 収束は上がるが聞き手の寄与が落ちる（真似の対象が増えて警告の分類がぼやける）。
- 開発条件・確認条件: 開発100001–100008、確認101001–101008。未使用（テストで確認）。閾値はpredator-v4から据え置き。
- 実行コマンド: `npm run study:referential -- --protocol predator5 --split development --model human-0.2.0 --model threat-cry-near-fear-0.13.0-experimental.5 --model threat-cry-fear-deaf-0.13.0-experimental.5 --model threat-cry-alarm-ceiling-0.13.0-experimental.3 --out outputs/predator-v5-development.json`、同じく`--split validation`。
