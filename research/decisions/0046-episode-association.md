# 0046 / 訪問1回につき1回の連合と、毒2つに1つの世界（valence-v10）

- 状態: ラウンド1終了、**未成立**。数え方の修正は働いたが、この世界では**良い声だけで後ろ3分の1の毒当たりがほぼ0**になり（味覚嫌悪の対照でも2.75→0.25）、悪い声の出番そのものが消えた。対比較は−0.25 / −1.25。厳密な連合学習の系統（v9・v10）はここで一区切りとし、次は所有者の判断を待つ。
- 背景: valence-v9（[判断0045](0045-strict-association.md)、開発群）で候補と聞かない対照の行動は全シードで完全に一致し（対比較0.000）、連合による警告は一度も発火しなかった。状態を直接見ると（開発シード86001–86002、scratch診断）、各分類の「無事」の回数が数十〜数百、「毒」は0〜3で、警告の条件（毒≧1かつ毒＞無事）を満たす個体がほぼ無い。原因は二つ。(1) **数え方**: 聞いた声1つごとに出所の記憶を作り、出所の近くで食べた瞬間にその記憶を1つずつ「無事」と数えていた。仲間が毎ステップ声を出す間に食べ続けると、1回の訪問で数十回の「無事」が積まれる。毒は味覚嫌悪で場所ごと1回しか当たらないので、勝負にならない。(2) **悪い声の機会**: 7か所・毒3つに1つの世界では毒に当たる機会が少なく、嫌悪の声は実行あたり33回（良い声519回）で、良い声との区別は0.10。連合が付く「悪い声の分類」そのものが育っていない。
- 候補`valence-assoc-0.12.0-experimental.9`（`decideValence(..., "assoc2")`）: experimental.8の数え方を訪問1回につき1回に直す。(1) 同じ分類の声を出所の3u以内から既に覚えていれば新しい記憶を作らず時刻だけ更新する。(2) （分類, 場所）の結果を数えたら、同じ組は300ステップ数え直さない。警告の条件（毒≧1かつ毒＞無事）、産出、味覚嫌悪、聞いた警告の使い方は変えない。聞かない対照`valence-assoc-private-0.12.0-experimental.9`。
- 世界（valence-v10）: valence-v7〜v9の世界（腐る、量6）で毒の割合を3つに1つ→**2つに1つ**に戻し、パイロット1の結果を受けて食料を9か所にする（無毒の供給を保つ）。悪い声の機会を増やす目的。v3/v4で毒2つに1つが過酷だったのは3か所・量4の世界で、7か所・量6なら飢えずに済むかをパイロットで確かめる。
- パイロット（88101–88104、既定・味覚嫌悪・上限対照）: (1) 味覚嫌悪の音なしの非常時割合3%未満・後ろ3分の1の空腹0.5未満、(2) 上限対照の毒に当たる回数の利益1.0回以上。満たさなければ再調整し、候補は走らせない。
- 閾値: 7項目と対比較1.0回、据え置き。
- 仮説と反証条件:
  - H1（世界）: 毒2つに1つでも7か所・量6なら非常時3%未満で、上限対照の利益は1.0回以上（v7〜v9より毒当たりが多いので余地は広がる）。
  - H2（候補）: 訪問1回につき1回の数え方で、毒の場所で悪い声を聞いて当たった経験を持つ個体が育ち、警告の分類を持つ個体・時刻が増える（v9は12000のうち0〜382）。対比較が正になる。1.0回に届くかは悪い声の区別（0.25以上に戻るか）に依存する。
  - 反証の主な筋: (a) 世界が過酷でパイロット不達。(b) 悪い声の区別が戻らず、連合の付く分類が無い→産出側の問題として次に回す。(c) 連合は育つが警告後の回避が毒当たりを減らさない→上限対照との差で判断。
- 開発条件・確認条件: 開発88001–88008、確認89001–89008。パイロット88101–88104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence10 --split pilot --model human-0.2.0 --model valence-aversion-0.12.0-experimental.2 --model valence-alarm-ceiling-0.12.0-experimental.5 --out outputs/valence-v10-pilot.json`、続いて`--split development` / `--split validation`に`--model valence-assoc-private-0.12.0-experimental.9 --model valence-assoc-0.12.0-experimental.9`を加えた5モデル。
- パイロット1（88101–88104、7か所・毒2つに1つ、`research/results/valence-v10-pilot1.{json,md}`）: **両基準不達**。味覚嫌悪の音なしの非常時7.0%（v7の2.0%から戻った）、空腹0.42。上限対照の利益0.75回（シード別−2,2,2,1）、上限対照の音なし非常時6.3%。毒を半分にすると無毒の食料は実質7×2/3≈4.7か所→3.5か所に減り、毒を避ける集団の飢えが戻る。上限対照の音ありでは嫌悪の声が38回（音なし120回）と抑えられ毒当たりは4.75 vs 9.75と半減しているが、後ろ3分の1の差は小さい。世界を再調整: 無毒の供給をv7と同等（約4.5か所）に保つため9か所（food-8 (14,13)・food-9 (26,16) を追加）にし、パイロット2を新しいシード88111–88114で行う。
- パイロット2（88111–88114、9か所・毒2つに1つ、`research/results/valence-v10-pilot.{json,md}`）: **両基準達成**。味覚嫌悪の音なしの非常時0.9%、後ろ3分の1の空腹0.25。上限対照の利益2.0回（シード別−1,3,2,4。音あり0.5 vs 音なし2.5）。悪い声の機会は増えた: 上限対照の音なしで嫌悪の声167回（v7の世界では62〜83回）。世界を確定し、候補と聞かない対照を含む5モデルで測る。

  - **この世界では声を出すどのモデルでも、音ありの後ろ3分の1の毒当たりが0〜0.75回**（音なし2.75〜4.13）。聞いた声を採餌に使わない味覚嫌悪の対照でさえ2.5 / 2.9回の利益。良い声は無毒の食料でしか出ない（毒を食べた瞬間に文脈は悪いに変わる）ので、9か所・毒2つに1つの世界では「良い声がする場所へ行く」だけで毒の場所を訪れなくなる。**良い声の不在が、それ自体で毒の印になっている。**
  - その結果、後ろ3分の1に毒に当たる個体がおらず、嫌悪の声も後ろ3分の1にはほぼ出ない（悪い声の重心が無いシードが大半、区別0.02〜0.06）。悪い声の収束・区別・対比較はこの世界では測れない（悪い声が要らない世界になった）。
  - 訪問1回につき1回の数え方は働いている（連合が発火して候補と対照の行動が分かれるシードがある）が、寄与は負（開発−0.25、確認−1.25で1シード−7）: 警告で避けた分類が良い声の分類と重なると無毒の食料を避ける。
  - 上限対照の余地は2.9 / 3.5回だが、その大半は味覚嫌悪の対照と同じ「良い声への誘導」の効果で、生得の警戒声固有の寄与（上限対照 − 聞かない対照）は−0.4 / +0.1回。
- 採否と判断者・理由: 未成立（Claude）。閾値は緩めない。
- 厳密な連合学習の系統（v9・v10）の総括と、構造的な発見: **良い声の慣習が成立した集団では、豊かな世界なら良い声の不在だけで毒を避けられる**。悪い声が便益を持つのは、無毒の食料が乏しく自力で毒の場所へ向かわざるを得ない世界だが、そこでは毒を避ける集団が飢える（v3〜v6）。豊かにすると悪い声の出番が消える（v7〜v10）。この「飢えるか、要らないか」の挟み撃ちが、4人・場所に固定された毒という設計の中で、悪い声の聞き手側の成立を阻んでいる。世界の設計そのものを変えない限り、この系統の候補の改良では聞き手側は測れない。
- 次の設計案（所有者の判断を要する）: (1) **毒の潜伏**: 毒の効果を数十ステップ遅らせ、毒の場所でも最初は良い声が出るようにする（良い声の不在が印にならなくなり、悪い声が唯一の手掛かりになる）。世界の変更で、契約は不変。(2) 悪い声の便益を後ろ3分の1ではなく実行全体の対比較で測る新しいprotocol（初回訪問の毒当たりは前半に集中する）。(3) 毒課題を閉じ、成立した2語の産出（v6）を「集団ごとの語彙」として観察画面・ダイジェストに反映し、別の指示対象（例: 危険な動物）へ進む。
- 限界と次の問い: 300ステップの再計数間隔と3uの半径は設計値。連合は聴覚分類（幅0.18）単位。4人・同じモデル。組み合わせ（文法）はない。
