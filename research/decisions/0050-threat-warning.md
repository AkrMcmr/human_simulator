# 0050 / 危険な動物の声: 逃走・危険の声・厳密な連合（predator-v2、所有者の選択）

- 状態: 登録（prospective）。人間モデルの共通フック（脅威・逃走方向）、候補・対照・上限対照、評価器の危険の声の尺度、protocol・テストをコミットし、パイロット（既定・聞かない対照・上限対照）で上限対照の余地と帰無の水準を見て閾値を固定してから、未使用シードで4モデルを測る。
- 背景と選択: predator-v1（[判断0049](0049-predator-design.md)）のパイロット4回で、世界（捕食者1体、噛んで離れる、害12）は被害の余地（後ろ3分の1に襲撃9回前後）と飢えの無さを満たしたが、「仲間が15ステップ以上先に見ていた襲撃」は約19%（実行あたり約5回）で事前の30%に届かなかった。所有者は案1を選んだ: 観察された非対称を世界の水準として受け入れ、主ゲートを後ろ3分の1ではなく**実行全体の対比較**（聞かない対照 − 候補の襲撃）にする。
- 共通フック（`packages/human/src/index.ts`、既定モデルの計算は不変）: `DecideOptions.threat`（候補が観察から計算した脅威の危険度と位置）と`fleeFrom`（聞いた警告からの逃走方向）。脅威か逃走方向があるとき「離れる」行動に逃走の項（危険度×1.6、警告のみなら0.9）が加わり、目標は脅威（無ければ警告の出所、無ければ相手）から遠ざかる方向。状態連動の声の「開き」は相手の危険度と脅威の危険度の大きいほうを使う。既定はどちらも渡さないので挙動は不変（テストで確認）。
- 候補`threat-0.13.0-experimental.1`（`packages/human/src/threat.ts`）: 食料の声の慣習（真似＋対比、[判断0024](0024-convention-v2.md)）の上に三つを加える。(1) **初期能力としての脅威の知覚**: 形態の類似度0.7未満の動物が視界6u以内にいれば、近さに応じた危険度（1−距離/6）を感じ、離れる。所有者が案1を選んだことでこの初期能力を承認したものと扱う（[判断0013](0013-state-coupled-voice.md)と同じ型）。(2) **危険の声**: 脅威が見えている間は発声の衝動（食料の声と同じ大きさ、10ステップに1回まで）を持ち、脅威を見ている時に聞いた声の分類を真似る（食料の声から0.25以上離す）。食べている時は食料の声（危険の声から離す）、どちらでもない時は両方から遠い自分の音。真似の元が無い時は状態連動（危険度→開き）が声の形を決める。(3) **厳密な連合による理解**（[判断0045](0045-strict-association.md)の型）: 聞いた声を出所と共に記録し、30ステップ以内に脅威を見るか痛み（衝突>0.5）を受ければその分類に「的中」、期限が過ぎれば「外れ」を数える。的中1以上かつ的中＞外れの分類が「警告」で、警告を聞いたら出所から20ステップ離れる。自分の声との照合はしない。
- 対照: `threat-deaf-0.13.0-experimental.1`（同じ知覚・声・連合の学習、聞いた警告で離れない）、`threat-alarm-ceiling-0.13.0-experimental.1`（脅威を見た時に固定の警戒声、その音を聞けば出所から離れる生得の理解）、既定。
- 評価器の追加: 危険の声（捕食者が見えている時の発声、後ろ3分の1）の重心・散らばり、収束（音なし − 音あり）、任意性（シード間の広がり）、**食料の声と危険の声の区別**（重心間距離）。実行全体の襲撃の利益は既存。対比較は実行全体の襲撃。
- 課題（predator-v2）: predator-v1の最終の世界で、パイロット1の結果を受けて捕食者の速さを0.30→0.75にする（他は同一。テストで確認）。
- 閾値（暫定、パイロット後に固定）: 食料の声の収束0.12、危険の声の収束0.12・任意性0.08、区別0.25、襲撃の利益（実行全体）2.0回、空腹の副作用−0.02、対比較「聞き手の寄与」2.0回。2.0回はpredator-v1のパイロットで仲間が先に見ていた襲撃が実行あたり約5回だったことの約4割。
- パイロット（94101–94104、既定・聞かない対照・上限対照）の基準: (1) 上限対照の実行全体の襲撃の利益2.0回以上、(2) 聞かない対照の同じ利益が上限対照の半分未満（逃げる個体の動きだけで襲撃が減っていない）、(3) 非常時3%未満・死亡が実行の半数未満。閾値はパイロットの帰無を見て固定し、候補を走らせる前に記す。
- 仮説と反証条件:
  - H1（産出）: 危険の声は食料の声と同じ機構で集まり（収束0.12以上）、食料の声から離れる（区別0.25以上）。毒課題のv6で2つの価値の声が分かれたのと同じ型。
  - H2（理解）: 対比較が2.0回以上。連合の「的中」は脅威が近づく前に仲間の声を聞く場面（仲間が先に見た襲撃、約5回/実行）で積まれる。
  - 反証の主な筋: (a) 上限対照でも余地が出ない（逃げても噛まれる、逃げる先が別の危険）→世界の再調整。(b) 危険の声が集まらない（脅威を見ている時間が短く真似の機会が少ない）。(c) 連合が食料の声を警告にする（食料の場所で仲間の声を聞いた直後に捕食者が来る）→誤警報で空腹が悪化。
- 開発条件・確認条件: 開発94001–94008、確認95001–95008。パイロット94101–94104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol predator2 --split pilot --model human-0.2.0 --model threat-deaf-0.13.0-experimental.2 --model threat-alarm-ceiling-0.13.0-experimental.2 --out outputs/predator-v2-pilot.json`、続いて`--split development` / `--split validation`に`--model threat-0.13.0-experimental.2`を加えた4モデル（パイロット5まではexperimental.1）。
- パイロット1（94101–94104、捕食者の速さ0.30、`research/results/predator-v2-pilot1.{json,md}`）: **基準(1)不達**。逃げる個体（聞かない対照）は襲撃を既定の26.5回から11.5回に半減させ（自分で見て逃げれば足りる）、残る襲撃のうち仲間が先に見ていたものは0.75回しか無く、上限対照の実行全体の襲撃の利益は−3.5回（音あり15.0 vs 音なし11.5）——警戒声で逃げる分だけ採餌が乱れ、襲撃は減らない。基準(3)は達成（死亡0、非常時0.3〜0.8%）。副次: 聞かない対照の危険の声は実行あたり991回（脅威が見えている間は毎ステップ衝動）で、食料の声の収束も0.116と鈍った。診断: 捕食者（0.30）が人間の逃走（0.65）より遅いので、見てから逃げれば間に合い、警告は要らない——毒課題の「要らない」側の壁の再現。世界を再調整: 捕食者の速さを0.75（見てからでは逃げ切れず、先に見た仲間の警告だけが間に合う）。候補・対照・上限対照に危険の声の間隔10ステップを加えた。パイロット2は新しいシード94111–94114。
- パイロット2（94111–94114、捕食者の速さ0.75、`research/results/predator-v2-pilot2.{json,md}`）: 逃げる個体でも襲撃は減らず（聞かない対照29.5回、既定32.5回）、仲間が先に見ていた襲撃は約30回中21〜29回と豊富になった。しかし**基準(1)不達**——上限対照の実行全体の襲撃の利益0.0回（29.5 vs 29.5）。捕食者は9u以内の最も近い個体を追い、視界5uで最初に見た者がその標的なので、警戒声は「自分が追われている」ことしか伝えず、他の個体は80ステップの間は安全。産出側は聞かない対照で危険の声の収束0.156・任意性0.084・区別0.256と、危険の声が食料の声と別に集まる兆しが出た（候補未実行のため参考値）。世界を再調整: **潜む捕食者**——2uまで近づかないと見えず、遅く（0.2）、3u以内の人間だけを追う。噛まれた者の声が捕食者の今の位置を伝え、聞いた者がその場所を避ければ次の噛みつきを避けられる（警告が「今」を伝える型）。パイロット3は新しいシード94121–94124。
- パイロット3（94121–94124、潜む・遅い捕食者、`research/results/predator-v2-pilot3.{json,md}`）: 逃げる個体は2uで見てから逃げても間に合い、襲撃は3.5〜4.25回（既定17回）。**基準(1)不達**——上限対照の利益−1.5回（5.0 vs 3.5）、余地そのものが小さい。世界0.8.0に`chaseSpeed`（追跡時の速さ）を追加し、「潜んで、追う時だけ速く（0.75）、巡回は遅い（0.2）」でパイロット4へ。
- パイロット4（94131–94134、`research/results/predator-v2-pilot4.{json,md}`）: 逃げる個体の襲撃は4〜5回（既定16〜17回）、上限対照の利益−0.75回で**基準(1)不達**。2uで見えてからでも、追跡0.75と逃走0.65の差では捕まる前に3uの追跡半径を抜けることが多い。四つの世界のすべてで「見てから逃げる」個体には警告の残余価値が無かった。最後の組み合わせとして、噛む時は即座（chaseSpeed 1.2、見えたら逃げ切れない）で、噛んだ後20ステップで次の最も近い個体を狙う「群れを一人ずつ襲う」捕食者を試す——同じ食料の場所にいる仲間は、噛まれた者の声で「今ここにいる」を知れば離れられる。パイロット5は新しいシード94141–94144。
- パイロット5（94141–94144、`research/results/predator-v2-pilot5.{json,md}`）: 上限対照の実行全体の襲撃の利益−0.25回（シードごとに+6、−8、−3、+4）で**基準(1)不達**。聞かない対照は音あり8.25回・音なし6.25回、既定は24.5回。基準(3)は達成（死亡0、非常時0〜0.8%）。追跡（seed 94142の襲撃ごとの位置）で分かった二つの不具合: (a) **世界0.8.0は`chaseSpeed`を型と設定で宣言していたが追跡の移動に使っていなかった**（`advanceWorld`は巡回の速さだけを使用）。パイロット4・5の捕食者は0.2で追っており、パイロット4の記録にある「追跡0.75では逃げ切れる」という解釈は誤り（実際は0.2）。(b) cooldown 20の捕食者は噛んだ後も同じ個体のそばに留まり、地図の隅に追い詰めた1人（B）を446〜1017ステップの間に11回噛んだ。「次の最も近い個体」は常に同じ個体だった。さらに上限対照は、普通の低い声（開き・共鳴とも0.1付近）を生得の警戒声と取り、seed 94141では各個体が実行の3分の1（800〜1270ステップ）を警戒逃走に使っていた（危険の声は7回しか無い）。
- 修正（世界0.9.0・上限対照experimental.2）: 世界は追跡中に`chaseSpeed`を実際に使い、`victimMemory`（噛んだ個体をその歩数だけ追わず噛まない）を加えた。候補・対照・上限対照の識別子は`threat-*-0.13.0-experimental.2`に上げた（候補・聞かない対照の判断規則は不変。上限対照だけ、警戒声の判定を「自分の食料の声より警戒声の形に近い音」に限り、普通の声を警戒声の半径の外に置く——valence-v7の上限対照と同じ守り）。protocol 1.5.0: chaseSpeed 1.2（今度は有効）、cooldown 5、victimMemory 300。狙い: 同じ食料の場所にいる群れは、最初の1人が2uで見た時には3u以内から1.2で追われて逃げ切れないが、その者の声を聞いた残りは5ステップの間に3uの外へ出られる（音なしでは次々に噛まれる）。
