# 0032 / 世代の連鎖を広い窓で測り直す（generations-v2）

- 状態: 実行済み・反証（revise）——**漂いは窓の問題ではなく現象**（H2成立）。入れ替え前の窓を広げると16シードすべてで入れ替え前の声の重心が取れた（食料の声21〜108回）が、系統の連続は0.115 / 0.125で閾値0.15に届かず、0.15以内に留まったのは16シード中5シード。全員入れ替わった後の収束は両群で保たれた（0.146 / 0.163、任意性0.078 / 0.099）。生得の声は連続0.28で任意性0.01（予測どおり）。この系統は閉じる。コミット1b6a560で固定してから実行した。
- 背景: [判断0030](0030-generations.md)で、全員が入れ替わった後も収束した任意の声は残るが漂い、系統の連続は未達だった。確認群の3シードでは入れ替え前の窓（800〜1200）の食料の声が1〜9回しかなく重心が取れず、連続が定義により0になった。
- 変更（評価器の窓と介入の時刻のみ）: 入れ替え前の窓を800〜1600に広げる。入れ替えを1600・2000・2400・2800に遅らせ、実行を4000ステップにする（後ろ3分の1は2667〜4000で、最初の4人は誰もいない）。閾値は不変。漂いの量（入れ替え前後の重心の距離）はチェックの値（0.3 − 距離）から読める。
- 候補と対照: 0030と同じ（候補`convention-contrast-0.10.0-experimental.2`、対照`eating-voice-referent`・`human-0.2.0`。真似なしは0030で連続0が確認済みなので省く）。
- 仮説と反証条件（evaluator: generations-v2、5項目、閾値不変）:
  - H1: 候補が5項目を両群で達成すれば「慣習の世代を越えた持続」と呼ぶ。
  - H2（報告のみ）: 窓が広がっても連続が0.15未満のシードが半数以上残るなら、漂いは窓の問題ではなく現象である。
  - 反証: 候補の連続がどちらかの群で0.15未満。その場合は漂いを現象として記録し、この系統を閉じる。
- 開発条件・確認条件: 開発60001–60008、確認61001–61008。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol generations2 --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model convention-contrast-0.10.0-experimental.2 --out outputs/generations-v2-development.json`（確認は`--split validation`）。
- 結果ファイル・ハッシュ: [開発](../results/generations-v2-development.md) / [JSON](../results/generations-v2-development.json)、[確認](../results/generations-v2-validation.md) / [JSON](../results/generations-v2-validation.json)。ソース1b6a560（未コミット変更なし）。開発60001–60008・確認61001–61008は観察済み。
- 改善と悪化・代替説明: 入れ替え前後の重心の距離は0.01〜0.30（連続の値0.3 − 距離から）。距離が小さいシードでは同じ声が3世代を越えて残り、大きいシードでは別の声に置き換わっている。新参者が入るたびに真似の元が揺れ、集団全体が動く。**代替説明**「後ろの声の収束が弱いだけ」は、収束の利得が両群で0.15前後（convention-v2の成立時と同じ水準）であることから否定。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録の連続では未成立（revise）。記録する現象: **任意の慣習は、作った個体が全員入れ替わっても集団に残るが、その音は世代を越えるあいだに漂う**。漂いを「失敗」ではなく測定対象にするなら、連続の閾値ではなく漂いの分布（距離の中央値など）を報告指標にした新しい登録が要る。本セッションではここで閉じ、所有者に報告する。
- 限界と次の問い: 入れ替えは4回の1系列。語・文法・意図の再現ではない。
