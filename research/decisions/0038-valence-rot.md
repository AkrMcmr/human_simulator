# 0038 / 腐る食料の世界で良い声と悪い声を再測定（valence-v2）

- 状態: ラウンド1終了、**未成立**（両群で7項目中5項目）。良い声と悪い声の区別は腐る世界では両群で閾値を越えた（0.264 / 0.272）が、毒の利益は負のまま。H2（停滞が原因）は反証。原因はコードの読み直しで別に特定し、[判断0039](0039-taste-aversion.md)へ。
- 背景: valence-v1（[判断0037](0037-valence.md)）で候補`valence-0.12.0-experimental.1`は、良い食料の声と悪い食料の声を両群で対照より明確に分けた（区別0.283 / 0.213、対照0.057 / 0.039）が、聞き手の毒の利益は後ろ3分の1で0付近だった。分けて見ると前3分の2の毒の摂食は半分以下（4.92→1.33、5.12→2.60）に減っており、後ろ3分の1だけ減らない。世界0.5.0では食料は「尽きたとき」にしか次が現れないため、集団が毒を避けるとその場所が尽きずに残り、3枠の生きた食料が毒で埋まる。前半で毒を避けた集団ほど、後半には毒しか残らない。毒の回避が世界の側で罰されており、後ろ3分の1の機能はこの世界では測れない。
- 世界の変更（世界0.6.0、`packages/world/src/index.ts`）: `foodSpawn.lifetime`を任意項目に追加。食料は現れてから`lifetime`ステップで腐り、尽きたときと同じく「空」として残って次の場所に新しい食料が現れる（初期の食料は0ステップ起点、`Resource.since`に出現ステップを保存）。省略時は従来どおり尽きるまで残る（0.5.0の挙動、既定の世界は不変）。設定検証は`lifetime`に1以上の整数を要求。乱数は使わない。
- 課題（valence-v2）: valence-v1の世界（4人・食料3か所が移り変わる・出現2つに1つが毒・初期の1か所が毒）に`lifetime: 500`を加える。音なしの集団は約600ステップに1か所を食べ尽くしていたので、500は「避けられた場所はおおむね1回分の間隔で消える」水準。候補・対照・既定は変えない（世界だけを変えて同じ候補を測る）。
- 評価器・尺度: valence-v1と同じ7項目・同じ閾値（良い声の収束0.12・任意性0.08、悪い声の収束0.12、区別0.25、毒の利益0.2、毒の種類依存0.1、空腹の副作用−0.02）。**候補のv1の結果を見た後なので閾値は一切変えない。** パイロットは既定と1つの声の候補のみで、(1) 音なしの後ろ3分の1に毒の摂食が起きること、(2) 帰無が閾値を越えないことを確認する用途に限る。
- 仮説と反証条件:
  - H1: 候補が7項目を両群で達成すれば「経験と真似だけで、良い食料の声と悪い食料の声が集団ごとに別々に共有され、形成後に聞き手が毒を避ける（2つの価値を持つ語彙の最小形）」と呼ぶ。v1の未成立の記録は残す。
  - H2: 候補の毒の利益は後ろ3分の1で0.2以上になる（v1で前3分の2に見えた5〜7割の削減が、毒の場所が消える世界では後半にも続く）。区別はv1と同程度（0.2〜0.3）で、閾値0.25を越えるかは半々と予想する。
  - 反証の主な筋: (a) 腐る世界でも後ろ3分の1の毒の利益が0.2未満なら、停滞の診断が誤りで、聞き手の回避が弱い（悪い声の出所3u以内の記憶消去と、悪い推定>0.3の声を追わない規則だけでは足りない）。(b) 腐ることで食料が全体に乏しくなり空腹の副作用が悪化する。(c) 区別が0.25に届かない場合は、聴覚分類の幅0.18と分離幅0.3の間にある幾何学の問題として別に扱う。
- 開発条件・確認条件: 開発72001–72008、確認73001–73008。パイロット72101–72104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence2 --split pilot --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --out outputs/valence-v2-pilot.json`、続いて`--split development` / `--split validation`に`--model valence-0.12.0-experimental.1`を加えた3モデル。
- パイロットで見えたこと（72101–72104、既定と1つの声の候補、`research/results/valence-v2-pilot.{json,md}`）: 腐る世界でも毒の摂食は起きる（音なしの後ろ3分の1で既定3.5、1つの声3.9。実行全体では11〜14と、v1の9〜10より多い——腐ることで食料の場所が多く現れ、毒の場所も増える）。帰無は閾値を越えない: 既定の毒の利益−0.40、1つの声の候補は−0.66（方向だけの声は腐る世界でも毒の場所へ人を集める）、区別0.054、任意性0.074。1つの声の毒の種類依存0.16は4シードの揺れ（−0.61〜0.67）。閾値は据え置き。

  - 区別: 候補は開発8シード中7シードが0.23以上、確認は8シード全部が0.22以上（対照は最大0.13）。腐る世界では**良い食料の声と悪い食料の声の分化は両群で事前の閾値を越えた**。産出側の2つの声は頑健と見てよい。
  - 毒の利益: 候補は音があると毒の摂食が**増える**（開発 音あり10.9 vs 音なし9.4、確認 11.2 vs 12.3。後ろ3分の1は4.19 vs 3.47、4.22 vs 4.13）。v1で見えた前3分の2の削減も消えた（開発 6.69 vs 5.94）。1つの声の対照は毒の摂食を大きく増やす（音ありで声が人を食料へ集め、毒の場所にも集める）。既定の0.200（確認）はシード間SD0.35の揺れで、既定には声の利用がない。
  - 世界の様子: 出現は全条件・全シードで18回（3か所×500ステップ×6周期）で、尽きる前に腐る。食料は相対的に豊富になり（84単位のうち24〜26を食べる）、v1のような食料不足による停滞は起きない。**それでも毒の利益は出なかった**ので、H2「停滞が原因」は反証された。
  - 原因（結果を見てからコードを読み直して特定）: 既定の知覚処理は毎ステップ、見えている食料で場所記憶を上書きする。候補の「毒の場所・悪い声の出所付近の食料の記憶を消す」は見えていない場所にしか効かず、目の前の毒の食料はそのまま食べる。v1の前半の削減は、尽きた場所が多く食料が遠い局面（記憶だけで動く）に限った効果だった。これは候補の設計の欠陥で、[判断0039](0039-taste-aversion.md)で「見えていても採らない」味覚嫌悪を候補に加えて測る。
- 採否と判断者・理由: 未成立（Claude）。閾値は緩めない。世界0.6.0の腐る食料は「避けた場所が枠を占める」欠陥を直す目的で入れ、目的どおり停滞は消えたので、以後のvalence課題の世界として残す。候補はexperimental.1のまま保持（産出側の2つの声の証拠として）、聞き手側を直したexperimental.2を次に測る。
- 限界と次の問い: 腐る食料は世界の都合による単純化で、食料が消える理由（他の動物・季節）は表さない。毒の帰属は食べて分かるだけ。4人・同じモデル。組み合わせ（文法）はない。
