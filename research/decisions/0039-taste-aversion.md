# 0039 / 味覚嫌悪: 見えている毒の食料を採らない候補（valence-v3）

- 状態: ラウンド1終了、**未成立**（候補は両群で7項目中2項目以下）。味覚嫌悪は毒の摂食を全条件で約75%減らすが、それゆえ悪い声の機会が消え、良い声の収束まで崩れた。次は嫌悪の声（[判断0040](0040-disgust-call.md)）。
- 背景: valence-v2（[判断0038](0038-valence-rot.md)）で「避けた毒の場所が枠を占める」世界の欠陥を直しても、候補`valence-0.12.0-experimental.1`の毒の利益は負のままだった（開発−0.32。音があると毒の摂食が**増える**）。原因はコードの読み直しで特定した: 既定の知覚処理（`packages/human/src/index.ts`）は毎ステップ、見えている食料で場所記憶を上書きする。experimental.1の「毒に当たった場所・悪い声の出所付近の食料の記憶を消す」は、見えていない場所にしか効かず、**目の前の毒の食料はそのまま食べる**。良い声が人を食料へ集める効果はそのまま働くので、音ありでは毒の場所にも人が集まり、毒の摂食が増える。v1の前半で見えた回避は、尽きた場所が多く食料が遠い（記憶だけで動く）局面に限った効果だった。
- 候補`valence-aversion-0.12.0-experimental.2`（`packages/human/src/valence.ts`、`decideValence(..., "aversion")`）: 味覚嫌悪（動物で一度の経験から成立することが知られる、食べて具合が悪くなった対象を避ける学習）を初期能力として置く。(1) 毒に当たった直後、自分の位置と3u以内の食料の場所を「嫌悪の場所」として600ステップ覚える。(2) 悪い推定が0.3を超える声を聞いたら、その出所も嫌悪の場所として覚える。(3) 嫌悪の場所の3u以内にある食料は、見えていても採餌対象から外す（場所記憶から消し、その判断に渡す観察からも除く。観察そのものは変えない）。ただし空腹が0.95以上のときは外さない（餓死より毒を選ぶ）。声の産出・良い／悪いの評価・真似・分離・悪い分類の声を追わない規則はexperimental.1と同じ。
- 対照`valence-private-0.12.0-experimental.2`（`"private"`）: (1)と(3)は同じだが、(2)を持たず、聞いた悪い声で場所記憶を消すことも、悪い分類の声を追わないこともしない（良い推定の声は追う）。声は両方出す。候補との差が「聞き手が悪い声を使うこと」の寄与になる。既定・1つの声（`convention-contrast-0.10.0-experimental.2`）・前候補experimental.1も同じシードで走らせる。
- 課題（valence-v3）: 世界はvalence-v2と同一（世界0.6.0、食料は500ステップで腐る、出現2つに1つが毒、初期の1か所が毒、4人）。テストで同一性を確認。
- 評価器・閾値: valence-v1の7項目・同じ閾値。私的嫌悪の対照が毒の利益0.2を達成した場合は、聞き手の悪い声の利用ではなく良い声の誘導の副産物と解釈し、候補が達成しても成立とは呼ばない（protocolの`establishedIf`）。
- 仮説と反証条件:
  - H1: 候補は7項目を両群で達成する。特に毒の利益は0.2以上（悪い声を聞いた個体がその場所を採らないので、音ありで毒の摂食が減る）、毒の種類依存は0.1以上（特徴をでたらめにすると悪い声が働かず、良い声の誘導だけが残る）。
  - H2: 私的嫌悪の対照は区別・収束・任意性を達成するが（産出は候補と同じ）、毒の利益は0.2未満（自分で当たるまで避けない）。前候補experimental.1はv2と同じく毒の利益が負。
  - 反証の主な筋: (a) 候補の毒の利益が0.2未満なら、悪い声を聞く機会（悪い推定>0.3の学習が成立する個体の割合）が少ない可能性があり、`valenceReferents.bad`の学習状況を確認する。(b) 対照も毒の利益を達成すれば、機能は私的な学習で説明され、声の寄与は示せない。(c) 空腹の副作用が悪化すれば（食料を避けすぎる）、嫌悪の期間600か空腹の上限0.95の設定の問題として別に記録する。
- 開発条件・確認条件: 開発74001–74008、確認75001–75008。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence3 --split development --model human-0.2.0 --model convention-contrast-0.10.0-experimental.2 --model valence-0.12.0-experimental.1 --model valence-private-0.12.0-experimental.2 --model valence-aversion-0.12.0-experimental.2 --out outputs/valence-v3-development.json`（確認は`--split validation`）。

  - 悪い声の機会: 毒に当たっているステップ（悪い声の発話）は既定・exp.1で実行あたり136〜185、味覚嫌悪で8〜14。**悪い声は「毒に当たっている間」にしか出ないので、避けられるようになると出なくなる**。後ろ3分の1の悪い声はほとんどのシードでゼロ（収束・区別が0）。
  - 良い声の収束の崩壊: 味覚嫌悪モデルでは良い声の収束も0.145 / 0.040に落ちた（exp.1は0.286 / 0.183）。疑われる原因は誤警報: 学習した悪い推定が良い声の分類（2つの声は0.28ほどしか離れておらず、分類の幅は0.18）に漏れ、良い声を聞いた出所まで避ける。空腹は音なしでも0.45→0.65に悪化し（毒の食料＝食料の半分を避ける費用）、音ありではさらに悪い（誤警報）。でたらめ特徴の条件では死亡が8実行中4件（開発）。
  - 私的嫌悪との差: 毒の摂食も声もほぼ同じ。**聞いた悪い声の利用は測れる差を生まなかった**。
  - 反証の筋(a)が当たった: 悪い声を学ぶ機会（毒に当たる）が味覚嫌悪で消える。声で学ぶ前に自分で学び終わる。
- 採否と判断者・理由: 未成立（Claude）。閾値は緩めない。味覚嫌悪そのものは毒の回避として機能し（既定の4分の1）、聞き手側の欠陥（見えている毒を食べる）を直したことは確かめられたので候補として残す。しかし声の機会が消える設計では悪い声は生まれない。次は悪い声の機会を「毒の場所の食料を見て嫌悪する」状態に広げ、毒の尺度を単位に変える（[判断0040](0040-disgust-call.md)）。
- 限界と次の問い: 嫌悪は場所（座標）に結びつき、食料の種類や見た目には結びつかない（見た目は同じなので区別できない）。同じ位置に後で無毒の食料が現れると600ステップの間は避ける。4人・同じモデル。組み合わせ（文法）はない。
