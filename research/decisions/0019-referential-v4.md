# 0019 / 4人の世界での繰り返しの発見（referential-v4）

- 状態: 実行済み・反証（revise）。到着の3項目のうち種類依存（到着遅れで測る）は全モデル0付近（候補0.017 / 0.009）。ただし、(1) 候補は空腹の副作用を両群で達成し（0.000 / −0.007）、盲目的な対照は未達（−0.106 / −0.118）、(2) 報告のみの「空腹で測った種類依存」は候補だけ両群で正（0.062 / 0.040）、(3) 事後診断で、**候補の64個体（16実行×4人）すべてが食後の声の分類（開き0.7〜0.8・共鳴0.8）を正に、他の分類を負に学んでいた**。種類の利益は「早く着く」ではなく「食料のない声を追わず、群がる費用を避ける」に現れる。コミット88519b6で固定してから実行した。
- 背景: [判断0018](0018-referential-v3.md)の診断2。二人の世界では、空腹で食料を知らない聞き手が聞く声は必ずもう一人のものなので、声の種類が方向に付け加える情報がなく、種類で選ぶ聞き手は追う回数が減る分だけ盲目的な追従より遅くなる。一方で聞き手は食後の声の分類を「食料がある」と正に学んでいた（診断1）。種類で追う相手を選ぶ圧力は、同時に複数の声が別々の場所から聞こえ、そのうち食料にいる声を選ぶ必要がある世界でなければ生じない。
- 変更（課題の世界のみ。モデル・世界0.3.0・評価器の指標定義は0018のまま）: 4人（A(10,14)・B(30,14)・C(20,6)・D(20,22)）。食料は量4（4人分。v3の量2は2人分）を**3か所**から始め、尽きると12か所の列の次に量4が現れる（常に3か所が生きている）。再生なし。実行3000ステップ。パイロット前の追跡: 1か所始まりでは4人のうち1〜4人が餓死し（健康0）、到着遅れが死者の未到着で埋まった。2か所でも死者が残り、3か所で6実行すべてが生存し出現4〜6回になったので3か所にした。3か所が生きていることは、同時に複数の食料の声が別々の場所から聞こえる条件でもある。
- 研究コードの一般化: 到着遅れは「見つけた個体以外の各個体」について平均し（二人なら従来と同一。テストでv3の保存値と一致を確認）、接触・4u未満は「どの対でも起きたステップ」の割合にした。
- 候補と対照: `eating-voice-referent-0.8.0-experimental.3`（候補）、`food-call-referent-0.8.0-experimental.3`（食後の声が音として分かれない対照）、`eating-voice-blind-0.8.0-experimental.2`（種類を使わない対照）、`human-0.2.0`。
- 仮説と反証条件（evaluator: referential-v4。閾値はパイロット後に固定: 到着の短縮≥0.10、方向依存≥0.10、種類依存≥0.05、空腹の副作用≥−0.02。接触は報告のみ、理由はパイロットの項）:
  - H1: 候補が5項目を開発・確認の両群で達成すれば「声の種類を手掛かりに食料へ向かう受け手側の合図利用が成立」と呼ぶ。
  - H2（パイロット後に改訂、候補の実行前）: `eating-voice-blind`（種類を使わない）の種類依存は両群で閾値未満。`food-call-referent`は当初「食後の声が音として分かれないので閾値未満」と予測したが、パイロットで4シードすべて正（0.09〜0.27）だった。状態連動の声（[判断0013](0013-voice-state.md)。空腹が共鳴に漏れる）だけで、食料にいる満腹寄りの個体と探索中の空腹な個体の声が分かれ、4人の世界ではそれが選べる情報になると解釈する。改訂後の予測: **出所評価の2モデルはどちらも種類依存を達成し、食後の声の連動は必要条件ではない**。候補が対照を明確に上回らなければ、連動（0016の工学的仮定）は不要と判断し、より少ない仮定の`food-call-referent`系統を主候補に切り替える。
  - H3（0018と対照的な予測）: 4人では候補の到着の短縮が盲目的な対照を**下回らない**（二人では下回った）。種類で選ぶことが、探索中の声を追って合流する費用を避けるため。
  - 反証: 候補の種類依存がどちらかの群で閾値未満。原因候補: 4人でも食料にいる個体は同時に1〜2人で声の混在が少ない、記憶の窓、分類の粒度、食料が尽きる前に着けない。
- 開発条件・確認条件: 第1ラウンド、開発28001–28008、確認29001–29008。パイロット28101–28104。いずれも未使用。
- 本人に渡さないもの: 条件名、音の意味、正解、介入の有無、相手の内面、食料の出現位置。
- 実行コマンド: `npm run study:referential -- --protocol v4 --split development --model human-0.2.0 --model eating-voice-blind-0.8.0-experimental.2 --model food-call-referent-0.8.0-experimental.3 --model eating-voice-referent-0.8.0-experimental.3 --out outputs/referential-v4-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（28101–28104、候補は含めない。判定に使わない。[結果](../results/referential-v4-pilot.md) / [JSON](../results/referential-v4-pilot.json)）: 3か所始まりで4人とも生存し、見つかった食料は5〜8、出現4〜7。到着の短縮は定位のある2モデルで0.63〜0.65（二人の世界の0.4より大きい: 他の3人が着く）。**種類依存は盲目−0.008、連動なしの出所評価0.176（4シードすべて正）**。接触は定位のある2モデルで−0.06〜−0.11で、4人が半径2uの食料を分け合う以上避けられないため、v4では接触をゲートから外し報告のみにした（副作用のゲートは空腹の平均。盲目は−0.112で未達、出所評価は−0.015で達成）。閾値の固定とH2の改訂はこの観察の後、候補の実行の前。

- 改善と悪化・代替説明: **到着の短縮と方向依存**は定位のある3モデルで両群達成し、二人の世界より大きい（候補0.57/0.51・0.57/0.55、連動なし0.51/0.36・0.52/0.37、盲目0.63/0.62・0.65/0.68）。**到着遅れで測った種類依存**は候補0.017/0.009、連動なし−0.035/−0.140、盲目−0.068/0.005で、パイロットの連動なし0.176（4シード）は再現しなかった（SD 0.16〜0.25）。**診断1（到着遅れは種類に鈍い）**: でたらめ特徴では分類がでたらめになり、出所評価の聞き手は盲目的な追従に近づく。この世界では声を追えば誰かは食料にいるので到着は遅れず、種類の利益は到着には出ない。**診断2（利益は費用の回避に出る）**: 音ありの空腹平均は、盲目0.49に対し候補0.39（音なし0.39と同じ）。候補は到着の利益（0.5以上）を保ちながら、群がる費用を払っていない。でたらめ特徴では候補の空腹が0.45/0.42へ上がる（報告のみの空腹の種類依存0.062/0.040。連動なし0.016/0.006、盲目0.053/−0.001、既定0.007/0.019）。**診断3（全個体が同じ対応を学んだ）**: 候補の`soundReferents`は64個体すべてで食後の声の分類が正（+0.3〜+1.0）、探索中の声の分類が負。連動なしの対照では、共鳴の低い分類（満腹寄り）が正・高い分類（空腹寄り）が負の傾向はあるが弱く、個体ごとにばらつく。状態連動の声だけでも情報はあるが、食べている状態の連動があると分類の境界が明確になる。代替説明「候補が単に追わない」は到着の短縮0.5以上で否定。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録の種類依存（到着遅れ）を達成せず反証（revise）。ただし診断2・3は、種類の利用が別の指標に現れていることを示す。次は、**種類依存を空腹で測る**ゲート（でたらめ特徴 − 音あり ≥ 0.03）を到着の2項目・空腹の副作用と組み合わせ、未使用のシードで登録し直す（referential-v5、[判断0020](0020-referential-v5.md)）。観察済みのシードは再利用しない。今回観察した0.062/0.040は閾値の尺度の参考にのみ使う。
- 限界と次の問い: 食料の出現位置は実験者が固定した列。音源定位に誤差がない。全員同じモデル。食後の声の音響領域は実験者が固定しており、共有音素の創発ではない（全個体が同じ対応を学んだのは、発し手の声が生得的に同じ領域に落ちるからで、慣習の収束ではない）。次: referential-v5で費用回避としての種類依存を事前登録して測る。
