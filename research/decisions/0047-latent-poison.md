# 0047 / 毒の潜伏: 良い声の不在が毒の印にならない世界（valence-v11、所有者の選択）

- 状態: **保留**（候補未実行）。パイロット3回（位置列12→13、潜伏40→15）のいずれでも基準(2)「上限対照の利益1.0回以上」を満たせず、取り決めどおり候補は走らせていない。世界0.7.0（毒の潜伏）と潜伏対応の候補・対照・評価器の変更は残す。次の一手は所有者の判断を待つ（下記）。
- 背景と選択: valence-v10（[判断0046](0046-episode-association.md)）で、良い声は無毒の食料でしか出ないため、豊かな世界では「良い声のする所へ行く」だけで毒を避けられ、悪い声の出番が消えた。所有者は案1「毒の潜伏」を選んだ: 毒の効果を遅らせ、毒の場所でも最初は良い声が出るようにすることで、良い声の不在が印にならなくなり、悪い声が唯一の手掛かりになる。
- 世界の変更（世界0.7.0、`packages/world/src/index.ts`）: `poisonDelay`を任意項目に追加。毒の食料の一口の`poison`効果は、食べたステップではなく`poisonDelay`ステップ後に届く（`WorldState.pendingPoison`に保留）。省略時は従来どおり同じステップ（0.5.0の挙動、既定の世界は不変）。契約は変えない。設定検証は0〜1000の整数。
- 評価器の変更（`research/studies/referential-v1.ts`）: 毒に当たる回数（個体×毒の場所）を「毒の効果が届いた時」ではなく「毒の食料を食べた時」（食料イベントの個体が毒の場所に立っている）に数える。潜伏の無い世界では値は変わらない（テストで確認）。毒の摂食量は届いた効果の合計のまま。
- 候補`valence-assoc-0.12.0-experimental.10`（`decideValence(..., "assoc3")`）: 潜伏に対応した厳密な連合。(1) 最近の食事を「場所・時刻・そのとき出所が3u以内にあった声の分類」として覚える（連続した食事は1件にまとめる）。(2) 毒が届いたら、100ステップ以内の未判定の食事をすべて自分の嫌悪の場所とし、その分類に「毒」を数える（食事の記憶が無ければ現在地）。同じ食事の毒が続いて届いても嫌悪は増やさない。(3) 100ステップ無事に過ぎた食事は分類に「無事」を数える。数え方は訪問1回につき1回（[判断0046](0046-episode-association.md)）。(4) 悪い声の文脈は「嫌悪の場所の食料が見えている」時だけ。毒が届いただけでは（その場が毒の場所とは限らないので）悪い声は出さない。食べている間は良い声（毒の場所でも、毒が届くまでは）。(5) 理解は厳密な連合（毒≧1かつ毒＞無事の分類を警告とし、出所を避け、追わない）。自分の声との照合は使わない（[判断0045](0045-strict-association.md)）。
- 対照: `valence-assoc-private-0.12.0-experimental.10`（同じ産出・嫌悪・連合、聞いた警告を採餌に使わない）、`valence-alarm-ceiling-0.12.0-experimental.10`（同じ潜伏対応の嫌悪と、嫌悪の場所を見た時の生得の警戒声、その音の生得の理解）、既定。従来の味覚嫌悪（experimental.2）は毒が届いた場所を嫌悪するので潜伏の世界では誤った場所を避け、対照として意味を持たないため外す（聞かない対照が「声を使わない味覚嫌悪」の役を兼ねる）。
- 課題（valence-v11）: valence-v10の世界（腐る、量6、9か所、毒2つに1つ）に`poisonDelay`を加え（パイロット1〜2を経て15）、出現位置列を13か所にする（毒の位置が周期ごとに入れ替わる）。40は、一人が量6を食べ尽くす150ステップより短く、仲間が良い声に引かれて集まる（到着遅れの上限300）には十分な長さ。
- パイロット（90101–90104、既定・聞かない対照・上限対照）: (1) 聞かない対照の音なしの非常時3%未満・後ろ3分の1の空腹0.5未満、(2) 上限対照の毒に当たる回数の利益1.0回以上、(3) **聞かない対照の毒に当たる回数の利益が上限対照の半分未満**（良い声の不在が印になっていない目安。v10ではこれが上限対照と同等だった）。満たさなければ再調整。閾値は変えない。
- 閾値: v7〜v10の7項目と対比較1.0回、据え置き。
- 仮説と反証条件:
  - H1（世界）: 潜伏で、毒の場所でも良い声が出て仲間が集まり、聞かない対照は音ありでも毒に当たる（利益が上限対照の半分未満）。上限対照は嫌悪の場所を見た時の警戒声で1.0回以上防ぐ。
  - H2（候補）: 悪い声の機会（嫌悪の場所を見る）が戻り、連合は「毒の場所で良い声を聞いた後に当たった」を学ぶ——ただしこの連合は**良い声の分類を毒と結びつける**危険がある（毒の場所で聞こえるのは良い声だから）。悪い声の分類は嫌悪の場所で聞こえるので、無事の食事では聞かれにくく、毒の側に偏るはず。対比較が1.0回以上になるかは、良い声の分類が「毒＞無事」に傾かない（無毒の食事で多数の無事を積む）ことに依存する。
  - 反証の主な筋: (a) パイロットで上限対照が1.0回に届かない、または聞かない対照が上限対照並みに防ぐ（潜伏が短すぎる）→潜伏を延ばす。(b) 候補の連合が良い声の分類を警告にして無毒の食料を避け、空腹の副作用が悪化する。(c) 悪い声の産出が戻っても区別が0.25に届かない。
- 開発条件・確認条件: 開発90001–90008、確認91001–91008。パイロット90101–90104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence11 --split pilot --model human-0.2.0 --model valence-assoc-private-0.12.0-experimental.10 --model valence-alarm-ceiling-0.12.0-experimental.10 --out outputs/valence-v11-pilot.json`、続いて`--split development` / `--split validation`に`--model valence-assoc-0.12.0-experimental.10`を加えた4モデル。
- パイロット1（90101–90104、位置列12か所、`research/results/valence-v11-pilot1.{json,md}`）: 基準(1)達成（聞かない対照の音なし非常時0.3%、空腹0.27）。**基準(2)不達**: 上限対照の毒に当たる回数の利益−0.75回（音あり1.00 vs 音なし0.25）。音なしでも後ろ3分の1の毒当たりが0.25回しか無く、防ぐ余地そのものが無い。原因は世界の規則性: 出現位置列12か所に毒2つに1つを重ねると、位置 p は常に毒か常に無毒（12が2で割り切れる）。味覚嫌悪を持つ集団は前3分の2で毒の位置を全部覚え、後ろ3分の1には当たらない。潜伏の効果（聞かない対照の実行全体の毒当たりは音なし5.75→音あり3.50と、v10の9.63→5.13より差が縮んだ）は出ている。世界を再調整: 位置列を13か所（(26,26)を追加）にして、2と互いに素にする——同じ位置が周期ごとに毒と無毒を入れ替わり、場所の記憶だけでは避けられなくなる。パイロット2は新しいシード90111–90114。
- パイロット2（90111–90114、位置列13・潜伏40、`research/results/valence-v11-pilot2.{json,md}`）: 余地は戻った——音なしの後ろ3分の1の毒当たり18.25回（位置が入れ替わるので場所の記憶では避けられない。既定は8.25回で、味覚嫌悪の集団のほうが多く当たる: 100ステップ以内の食事をすべて嫌悪する過剰般化で無毒の場所まで避け、知らない場所へ向かうため）。しかし**基準(2)不達**: 上限対照の利益−0.75回、音ありの空腹0.52（音なし0.32）。潜伏40の間に、良い声に引かれた仲間が到着して食べ終える（毒当たりの種類: 警告なし54件、警告後20件、最初40件）。警告は最初の食べ手が毒を知ってからしか出ず、間に合わない。基準(3)は聞かない対照1.75回 vs 上限対照−0.75回で意味を持たない。世界を再調整: 潜伏を40→**15**に短縮（良い声の不在が印になる時間は15ステップだけ消え、仲間の到着より短い）。位置列13は維持。パイロット3は新しいシード90121–90124。
- パイロット3（90121–90124、位置列13・潜伏15、`research/results/valence-v11-pilot3.{json,md}`）: **基準(2)不達**。上限対照の利益−2.0回（音あり19.75 vs 音なし17.75）、音ありの空腹0.56（音なし0.37）、警告後の毒当たり36件。位置が周期ごとに入れ替わる世界では、「警告を聞いた場所を600ステップ避ける」という応答そのものが裏目に出る: 無毒に戻った場所を避けて飢え、知らない場所へ向かって毒の最初の一口を食べる。聞かない対照の利益は1.0回（シード別4,8,−2,−6）で揺れが大きく、基準(3)も判定できない。
- パイロット3回の総括: 毒の潜伏は「良い声の不在が毒の印になる」効果を弱めた（聞かない対照の音あり／音なしの毒当たりの差はv10の9.6→5.1からv11の28→26へ縮小）が、完全な生得の警戒声を持つ上限対照が後ろ3分の1の毒当たりを1.0回以上減らす世界は、3回の調整（位置列12→13、潜伏40→15）のどれでも作れなかった。理由は二つで、互いに排他的: (a) 毒の位置が固定なら場所の記憶だけで足り、後ろ3分の1に防ぐ余地が無い（パイロット1）。(b) 毒の位置が入れ替わるなら、警告への唯一の応答である「場所を避ける」が期限（600ステップ）の間に裏目に出、しかも最初の食べ手が知る前に良い声で集まった仲間は間に合わない（パイロット2・3）。**警告が価値を持つには、警告が「その場所の今の状態」を伝え、聞き手がそれを場所の記憶より優先できる必要がある**が、今の個体には「今」を表す手段（例: 警告の鮮度で嫌悪の期限を決める、警告が止んだら戻る）が無い。
