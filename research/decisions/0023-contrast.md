# 0023 / 食料の声を食べていない時には避ける（対比）と、慣習的な合図の成立

- 状態: 実行済み・**未成立だが4項目は両群達成**（revise）。候補は確認群で5項目すべてを達成し、開発群では空腹の副作用（−0.043）だけを外した。収束の利得0.196 / 0.167、任意性0.184 / 0.126、**空腹の種類依存0.045 / 0.063**（対比なしは0.013 / −0.006）、到着の短縮0.446 / 0.419。対比なしの0022候補は収束・任意性を再現し（0.178 / 0.150、0.128 / 0.159）、種類依存は達成しない（H2どおり）。コミットb12ea62で固定してから実行した。
- 背景: [判断0022](0022-convention.md)で、真似によって任意の食後の声が集団ごとに共有される現象が両群で成立した。しかし聞き手がその声を食料の手掛かりに使う3項目は開発群でしか達成しなかった。診断: 慣習の声は既存の目録から選ばれるので、食べていない個体も同じ分類の声を出し、出所評価が正負に混ざる。言語の語が機能するには、形が場面に**対比的に**割り当てられる必要がある（食料の声は食料でだけ出す）。
- 候補`convention-contrast-0.10.0-experimental.2`: 0022の候補に一つだけ足す。食べていない時に声を出すなら、自分の産出目録のうち食料の声から0.25以上離れた最も遠い分類の形を出す（なければ既定の声）。食べている時は0022と同じく食料の声を真似る。与えないもの: 意味、正解、相手の内面、共有の目録。
- 対照: `convention-0.10.0-experimental.1`（対比なし。同じ第2ラウンドのシードで再実行し、0022の結果が再現するかも見る）、`convention-no-imitation`、`eating-voice-referent`、`human-0.2.0`。
- 仮説と反証条件（evaluator: convention-v1、ゲート不変: 収束の利得≥0.12、任意性≥0.08、空腹の種類依存≥0.03、到着の短縮≥0.10、副作用≥−0.02）:
  - H1: 候補が5項目を開発・確認の両群で達成すれば「経験と真似だけで、任意の食後の声が個体間で共有され、聞き手がそれを食料の手掛かりに使う（慣習的な合図の最小形）」と呼ぶ。
  - H2: 対比なしの0022候補は収束・任意性を再現するが、種類依存は両群では達成しない（0022の再現）。
  - H3（報告のみ）: 候補の食後の声の散らばりは対比なしより小さくならない（対比は収束を邪魔しない）。
  - 反証: 候補の種類依存がどちらかの群で0.03未満。原因候補: 避ける先の音が別の個体の食料の声と重なる、産出目録が小さく避けられない、収束前の初期に混ざった出所評価が残る。
- 開発条件・確認条件: 第2ラウンド、開発40001–40008、確認41001–41008。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol convention --round 2 --split development --model human-0.2.0 --model convention-0.10.0-experimental.1 --model convention-contrast-0.10.0-experimental.2 --out outputs/convention-v1-round2-development.json`（確認は`--split validation`）。
- 結果ファイル・ハッシュ: [開発](../results/convention-v1-round2-development.md) / [JSON](../results/convention-v1-round2-development.json)、[確認](../results/convention-v1-round2-validation.md) / [JSON](../results/convention-v1-round2-validation.json)。ソースb12ea62（未コミット変更なし）。開発40001–40008・確認41001–41008は観察済み。
- 改善と悪化・代替説明: 対比を足すと種類依存が両群で閾値を越えた（0.013→0.045、−0.006→0.063）。食料の声を食べていない時に避けることで、その声の出所評価が正に揃い、聞き手が使えるようになったと解釈できる。収束はむしろ強まった（散らばり0.05〜0.10）。**空腹の副作用**は開発群で8シード中7シードが負（−0.043±0.032）、確認群では+0.008。音ありの空腹平均は開発0.44前後 vs 音なし0.40、確認0.394 vs 0.402。**診断（判定には使わない）**: 慣習の声は生得の声と違って実行の初めには存在せず、収束と出所評価が育つまで（数百ステップ）聞き手は曖昧な声を追って群がる。空腹平均は全実行の平均なので、この形成期の費用を含む。対比なしの候補では副作用が両群で−0.06〜−0.08とさらに大きく、対比が費用を半減させている。**代替説明**「対比の声が別の個体の食料の声と重なる」は、収束の利得が対比で下がらないことから主因ではない。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。5項目の呼称は与えず未成立（revise）。ただし慣習の形成に時間がかかる以上、「形成後に機能するか」を測るには空腹の指標を実行の後ろ3分の1で取るのが筋である。閾値は変えず、指標の窓を後ろ3分の1に限る評価器convention-v2を、未使用シードで登録して測る（判断0024）。観察済みシードは再利用しない。
- 限界と次の問い: 4人・同じモデル。共有される音は1つで指示対象は食料だけ。対比の相手は「食料でない時」の総称で、第2の語ではない。語・文法・意図の再現ではない。次: 形成後の窓で測るconvention-v2（判断0024）。
