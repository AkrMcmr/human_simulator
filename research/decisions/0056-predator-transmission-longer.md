# 0056 / 新参者の学習時間を2倍にする（predator-transmission-v2、所有者の選択）

- 状態: 登録（prospective）。protocolとテストをコミットし、未使用シード（104001–104008 / 105001–105008）で4モデル（既定、候補、対照、上限対照）を測る。パイロットは省く（世界・対照・上限対照はv1と同一で、上限対照の新参者の余地は確認済み）。
- 背景と選択: predator-transmission-v1（[判断0055](0055-predator-transmission.md)）で、食料の声は新参者に伝わった（採用率の利得0.343 / 0.348）が、危険の声は在来者の声が半径0.15に集まらず伝わらず（−0.047 / 0.127）、新参者の理解は0.25 / 0.25回（閾値0.5）だった。新参者が到着後に受ける襲撃は5〜6回で、「6u以内の声の直後に自分が危険に遭う」経験が的中2回に届きにくい。所有者は選択肢(b)「新参者の学習時間を延ばす（6000ステップ）」を選んだ。世界の再調整はしない。
- 変更: 全体を7500ステップにし、1500ステップ目の入れ替え後に新参者が6000ステップ（v1の2倍）を生きる。後ろ3分の1（5000〜7500）で在来者の声と新参者の採用率・空腹を測る。新参者の襲撃は到着後の全期間で数える。モデル・世界・ゲート・閾値はv1と同一。
- 仮説と反証条件:
  - H3'（新参者の理解）: 新参者の経験（自分の危険）が2倍になれば、対比較「新参者の理解」（聞かない対照 − 候補の新参者の襲撃、音あり、到着後）が0.5回以上を両群で達成する。閾値は新参者の生存期間が2倍になっても据え置く（寄与の絶対数が増える方向なので緩和ではない）。
  - H2'（採用）: 在来者の危険の声が集まる時間も2倍になる。危険の声の採用率の利得0.3以上、食料の声0.3以上を両群で。
  - H1（在来者の2語）: 収束0.12・0.12、区別0.25を両群で。
  - 反証の主な筋: (a) 時間を延ばしても在来者の危険の声の散らばりが0.15を超えたまま（収束の不安定は時間ではなく構造）。(b) 新参者の理解は増えるが、警告で逃げる費用（空腹）も増えて新参者の空腹の副作用（−0.02）が未達のまま。(c) 襲撃が累積して健康が尽きる（死亡が実行の半数以上なら世界の前提が崩れる——その場合は記録して止める）。
