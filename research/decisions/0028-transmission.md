# 0028 / 慣習的な合図は新参者に伝わるか（transmission-v1）

- 状態: 実行済み・反証（revise、ただし指標の欠陥を発見）。候補は在来の収束（0.141 / 0.168）、新参者の副作用（+0.185 / +0.142: 新参者の空腹は音あり0.28 vs 音なし0.44）、新参者の種類依存（0.229 / 0.076）を両群で達成したが、**採用の利得は−0.050 / −0.026で未達**、在来の任意性も確認群で0.065と閾値を下回った。採用の指標に欠陥があった（下記）。コミット0f87703で固定してから実行した。
- 背景: [判断0024](0024-convention-v2.md)で、任意の食料の声が集団ごとに共有され、形成後に機能する慣習的な合図の最小形が成立した。第2の指示対象は3ラウンドで未成立（[判断0027](0027-scarce-warmth.md)）。言語の慣習は、それを作った個体だけのものではなく、**新しく加わる個体が教えられずに身につけ、使える**ことで世代を越える。これは語彙の数とは独立に測れる、言語らしさの中心的な性質である。
- 介入（観察者側。人間には知らされない）: convention-v2の世界で、1500ステップ目に個体Dを、同じ場所にいる何も知らない個体（初期状態）に入れ替える。Dの記憶・目録・出所評価はすべて失われる。在来の3人はそのまま。
- 評価器の追加: 後ろ3分の1（2000〜3000ステップ）で、新参者の食料の声の重心と在来3人の食料の声の重心の距離（新参者の距離）、新参者だけの空腹平均。在来の収束・任意性は在来3人の声で計算する。
  - 採用の利得 = 音なしの距離 − 音ありの距離（聞けるときだけ在来の声に近づく＝真似による採用）。
  - 新参者の副作用 = 音なし − 音あり の新参者の空腹（聞けることで損をしない）。
  - 新参者の種類依存 = でたらめ特徴 − 音あり の新参者の空腹（声の種類が新参者の役に立っている）。
- 候補と対照: `convention-contrast-0.10.0-experimental.2`（候補）。対照: `eating-voice-referent`（生得の声。新参者も生まれつき同じ声なので、採用の利得は0付近——学習による採用の帰無）、`convention-no-imitation`（真似なし。採用なし）、`human-0.2.0`。
- 仮説と反証条件（閾値はパイロット後に固定: 在来の収束0.12・任意性0.08、採用の利得0.1、新参者の副作用−0.02、新参者の種類依存0.03）:
  - H1: 候補が5項目を両群で達成すれば「集団の任意の食料の声は、何も知らない新参者に、教えなくても経験と真似だけで伝わり、新参者はそれで得をする（慣習的な合図の伝達）」と呼ぶ。
  - H2: 生得の声は採用の利得が0付近（音なしでも同じ声）。真似なしは採用の利得が0付近。
  - 反証の主な筋: (a) 新参者が1500ステップでは在来の声を学びきれない（採用の利得が小さい）。(b) 採用しても新参者の空腹が改善しない。(c) 新参者の参入で在来の収束が崩れる（在来の収束の利得が0.12未満）。
- 開発条件・確認条件: 開発50001–50008、確認51001–51008。パイロット50101–50104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol transmission --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model convention-no-imitation-0.10.0-experimental.1 --model convention-contrast-0.10.0-experimental.2 --out outputs/transmission-v1-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（50101–50104、候補は含めない。[結果](../results/transmission-v1-pilot.md) / [JSON](../results/transmission-v1-pilot.json)）: 採用の利得は生得の声0.003、真似なし0.003（最大0.049）で0付近。新参者は声の方向だけで得をする（副作用の帰無は+0.09〜+0.12）。種類依存の帰無は0付近か負。暫定の閾値をそのまま固定した。閾値の固定は候補の実行の前。
- 結果ファイル・ハッシュ: [開発](../results/transmission-v1-development.md) / [JSON](../results/transmission-v1-development.json)、[確認](../results/transmission-v1-validation.md) / [JSON](../results/transmission-v1-validation.json)。ソース0f87703（未コミット変更なし）。開発50001–50008・確認51001–51008は観察済み。
- 改善と悪化・代替説明: **新参者は声を使えている**: 候補の新参者の後ろ3分の1の空腹は音あり0.277 / 0.278、音なし0.462 / 0.420、でたらめ特徴0.506 / 0.354。方向だけでなく種類が新参者の役に立っている（生得の声でも同様に得をするが、それは生得の種類）。**採用の指標の欠陥**: 「音なしの距離 − 音ありの距離」は、音なし条件では在来の声も収束せず、在来の重心も新参者の重心も目録の平均（中央付近）に落ちるため距離が偶然小さく（0.03〜0.1）、音あり条件で在来が任意の点に収束すると、採用しない新参者の距離は大きくなる。つまり指標は採用に対して逆向きに偏る。生の値を見ると、音あり条件で新参者の距離が在来の散らばり（0.05〜0.13）の内側にあるシードは16のうち9で、残りは0.10〜0.35。1500ステップで採用が起きるシードと起きないシードがある。**代替説明**「新参者が声を出していない」は、新参者の食後の声の回数（後ろ3分の1で20〜50回）から否定。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。事前登録のゲートで未成立（revise）。新参者の理解（声の種類で得をする）は両群で示されたが、産出の採用の指標が偏っていたので、採用を**音あり条件の在来の声を基準にした割合**で測り直す: 新参者の後ろ3分の1の食料の声のうち在来の重心から0.15以内の割合を、音ありの新参者と、聞けない（音なし）新参者の声について同じ基準で比べる（判断0029、transmission-v2）。閾値は新しい世界ではないので観察済みの帰無（生得・真似なし）は流用せず、未使用シードでパイロットを行う。
- 限界と次の問い: 新参者は1人、入れ替えは1回。世代の連鎖（何度も入れ替える）は次。語・文法・意図の再現ではない。
