# 0051 / 逃げながら叫ぶ: 危険の声を逃走の1手に乗せる候補（predator-v3、所有者の選択）

- 状態: 登録（prospective）。世界0.10.0、候補・対照・上限対照（experimental.3）、protocol predator-v3、テストをコミットし、パイロット（既定・聞かない対照・上限対照、96101–96104）で上限対照の余地と叫びの回数を確認してから、未使用シード（96001–96008 / 97001–97008）で4モデルを測る。
- 背景と選択: predator-v2（[判断0050](0050-threat-warning.md)）のパイロット7回で、世界は「生得の警戒声なら襲撃を3.5回減らせる」水準（追跡0.75、噛んだ個体を300ステップ無視、protocol 1.6.0）に達したが、候補群は脅威を見ると「離れる」（逃走の効用1.6×危険度）が「声を出す」（食料の声と同じ効用）に常に勝ち、危険の声を実行あたり4回未満しか出さなかった（既定は32回: 逃げないので声が出る）。所有者は選択肢1「候補側を直す新しい仮説『逃げながら叫ぶ』を登録する」を選んだ。
- 世界0.10.0（`packages/world/src/index.ts`）: どの行動でも`sound`が付いていれば発声として周囲に届く（労作+0.15も同じ）。契約0.3.0の`ActionIntent.sound`は元々どの行動にも付けられる。既定モデルは発声行動にしか音を付けないので挙動不変（テストで保存結果と一致）。
- 候補`threat-cry-0.13.0-experimental.3`（`packages/human/src/threat.ts`、`decideThreat(..., cry = true)`）: experimental.2と同じ知覚・声の選び方・厳密な連合に、一つだけ加える——脅威が見えていて発声の衝動がある時（10ステップに1回）、選んだ行動が発声でなければ、その行動に危険の声を乗せる（逃げながら叫ぶ）。叫びの形は文脈の声（脅威を見ている時に聞いた声の真似、食料の声から分離）、無ければ自分の音か新しい音で、核の発声と同じ弱い状態連動（0.2）と運動の揺らぎ（±0.035）を通す。叫びは自分の産出した音として記憶される（真似と対比の材料）。発声の衝動を行動の候補として競わせる項（callUrge）は外した。対照`threat-cry-deaf-…`は同じ叫びで聞いた警告に動かない。上限対照`threat-cry-alarm-ceiling-…`は逃げながら固定の警戒声を叫び（生得の反射の形なので状態連動を通さず揺らぎだけ。experimental.2の上限対照は核の発声経路で状態連動0.2を通していたため、脅威が見えて危険度が高いと警戒声が自分の半径0.18の外に出ていた——パイロット7までの上限対照の余地は過小評価の可能性がある）、その音（自分の食料の声より警戒声に近い音）を聞けば出所から離れる。
- 評価器（`research/studies/referential-v1.ts`）: 発声の数え方を「発声行動」から「音の付いた行動」に広げた（旧モデルでは同値）。危険の声の収束・任意性・区別は叫びの形から測る。
- 仮説と反証条件:
  - H1（産出）: 逃走に乗せることで危険の声が実行あたり10回以上出て、食料の声と同じ機構で集まり（収束0.12以上）、食料の声から離れる（区別0.25以上）。
  - H2（理解）: 対比較「聞き手の寄与」（聞かない対照 − 候補の襲撃、音あり、実行全体）が1.0回以上。閾値はpredator-v2パイロット7の上限対照の固有の余地（上限対照 − 聞かない対照 = 1.0回）に等しく、帰無（食料の声で動く場所が変わる副産物2.5回）は対で相殺される。パイロット前に固定し、パイロットで変えない。
  - 反証の主な筋: (a) 上限対照でも余地が2.0回未満（叫んでも間に合わない）→世界の再調整はせず保留。(b) 叫びは出るが集まらない（見えている時間が短く真似の機会が少ない）。(c) 連合が食料の声を警告にして誤警報で空腹が悪化（forage-benefit −0.02未満）。
- パイロット（96101–96104、既定・聞かない対照・上限対照）の基準: (1) 対比較「上限対照の余地」（聞かない対照 − 上限対照、音あり、実行全体）2.0回以上、(2) 聞かない対照の危険の声が実行あたり10回以上、(3) 非常時3%未満・死亡が実行の半数未満。候補は走らせない。パイロットは1回（世界の再調整はしない）。
- 開発条件・確認条件: 開発96001–96008、確認97001–97008。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol predator3 --split pilot --model human-0.2.0 --model threat-cry-deaf-0.13.0-experimental.3 --model threat-cry-alarm-ceiling-0.13.0-experimental.3 --out outputs/predator-v3-pilot.json`、続いて`--split development` / `--split validation`に`--model threat-cry-0.13.0-experimental.3`を加えた4モデル。
- 主張しないこと: 捕食者は決まった規則で動き、意図も学習もない。叫びは生得の反射の型（脅威が見えると声が出る）で、意味・正解は与えない。語・文法・意図の再現ではない。
- パイロットで見えたこと: 実行後に追記。
