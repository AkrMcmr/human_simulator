# 0043 / 産出による理解と、飢えを減らした世界（valence-v7）

- 状態: ラウンド1終了、**未成立**。世界は確定し上限対照は両群で毒に当たる回数を1.75 / 2.0回減らした（余地あり）が、候補experimental.6は産出側まで崩れた。原因は実装の欠陥（状態連動後の音を自分の声として再利用する縮小写像）で、修正版を[判断0044](0044-mirror-corrected.md)で測る。
- 背景: valence-v6の診断（[判断0042](0042-ceiling-and-paired.md)）は失敗の原因を二つに分けた。(1) 上限対照（生得の警戒声・生得の理解）が警告後に毒を食べた7件はすべて**空腹0.95以上の非常時上書き**——非常時は全個体・全時刻の11〜15%で、この世界は味覚嫌悪の集団にまだ厳しい。(2) 候補（間隔10の嫌悪の声）が警告後に毒を食べた12件のうち9件は**理解の不成立**——聞いた声を自分の「悪い声の分類」と照合するが、その分類は「毒・嫌悪の状態で聞いた声」から作られるため、一人で毒に当たる個体には長く存在しない。声は出しているのに、その声が何を意味するか自分でも知らない状態。
- 候補`valence-mirror-0.12.0-experimental.6`（`packages/human/src/valence.ts`、`decideValence(..., "mirror")`）: experimental.5（味覚嫌悪、控えた嫌悪の声、間隔10）に「産出による理解」を加える。(1) 良い文脈・悪い文脈で自分が実際に出した声の形を`ownVoices`として覚える。(2) 真似の元（聞いた声の評価）が無いときはその自分の声を再び出す——最初の声は任意だが、以後は文脈ごとに一貫する。(3) 聞いた声が自分の悪い声から0.18以内で、かつ自分の良い声より近ければ警告として出所を避ける（experimental.5の規則も残す）。意味は自分の産出から、共有は真似から来る。声の形そのものに生得の意味は与えない（上限対照との違い）。
- 対照`valence-mirror-private-0.12.0-experimental.6`（`"mirror-private"`）: 同じ産出だが聞いた悪い声を採餌に使わない。上限対照`valence-alarm-ceiling-0.12.0-experimental.5`（世界の余地）、味覚嫌悪`valence-aversion-0.12.0-experimental.2`（声なしの回避）、既定も走らせる。
- 世界（valence-v7）: valence-v5/v6の世界で食料の量を4→6にし（初期の場所と現れる食料の両方）、パイロット1〜3の結果を受けて同時に生きている食料の場所を3→7にする（初期にfood-4〜food-7を追加。腐ると同じ位置列から次が現れるので、生きている枠が5になる）。目的は非常時を減らすこと。
- 評価器の追加: 非常時の割合`desperateFraction`（生きている個体・時刻のうち空腹0.95以上の割合）を報告。毒当たりの種類（[判断0042](0042-ceiling-and-paired.md)の診断）も報告に含める。
- パイロット（82101–82104、既定・味覚嫌悪・上限対照。候補と聞かない対照は走らせない）: (1) 味覚嫌悪系の音なしの非常時割合3%未満・後ろ3分の1の空腹0.5未満、(2) **上限対照の毒に当たる回数の利益1.0回以上**。(2)を満たさなければ世界に余地がないので候補を測らず、世界を再調整して再登録する。閾値は変えない。
- 閾値: v5/v6の7項目、対比較「聞き手の寄与」1.0回。成立は7項目と対比較を両群で達成すること。
- 仮説と反証条件:
  - H1（世界）: 食料6で非常時は3%未満に下がり、上限対照の毒に当たる回数の利益は1.0回以上になる（v6の警告後19件の大半が防がれる）。
  - H2（候補）: 産出による理解で、警告を聞いた後の毒当たりが減り、対比較（聞かない対照 − 候補）が1.0回以上。産出側4項目はv6と同様に両群で達成。
  - H3: 聞かない対照は産出4項目を達成し、対比較の定義上、候補との差だけが聞き手の寄与になる。
  - 反証の主な筋: (a) 上限対照が1.0回に届かない→世界の再調整。(b) 上限対照は届くが候補の対比較が0付近→自分の悪い声と他人の悪い声が0.18以内に揃わない（真似の収束が理解に足りない）か、良い声と悪い声が近すぎて区別できない。毒当たりの種類の「警告後・嫌悪の記憶なし」の件数で判別する。(c) 空腹の副作用の悪化→誤警報。
- 開発条件・確認条件: 開発82001–82008、確認83001–83008。パイロット82101–82104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence7 --split pilot --model human-0.2.0 --model valence-aversion-0.12.0-experimental.2 --model valence-alarm-ceiling-0.12.0-experimental.5 --out outputs/valence-v7-pilot.json`、続いて`--split development` / `--split validation`に`--model valence-mirror-private-0.12.0-experimental.6 --model valence-mirror-0.12.0-experimental.6`を加えた5モデル。
- パイロット1（82101–82104、食料の量6・3か所、`research/results/valence-v7-pilot1.{json,md}`）: **基準(1)不達**。非常時割合は音なしで味覚嫌悪0.20・上限対照0.21（v6の世界の0.11〜0.15より高い）、既定でも0.08〜0.10。後ろ3分の1の空腹は0.54〜0.58。量を増やしても飢えは減らない——飢えは食料の量ではなく、**食料が見つからない時間**（視界5uで3か所しか無い）から来る。基準(2)は達成: 上限対照の毒に当たる回数の利益1.75回（シード別0,0,1,6。1シードに偏る）、警告後の毒当たり11件はなお非常時。取り決めどおり候補は走らせず、世界を再調整: 生きている食料の場所を3→5（初期にfood-4 (10,26)・food-5 (30,3) を追加、量6は維持）。パイロット2は新しいシード82111–82114で行う。
- パイロット2（82111–82114、量6・5か所、`research/results/valence-v7-pilot2.{json,md}`）: 非常時は既定2.4〜3.2%、味覚嫌悪の音なし6.2%、後ろ3分の1の空腹0.35（基準(1)の3%にわずかに不達、空腹は達成）。**上限対照は音ありで悪化**: 毒に当たる回数の利益−1.5、空腹0.60（音なし0.39）、非常時12.8%。警告後の毒当たり14件は非常時が原因で、その非常時は誤警報——自分の集団の良い声が警戒声の形（開き0.1・共鳴0.1）から0.18以内に来ると警告と誤認し、無毒の食料も避けて飢える——で作られている。計測器（上限対照）の欠陥として、聞いた音が自分の良い声より警戒声に近いときだけ警告とする保護を加えた（候補の「産出による理解」と同じ形の保護）。世界は生きている食料の場所を6（food-6 (36,13) を追加）にして、パイロット3を新しいシード82121–82124で行う。
- パイロット3（82121–82124、量6・6か所・保護つき上限対照、`research/results/valence-v7-pilot3.{json,md}`）: **基準(2)達成**——上限対照の毒に当たる回数の利益2.0回（シード別−1,2,5,2。音あり2.5 vs 音なし4.5）、種類依存5.5回、空腹の副作用−0.02、警告後の毒当たりは23件中6件に減った。保護は誤警報を止めた（でたらめ特徴の条件では依然34件の警告なし毒当たりと空腹0.68——でたらめな音が警戒声に当たる誤警報は保護の外）。**基準(1)不達**——非常時は既定0.7〜1.6%、味覚嫌悪の音なし6.2%（音あり2.5%）、後ろ3分の1の空腹0.43。取り決めどおり基準は緩めず、生きている食料の場所を7（food-7 (4,14) を追加）にしてパイロット4を新しいシード82131–82134で行う。
- パイロット4（82131–82134、量6・7か所、`research/results/valence-v7-pilot.{json,md}`）: **両基準達成**。非常時は既定0.0〜0.2%、味覚嫌悪の音なし2.0%（シード別1.5, 0.1, 2.6, 4.0%）、後ろ3分の1の空腹0.34。上限対照の毒に当たる回数の利益1.5回（シード別2,1,1,2。音あり3.25 vs 音なし4.75）、種類依存1.0回。上限対照の空腹の副作用は−0.18（警告で場所を避ける費用と、でたらめ特徴での誤警報）。世界を確定し、候補と聞かない対照を含む5モデルで開発・確認群を測る。

  - 世界: 非常時は既定0.1〜0.6%、味覚嫌悪系1〜2%、餓死0。上限対照は両群で1.75 / 2.0回（音あり1.6 / 1.3 vs 音なし3.4 / 3.3）を達成し、**この世界には声で防げる毒の余地がある**ことが確定した。
  - 候補experimental.6の崩壊: 音なしでも声の散らばりが0.10（他モデル0.26）で、良い声と悪い声が重なる（区別0.12 / 0.17）。原因はコードの読み直しで特定——自分の声として状態連動**後**の音を記録し、次にそれを土台に再び状態連動をかける反復は縮小写像で、全個体・両文脈の声が一点に収束する。良い声と悪い声が重なった状態で「自分の悪い声に近い音」を警告と判定するので誤警報が多く、空腹の副作用−0.16 / −0.14、対比較−2.0 / −0.1。聞かない対照も同じ産出の欠陥で産出4項目を落とした。
  - 副次的な観察: この世界では味覚嫌悪（声を採餌に使わない）でも毒に当たる回数の利益が0.6 / 1.4回出る。良い声は無毒の食料でしか出ないため、良い声に集まるだけで毒の場所を相対的に避ける。音なし対音ありの毒の利益は「悪い声の理解」の証拠にならず、対比較（聞かない対照との差）だけが証拠になる。
- 採否と判断者・理由: 未成立（Claude）。世界（量6・7か所）は以後のvalence課題の基準として確定。experimental.6は実装の欠陥として記録し、自分の声を状態連動の前の形で覚え悪い声を良い声から離す修正版experimental.7を、同じ世界・新しいシードで測る（[判断0044](0044-mirror-corrected.md)）。
- 限界と次の問い: 自分の声と他人の声の照合半径0.18は聴覚分類の幅と同じ設計値。非常時上書き0.95は残す（飢えた個体が毒を選ぶのは合理的で、外すと餓死が増える）。4人・同じモデル。組み合わせ（文法）はない。
