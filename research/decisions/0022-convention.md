# 0022 / 経験と真似だけで、任意の食後の声は共有されるか（convention-v1）

- 状態: 実行済み・**慣習の2項目は両群で成立、聞き手の利用は開発群のみ達成（全体としては未成立、revise）**。候補の収束の利得は0.145 / 0.182、任意性は0.127 / 0.148で、どちらも両群で閾値を越えた。対照はどちらも越えない（生得の声: 収束の利得−0.003 / −0.006・任意性0.007 / 0.010。真似なし: 0.057 / 0.046・0.029 / 0.044）。聞き手の利用（種類依存・到着・副作用）は開発群で3項目達成（0.048・0.580・−0.007）、確認群で種類依存−0.045・副作用−0.028が未達。事前登録の呼称（5項目）は与えない。ただしprotocolの定義（収束と任意性のどちらかが未達なら慣習と呼ばない）に照らし、**「経験と真似だけで、任意の食後の声が個体間で共有される」現象そのものは両群で成立**したと記す。コミットd78c3a2で固定してから実行した。
- 背景: [判断0020](0020-referential-v5.md)で、聞き手が声の種類を食料の手掛かりに使うことが成立した。しかしその声（開き0.9・共鳴0.9付近）は「食べている状態が声に漏れる」という**生得の音響領域**で決まっており、慣習ではない。[判断0021](0021-caller-cost.md)で、発し手が費用を学んでも状態の漏れは消えないことも分かった。言語の核心である**任意性**（どの音でもよく、集団で共有されるから通じる）に進むには、生得の領域を外し、発し手が経験と真似で音を選ぶ必要がある。
- 候補`convention-0.10.0-experimental.1`（発し手側の変更。聞き手は0.8.0-experimental.3の出所評価のまま）:
  - 生得の食後の声（eatingCoupling）を持たない。状態連動は0.2に弱める（候補レベルの仮定。強いと収束先が状態で決まり任意性が測れない）。
  - 食べている時に声を出したくなる傾向（+0.45）は残す。
  - 食べている時に聞いた声を分類ごとに数える（`eatingHeard`）。
  - 食べている時に声を出すなら、聞いた分類のうち「出所に食料があった推定（soundReferents）＋ 0.5×食べている時に聞いた割合」が最大で0.05を超えるものの形を**真似て**出す。なければ既定の声。
  - 与えないもの: 共有の目録、意味、正解、相手の内面。真似の元は本人が聞いた音だけ。
- 対照: `convention-no-imitation`（同じ弱い連動・同じ聞き手、真似なし。収束に真似が必要かを示す）、`eating-voice-referent`（生得の声。収束はするが任意性がないはず）、`human-0.2.0`。
- 評価器（convention-v1、世界はreferential-v5と同一）: 実行の後ろ3分の1に食べている状態で出した声の重心を個体ごとに取り、
  - 収束の利得 = 音なしの散らばり − 音ありの散らばり。散らばりは全員の食後の声を合わせた重心からの平均距離（聞き合えるときだけ一つの声に集まる）。最初のパイロットでは個体ごとの重心の個体間距離で測ったが、真似なしでも各個体の重心が自分の目録の平均に寄って広がりが小さく出る（0.06〜0.14）ため、候補を走らせる前にこの定義へ変えた。
  - 任意性 = 各シードの音あり重心の、全シード平均重心からの距離の平均（収束先がシードごとに違う）。
  - 空腹の種類依存・到着の短縮・空腹の副作用はreferential-v5と同じ（聞き手が使えているか）。
- 仮説と反証条件（閾値はパイロット後に固定: 収束の利得≥0.12、任意性≥0.08、種類依存≥0.03、到着の短縮≥0.10、副作用≥−0.02）:
  - H1: 候補が5項目を両群で達成すれば「経験と真似だけで、任意の食後の声が個体間で共有され、聞き手がそれを食料の手掛かりに使う（慣習的な合図の最小形）」と呼ぶ。
  - H2: 生得の声は任意性が0付近（常に同じ領域）。真似なしは収束の利得が0付近。
  - 反証の主な筋: (a) 収束しない（真似の正の帰還が弱い、各個体の初期の声がばらばらで「食べている時に聞いた声」が一致しない）。(b) 収束するが任意性がない（弱い状態連動0.2でも収束先が満腹寄りの領域に引かれる）。(c) 収束しても聞き手が使えない（種類依存未達）。それぞれ次の設計を分ける。
- 開発条件・確認条件: 開発38001–38008、確認39001–39008。パイロット38101–38104。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol convention --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model convention-no-imitation-0.10.0-experimental.1 --model convention-0.10.0-experimental.1 --out outputs/convention-v1-development.json`（確認は`--split validation`）。
- パイロットで見えたこと（38101–38104、候補は含めない。[結果](../results/convention-v1-pilot.md) / [JSON](../results/convention-v1-pilot.json)）: 生得の食後の声は全員の声の散らばりが0.05前後で条件差なし（収束の利得−0.005）、任意性0.010。真似なしは散らばり0.16〜0.26で、聞き合う条件のほうがやや小さい（利得0.056、最大0.090）——真似がなくても聞き合うと状態や行動が揃うためで、これが帰無の尺度。任意性0.041（弱い状態連動でも重心は開き0.35・共鳴0.45付近に寄る）。閾値の固定はこの観察の後、候補の実行の前。個体重心の広がりで測った最初のパイロットでは、真似なしでも広がりが0.06〜0.14と小さく（各個体の重心が目録の平均に寄る）、指標を散らばりへ変えた。
- 結果ファイル・ハッシュ: [開発](../results/convention-v1-development.md) / [JSON](../results/convention-v1-development.json)、[確認](../results/convention-v1-validation.md) / [JSON](../results/convention-v1-validation.json)。ソースd78c3a2（未コミット変更なし）。開発38001–38008・確認39001–39008は観察済み。
- 改善と悪化・代替説明: **収束**: 候補の全員の食後の声の散らばりは、音なしで0.25〜0.28（真似の元が届かない）、音ありで0.05〜0.20（16実行中13実行が0.13以下）。同じ弱い連動で真似だけを外した対照は音ありでも0.16〜0.24。つまり収束は真似による。**任意性**: 候補の収束先（音あり重心）はシードごとに散らばる——開発で(0.30,0.34)・(0.42,0.25)・(0.48,0.33)・(0.24,0.27)・(0.32,0.48)・(0.36,0.46)・(0.50,0.37)・(0.17,0.37)、確認で(0.26,0.55)・(0.53,0.29)・(0.14,0.24)…——のに対し、生得の声は常に(0.72〜0.74, 0.76〜0.78)。どの音でもよく、集団の履歴で決まっている。**聞き手の利用が確認群で弱い理由（診断、判定には使わない）**: 慣習の声は「食べている時に聞いた声」から選ぶので、収束先は誰かが食べていない時にも出していた既存の目録の音になりやすい。同じ分類の音が食料の場所からも探索中の個体からも届くため、出所評価は正負が混ざり、種類の手掛かりとしての鋭さが生得の声（食べている時にしか出ない領域）より落ちる。開発群では0.048と越えたが、確認群では−0.045。**代替説明**「収束は状態連動0.2による」は、同じ連動の真似なし対照で収束が起きないことで否定。「収束は互いの声を分類して覚える受け手側の学習の副産物」は、真似なし対照も同じ聞き手を持つことで否定。
- 採否と判断者・理由: 判断者はこのセッションのLLM（Claude）。5項目の呼称は与えず未成立（revise）。慣習の2項目は両群で成立し、この実験室で初めて**集団ごとに異なる任意の音が共有される**現象を記録した。次は、その音が食料の手掛かりとして鋭くなる条件: 発し手が**食べていない時にはその音を避ける**（対比。形と場面の一対一に近づく）候補を登録し、同じ5ゲート・未使用シードで測る（判断0023）。
- 限界と次の問い: 4人・同じモデル。食料の出現位置は固定列。真似は形の再現で、音声の運動学習ではない。語・文法・意図の再現ではない。共有された音は1つで、「食料」以外の指示対象はない。次: 対比（判断0023）、複数の指示対象。
