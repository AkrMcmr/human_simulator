# 0024 / 慣習が形成された後の機能を測る（convention-v2）

- 状態: 登録（prospective）。評価器の窓の変更・protocol・テストをコミットしてから、未使用シードで測る。パイロットは行わない（世界・閾値はconvention-v1と同一）。
- 背景: [判断0023](0023-contrast.md)で、真似＋対比の候補が収束・任意性・種類依存・到着の4項目を両群で達成し、空腹の副作用だけを開発群で外した（−0.043）。診断: 慣習の声は生得の声と違い実行の初めには存在せず、収束と出所評価が育つまで聞き手は曖昧な声を追って群がる。全実行の空腹平均はこの形成期の費用を含む。
- 変更（評価器のみ）: 空腹で測る2項目（種類依存・副作用）を、実行の後ろ3分の1（2000〜3000ステップ）の空腹平均で取る（`hungerWindow: "late"`）。到着・収束・任意性の定義と、すべての閾値はv1のまま。世界・モデルは変えない。
- 候補と対照: `convention-contrast-0.10.0-experimental.2`（候補）、`convention-0.10.0-experimental.1`（対比なし）、`eating-voice-referent-0.8.0-experimental.3`（生得の声。任意性で落ちるはず）、`human-0.2.0`。
- 仮説と反証条件（evaluator: convention-v2、閾値: 収束の利得≥0.12、任意性≥0.08、後ろ3分の1の種類依存≥0.03、到着の短縮≥0.10、後ろ3分の1の副作用≥−0.02）:
  - H1: 候補が5項目を両群で達成すれば「経験と真似だけで、任意の食後の声が個体間で共有され、**慣習が形成された後には**聞き手がそれを食料の手掛かりに使い、群がる費用を払わない（慣習的な合図の最小形）」と呼ぶ。
  - H2: 対比なしは種類依存を達成しない。生得の声は任意性を達成しない。
  - 反証: 候補の後ろ3分の1の副作用がどちらかの群で−0.02未満。その場合、費用は形成期のものではなく慣習の声に伴う恒常的なもので、「聞き手が慣習の声を追うと群がる」構造自体を見直す（例: 出所評価の負の学習を強める）。
- 開発条件・確認条件: 開発42001–42008、確認43001–43008。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol convention2 --split development --model human-0.2.0 --model eating-voice-referent-0.8.0-experimental.3 --model convention-0.10.0-experimental.1 --model convention-contrast-0.10.0-experimental.2 --out outputs/convention-v2-development.json`（確認は`--split validation`）。
