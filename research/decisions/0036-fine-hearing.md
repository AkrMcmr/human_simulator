# 0036 / 聴覚分類を細かくする（lexicon-v3 第2ラウンド）

- 状態: 登録（prospective）。候補・テスト・第2ラウンドのシードをコミットしてから、lexicon-v3の第2ラウンド（未使用シード、ゲート不変）で測る。
- 背景: [判断0034](0034-mid-scarcity.md)で、暖かさの声は1回の実行の中で集まり、食料の声から0.2ほど離れるが、区別（0.22）と特異性（0.20）が閾値に届かなかった。聞き手の聴覚分類は「0.18以内なら同じ分類」（0.1.0からの既定値）で、0.2離れた2つの声は境界上にあり、出所評価も真似の元も混ざりやすい。
- 候補レベルの仮定（知覚。所有者が2026-09-20の指示で「モデルと検証環境の改善を続ける」ことを求めているため、候補として実装し、既定は変えない）: 聞いた音の分類幅を0.18から0.09にする（`DecideOptions.auditoryResolution`。既定の人間は従来どおり0.18）。0.2離れた声は別の分類になる。分離の規則（0.3）と場所記憶の評価はそのまま。
- 候補`lexicon-0.11.0-experimental.5`。対照: `lexicon-0.11.0-experimental.4`（分離あり・聴覚0.18）、`human-0.2.0`。
- 仮説と反証条件（evaluator: lexicon-v3、9項目、閾値不変）:
  - H1: 候補が9項目を両群で達成すれば「語彙の最小形」と呼ぶ。
  - H2: 区別・特異性が0.11.0-experimental.4より上がる（分類が細かくなれば、出所評価が声ごとに分かれ、真似の元も混ざらない）。
  - 反証: 暖かさ側のどれかが両群で閾値未満。分類を細かくしすぎると分類数の上限（16）に当たり、古い分類が新しい音に引き寄せられる副作用がありうる。
- 開発条件・確認条件: 第2ラウンド、開発68001–68008、確認69001–69008。いずれも未使用。
- 実行コマンド: `npm run study:referential -- --protocol lexicon3 --round 2 --split development --model human-0.2.0 --model lexicon-0.11.0-experimental.4 --model lexicon-0.11.0-experimental.5 --out outputs/lexicon-v3-round2-development.json`（確認は`--split validation`）。
