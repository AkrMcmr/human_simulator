# 0041 / 控えた嫌悪の声と、毒3つに1つの世界（valence-v5）

- 状態: パイロット済み・閾値固定（候補未実行）。開発78001–78008・確認79001–79008で5モデルを測る。
- 背景: valence-v4（[判断0040](0040-disgust-call.md)、開発群）で嫌悪の声の候補は破綻した。(1) 嫌悪の場所の食料が見えている間は毎ステップ発声の衝動があり、実行あたりの悪い声が914回（音なし240）に達して採餌と探索を押しのけ、後ろ3分の1の空腹0.83、8実行中5件で死亡（でたらめ特徴では8件）。(2) 聞いた警告で得た嫌悪の場所も嫌悪の声の対象になるので、警告が警告を呼ぶ連鎖が起き、音ありの集団は音なしより多くの食料を避けた（良い声の収束−0.28、空腹の副作用−0.21）。(3) それ以前に、味覚嫌悪の集団は音なしでも空腹0.61〜0.68・死亡2〜6件で、**食料の半分が毒の世界は毒を避ける集団には過酷すぎる**。餓死が全尺度を汚す。
- 候補`valence-onset-0.12.0-experimental.4`（`packages/human/src/valence.ts`、`decideValence(..., "onset")`）: experimental.3に2つの抑制を加える。(1) 嫌悪（悪い声の文脈と発声の衝動）を生むのは**自分が毒に当たった**場所（firsthand）だけ。聞いた警告で得た場所は避けるが、嫌悪の声の対象にはしない（うわさの連鎖を断つ）。(2) 嫌悪の声の衝動は50ステップに1回まで（前回の嫌悪中の発声から`DISGUST.refractory`以上）。嫌悪中に自発的に声を出すことはあり、その声は悪い声で出る。理解（自分の悪い声と同じ分類の音の出所を避ける、自分の良い声の分類は警告にしない、学習した悪い推定>0.3）はexperimental.3と同じ。
- 対照`valence-onset-private-0.12.0-experimental.4`（`"onset-private"`）: 同じ控えた嫌悪の声を出すが、聞いた悪い声を採餌に使わない。既定・1つの声・味覚嫌悪（experimental.2）も走らせる。
- 世界（valence-v5）: valence-v2〜v4の腐る世界で、毒の割合だけを出現2つに1つ→**3つに1つ**に変える（`toxicEvery: 3`。位置列12か所は3で割り切れるので、同じ位置の食料は常に毒か常に無毒）。初期の食料3か所のうち1か所が毒なのは変えない。目的は「毒を避ける集団が餓死しない」水準にすること。
- パイロット（78101–78104、既定と味覚嫌悪のみ）: 味覚嫌悪の集団の音なしで、後ろ3分の1の空腹が0.6未満、死亡が実行の半数未満であることを確認する。満たさなければ世界をさらに調整して再登録し、候補は走らせない。音なしの毒の摂食が起きることも確認する。閾値は変えない。
- 評価器・閾値: 良い声の収束0.12・任意性0.08・悪い声の収束0.12・区別0.25・空腹の副作用−0.02はvalence-v4と同じ。毒の尺度は**毒に当たる回数**に変える: 毒の摂食があった（個体, 毒の場所）の組の数（何口食べても1回。評価器`poisonings` / `latePoisonings`）。v4の単位尺度は、1か所を食べ尽くすと4単位・1口0.04単位と粒が100倍違い、既定モデルでも1.1単位の差が偶然に出た。毒の利益＝音なし − 音あり の後ろ3分の1の回数、種類依存＝でたらめ特徴 − 音あり。閾値は暫定1.0回・0.5回で、パイロット（既定と味覚嫌悪）の音なしの水準を見て候補を走らせる前に固定する。単位の2尺度は報告のみ。私的（聞かない）対照が毒の利益（回数）を達成した場合は成立と呼ばない。
- 仮説と反証条件:
  - H1: 候補は7項目を両群で達成する。嫌悪の声は実行あたり数十〜百回台に収まり、良い声の収束はexperimental.1並み（0.2前後）に戻る。
  - H2: 聞かない対照は悪い声の収束・区別を達成するが、毒の利益（回数）は閾値未満。味覚嫌悪は悪い声の収束・区別を達成しない。
  - 反証の主な筋: (a) 毒3つに1つでも嫌悪の声の機会が少なく、悪い声が収束しない。(b) 収束しても、聞いた警告が届く前に自分で当たってしまい、毒の利益（回数）が閾値未満。(c) 空腹の副作用が悪化するなら、警告による回避の費用（無毒の食料の見逃し）が便益を超えている。
- 開発条件・確認条件: 開発78001–78008、確認79001–79008。パイロット78101–78104。いずれも未使用（テストで確認）。
- 実行コマンド: `npm run study:referential -- --protocol valence5 --split pilot --model human-0.2.0 --model valence-aversion-0.12.0-experimental.2 --out outputs/valence-v5-pilot.json`、続いて`--split development` / `--split validation`に`--model convention-contrast-0.10.0-experimental.2 --model valence-onset-private-0.12.0-experimental.4 --model valence-onset-0.12.0-experimental.4`を加えた5モデル。
- パイロットで見えたこと（78101–78104、既定と味覚嫌悪、`research/results/valence-v5-pilot.{json,md}`）: 味覚嫌悪の集団の音なしは後ろ3分の1の空腹0.50・死亡0（v3/v4の0.65〜0.73・2〜6件から回復）。毒の摂食は既定8.8単位に対し味覚嫌悪0.88単位、毒に当たる回数は既定7.5回・味覚嫌悪8.0回（実行全体）、後ろ3分の1は3.75回・3.25回（味覚嫌悪はシード間3〜4と安定）。回数の尺度は単位の尺度（味覚嫌悪の後ろ3分の1で0.3単位前後）より粒が揃う。帰無の利益は既定0.75回・味覚嫌悪0.25回、種類依存は0.5回・0.75回。**閾値を利益1.0回・種類依存1.0回に固定**（暫定の0.5回は帰無の平均と同じだったので引き上げた。候補は未実行）。味覚嫌悪の音ありの空腹は0.60（音なし0.50）で、良い声の保護がないexperimental.2では聞いた声が誤警報になる兆し。
