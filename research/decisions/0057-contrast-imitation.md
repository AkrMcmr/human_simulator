- 状態: **反証（開発・確認とも収束が悪化、開発では聞き手の寄与も未達）。候補は採用しない。** 登録時の記述: 候補`threat-cry-contrast-0.13.0-experimental.6`と対照`threat-cry-contrast-deaf-0.13.0-experimental.6`、protocol predator-v6、テストをコミットし、未使用シード（106001–106008 / 107001–107008）で4モデル（既定、候補、対照、predator-v3の上限対照）を測る。パイロットは省く（世界・上限対照は不変）。
- 背景と選択: predator-v4以降の10分割で危険の声の収束（0.12）は達成5・未達5、predator-transmission-v2（[判断0056](0056-predator-transmission-longer.md)）でも確認群の在来者の危険の声が集まらず伝達が未達だった。所有者は選択肢(a)「危険の声の収束を安定させる産出側の候補」を選んだ。
- 診断（predator-v5の開発・確認シード6本、観察済み。候補experimental.5の後ろ3分の1の叫び）: 散らばりは個体内0.03〜0.08に対し個体間0.06〜0.16で、個体間のずれが支配的。危険の声を持たない個体の叫びは0%。各個体の「怖がっている間に最も多く聞いた分類」（真似の元）の個体間の広がりは0.17〜0.33で、叫びより大きい。その分類が自分または仲間の**食料の声**だった個体が16個体中4——逃げている間（怖がっている間）に聞こえる音の大半は食料の声（実行あたり発声1300回超に対し叫び40回前後）なので、「怖がっている間に聞いた割合」の最大は食料の声に落ちやすい。食料の声から0.3離す補正が働くが、その向きは個体の食料の声の位置で変わり、個体間のずれになる。
- 候補の規則（`packages/human/src/threat.ts`、`scoring = "contrast"`。知覚・叫び・届く範囲の連合・怖がっている間の文脈はexperimental.5と同一）: 危険の声の真似の元を、分類ごとの「怖がっている間に聞いた割合 − 食べている間に聞いた割合」が最大で、重み0.5を掛けて0.05を超える分類にする（食料の声の慣習と同じ定数）。両方の文脈で同じ割合で聞こえる分類（食料の声）は0になり、怖がっている間にだけ多く聞く分類（仲間の叫び）だけが危険の声になる。意味・正解・他者の内部状態は与えない。
- 仮説と反証条件:
  - H1''（産出）: 危険の声の収束0.12以上、任意性0.08以上、食料の声との区別0.25以上を両群で達成（experimental.5: 収束0.127 / 0.100、区別0.256 / 0.269）。
  - H2''（理解）: 聞き手の寄与1.0回以上を両群で維持（通算6分割すべて達成中）。
  - 残りのゲート（襲撃の利益2.0、空腹の副作用−0.02、食料の声の収束0.12）も両群で達成した時に限り「経験と真似だけで、食料の声と危険の声が集団ごとに別々に共有され、聞き手が危険の声で襲撃を避ける（2つの指示対象を持つ語彙の最小形）」と呼ぶ。
  - 反証の主な筋: (a) 対比の差が小さく（叫びの割合が低い）、最小スコア0.05に届かず危険の声を持たない個体が増えて叫びが散る。(b) 集まるが別の分類に集まる個体が残り、収束が境界のまま。(c) 収束は上がるが警告の分類が狭まり聞き手の寄与が落ちる。

- 主張しないこと: 捕食者は決まった規則で動き、意図も学習もない。叫びは生得の反射の型で、意味・正解は与えない。語・文法・意図の再現ではない。
- 開発（106001–106008）・確認（107001–107008）（`research/results/predator-v6-{development,validation}.{json,md}`）: **反証**。危険の声の収束は0.064 / 0.097（閾値0.12）で両群未達——experimental.5（0.127 / 0.100）より悪化し、音ありの叫びの散らばりは0.185 / 0.163（experimental.5は0.12〜0.16）。区別0.302 / 0.281と任意性0.103 / 0.114は達成。聞き手の寄与は開発0.625回（閾値1.0、experimental.4以降の8分割で初めての未達）、確認3.625回。襲撃の利益1.375 / 2.875、空腹の副作用−0.039 / −0.021（未達）。同じ対比の真似を持つ聞かない対照も収束0.066 / 0.055で、悪化は対比の規則そのものによる。
- 診断（解釈、追跡は未実施）: 対比は「食べている間にも聞く分類」を外すが、叫びの分類は食べている場所の近くでも聞こえる（捕食者は食料の場所で襲う）ので、叫びの分類も食べている間の割合を持ち、差が小さくなって最小スコア0.05を跨ぎやすい。真似の元が分類の間で入れ替わり、個体ごとに別の分類に落ちる。食料の声を外す狙いは当たっても、叫びを選ぶ安定性を下げた。
- 結論: 対比の真似は採用しない。産出の最良はexperimental.5（怖がっている間の真似）のまま。危険の声の収束が閾値の境界にある原因は「真似の元が個体ごとに別の分類に落ちる」こと（判断0057の診断）で、対比では直らなかった。閾値は変えない。次の選択肢は`docs/STATUS.md`に記す。
