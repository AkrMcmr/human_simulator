- 背景と選択: 危険な動物の課題を到達点として閉じた後（[判断0054](0054-close-predator-line.md)）、所有者は次の課題に(A)「2語の伝達」を選んだ。食料の声・危険の声・警告の意味を持つ集団に、何も知らない新参者を入れ、教えずに両方の声と警告の意味を身につけるかを測る。transmission-v2（[判断0029](0029-transmission-v2.md)）の型（1500ステップ目に個体Dを同じモデルの何も知らない個体に入れ替える、採用率＝新参者の後ろ3分の1の声が在来者の声の0.15以内にある割合、聞ける新参者 − 聞けない新参者）を捕食者の世界（predator-v5と同一）に移し、4500ステップまで走らせる（新参者が警告の意味を自分の経験から学ぶには、集団が実行あたり20回前後受ける襲撃のうち自分の分を数回経験する時間が要る）。
- 候補・対照: predator-v5と同じ（候補`threat-cry-near-fear-0.13.0-experimental.5`、対照`threat-cry-fear-deaf-0.13.0-experimental.5`、上限対照`threat-cry-alarm-ceiling-0.13.0-experimental.3`）。人間モデルの変更なし。
- 評価器（`research/studies/referential-v1.ts`）: `newcomerAttacks`（新参者が到着後に受けた襲撃）、`newcomerThreatCalls`（新参者の後ろ3分の1の危険の声。在来者の分は従来の危険の声の重心に残す）、尺度`adoption-threat-rate-gain`（危険の声の採用率の利得。在来者の後ろ3分の1の危険の声が半径0.15に集まっていなければ0）、`newcomer-attack-benefit`（音なし − 音ありの新参者の襲撃、報告のみ）。旧protocolでは新参者が無いので値は0・空で、既存の結果に影響しない。
- 仮説と反証条件:
  - H1（在来者の2語の維持）: 在来者の食料の声の収束0.12、危険の声の収束0.12、区別0.25を両群で達成。
  - H2（新参者の採用）: 新参者の食料の声の採用率の利得0.3以上、危険の声の採用率の利得0.3以上を両群で達成。
  - H3（新参者の理解）: 対比較「新参者の理解」（聞かない対照 − 候補の新参者の襲撃、音あり、到着後）0.5回以上を両群で達成。0.5回は集団の聞き手の寄与1.0回（4人分）を1人分に按分した0.25回の2倍。パイロット前に固定し、パイロットで変えない。
  - 新参者の空腹の副作用−0.02、集団の空腹の副作用−0.02も両群。
  - 反証の主な筋: (a) 在来者の危険の声がそもそも集まらない（predator-v5で収束は0.10〜0.15）→採用率は0になり未成立。(b) 新参者は3000ステップでは的中2回に届かず警告を学べない。(c) 新参者は在来者の叫びを真似るが、怖がっている間の文脈が自分の危険に偏り、在来者と別の音に落ちる。
- パイロット（102101–102104、聞かない対照・上限対照）の基準: (1) 対比較「上限対照の新参者の余地」（聞かない対照 − 上限対照の新参者の襲撃、音あり）1.0回以上、(2) 新参者の後ろ3分の1の危険の声が実行あたり3回以上、(3) 非常時3%未満・死亡が実行の半数未満。(1)が1.0回未満なら保留。候補は走らせない。

- 実行コマンド: `npm run study:referential -- --protocol predatorTransmission --split pilot --model threat-cry-fear-deaf-0.13.0-experimental.5 --model threat-cry-alarm-ceiling-0.13.0-experimental.3 --out outputs/predator-transmission-pilot.json`、続いて`--split development` / `--split validation`に`--model human-0.2.0 --model threat-cry-near-fear-0.13.0-experimental.5`を加えた4モデル。
- 主張しないこと: 捕食者は決まった規則で動き、意図も学習もない。新参者は同じモデルの何も知らない個体で、教える・教わるの意図はない。音に意味・正解を与えない。語・文法・意図の再現ではない。
- パイロット（102101–102104、聞かない対照・上限対照、`research/results/predator-transmission-v1-pilot.{json,md}`）: **3基準すべて達成**。(1) 上限対照の新参者の余地1.25回（聞かない対照4.75 vs 上限対照3.5。シードごとに+3、+2、+5、−5——1シードで上限対照の新参者が8回噛まれた）。(2) 新参者の後ろ3分の1の危険の声は聞かない対照で実行あたり5.25回（3〜9）、上限対照3〜13回。(3) 死亡0、非常時0〜0.2%。参考（候補未実行）: 聞かない対照でも新参者の危険の声の採用率の利得0.59、食料の声0.42——採用は産出（怖がっている間の真似）の尺度で、理解を要しない。在来者の区別は聞かない対照0.193で未達、上限対照0.407。対比較の閾値（新参者の理解0.5回）は固定のまま、候補と既定を加えた4モデルで開発（102001–102008）・確認（103001–103008）へ進む。
- 開発（102001–102008）・確認（103001–103008）（`research/results/predator-transmission-v1-{development,validation}.{json,md}`）: **未成立**。
  - 食料の声の伝達: 新参者の採用率の利得0.343 / 0.348（閾値0.3）で**両群達成**。在来者の食料の声の収束0.147 / 0.135も達成。
  - 危険の声の伝達: 採用率の利得−0.047 / 0.127（0.3）で未達。在来者の危険の声の収束0.098 / 0.085（0.12）・区別0.231 / 0.241（0.25）が未達で、在来者の後ろ3分の1の危険の声の散らばり（0.16 / 0.17）が採用の半径0.15を超え、採用の前提（慣習の存在）が成り立たない。
  - 新参者の理解: 対比較0.25 / 0.25回（閾値0.5。シードごとに−2〜+4）で未達。新参者が到着後に受ける襲撃は5〜6回で、「6u以内の声の直後に自分が危険に遭う」経験が的中2回に届きにくい。集団の聞き手の寄与は3.625 / 5.625回で達成（在来者は守られている）。
  - 費用: 聞ける新参者の後ろ3分の1の空腹は0.303 / 0.334（聞けない新参者0.276 / 0.261）で、新参者の空腹の副作用−0.027 / −0.073（−0.02）未達。集団の空腹の副作用も−0.022 / −0.049で未達。警告で逃げる費用が、まだ意味を学び切っていない新参者に集中する。
  - 対照の側で見えたこと: 聞かない対照（同じ産出、警告で逃げない）は確認群で在来者の2語（収束0.142、区別0.338）と新参者の両方の声の採用（食料0.564、危険0.435）をすべて達成した。産出の体系そのものは、集まりさえすれば新参者に伝わる。候補では警告からの逃走が在来者の危険の声の散らばりを広げている可能性がある（predator-v5では逆に候補の方が区別が良く、分散の範囲内かは不明）。
- 結論: 言えること——食料の声は危険な動物の世界でも新参者に伝わる（両群）。集団の聞き手の寄与は新参者を入れても保たれる（両群）。言えないこと——危険の声と警告の意味の伝達。原因は在来者の危険の声の収束が閾値を跨ぐこと（判断0052・0053から続く未解決）と、新参者が警告の意味を学ぶ経験（自分の危険）が3000ステップで数回しか無いこと。閾値は変えない。次の選択肢は`docs/STATUS.md`に記す。
