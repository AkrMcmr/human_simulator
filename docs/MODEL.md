# v0.1の仮定と計算

この文書の係数は実装上の仮定です。生理学・発達心理学の実測による校正はありません。「原始状態の人間」の科学的定義ではなく、ユーザーが定めた特殊な初期条件を扱います。

## 状態と情報の境界

世界は位置・速度・資源・音の放射を持ち、人間は身体状態・個体別の記憶・行動予測・音響特徴の分類を持ちます。世界の完全な状態は実験者には表示できますが、人間には知覚範囲内の相対位置、相対速度、外見の類似度、資源の手掛かり、雑音を含む音だけを渡します。

自分の絶対位置と、安定した相手の追跡IDを利用できることは簡略化です。自己位置推定や再認識の学習はまだ実装していません。視覚は遮蔽物なしの円形範囲16u、聴覚は20uが既定値です。視認できない音源には個体IDを付与しません。

人間は似た外見（類似度0.7以上）の相手を同種らしいものとして扱います。二人の世界での見かけ上の一致は、実際の種認識の妥当性を証明しません。

## 身体

空腹・疲労・寒さ・健康は0〜1です。初期値は順に0.24/0.15/0.10/1。食べる、暖を取る、休むという行動の技能と効用は初期装備です。

各ステップの更新（範囲外は0〜1へ丸める）:

- 空腹 += 0.002 + 運動量×0.0007 − 摂食量
- 疲労 += 0.001 + 運動量×0.002 − 休息時0.025
- 寒さ += (環境寒度 − 寒さ)×0.025 − 運動量×0.0006
- 健康 -= 生理ストレス×0.006 + 接触痛×0.006。生理ストレスが0なら0.00015回復。

生理ストレスは空腹0.9・寒さ0.85・疲労0.95からの超過分の和です。暖かい場所は環境寒度を下げます。食料は有限で再生し、同時に食べる個体には均等配分します。健康0の個体は行動しません。

水分・排泄・感染・発育・実際の熱収支は未実装です。成人相当という指定は移動・生活技能の設定として反映していますが、現実の筋力や代謝の再現ではありません。時間と距離は抽象単位です。

## 危険の推定

相手ごとに危害/無危害の証拠をBeta(1,1)から保持します。直前または現在の距離が2.5u未満で相手を連続視認しているときだけ、直前の接触痛の有無を1件加算します。忘却は既定値0.002で事前分布へ戻します（alpha−1とbeta−1を同じ率で縮めるので、接触がないと推定が0.5へ流れます。[判断0006](../research/decisions/0006-reaction-reversal.md)で480ステップの無接触により無害の記憶の危険度が0.015→0.085に上がることを確認）。

候補0.5.0-experimental.1（`packages/human/src/signal-sender.ts`、登録簿`signal-sender-0.5.0-experimental.1`）は、受信側候補0.4.0の上で、出した音の自分の分類ごとに相手との距離変化を学び、`predictedSafety`と同じ式で分類に得点を付けて温度0.05のsoftmaxで音を選びます（20%は従来の選び方）。自由worldの評価（[判断0012](../research/decisions/0012-signal-sender.md)）では合図は未成立で、反証された候補として登録簿に残しています。

候補0.3.0-experimental.1（`decideWithOptions`の`forgetting: "keep-estimate"`、登録簿`forgetting-keep-estimate-0.3.0-experimental.1`）は、推定alpha/(alpha+beta)を固定したまま総量だけを2+(総量−2)(1−0.002)へ縮めます。証拠の減り方は同じで、推定は流れません。[判断0007](../research/decisions/0007-keep-estimate-forgetting.md)で改善ゲートを達成し候補として保持中。既定ではありません。

この因果帰属は近接と接触痛の関連づけにすぎず、悪意の推定ではありません。遠くで何も起きなかったことを無危害の証拠として加算しません。

現在の危険度 = clamp(近さ×危害の推定率 + 接近速度の正の部分×0.2 + 距離1.5u未満なら0.25)。近さはclamp(1−距離/12)。相手を視認しない場合は0です。これは「安全」という確信ではありません。

不確実さ = 1 / sqrt(1 + 視認回数/8)。視認回数で必ず減るヒューリスティックで、ベイズ的な予測不確実性そのものではありません。

## 行動の選択と距離の学習

候補は観察・接近・離隔・探索・摂食・保温・休息・発声。相手や記憶した資源がないときは対応する候補を除外します。候補ごとの身体要求、好奇心、警戒、行動継続（0.06）、コストの加算を効用とします。全項と値を各判断の `scores[].terms` に保存します。

効用を温度0.09のsoftmaxで選択します。既定8%は候補から均等な探索選択です。好奇心は探索・接近・発声を直接加点するため、好奇心を増やして発声が増えるのは実装による効果を含みます。

同じ相手を次のステップでも視認したとき、自分の直前の行動ごとに距離変化を記録します。距離変化は−2〜2uに制限し、予測平均を `mean += learningRate × (delta − mean)` で更新します。分散も指数平均で更新しますが、現在の効用には直接使いません。

発声後の距離変化の予測と経験数は、以後の発声効用に影響します。他の行動の予測は記録・評価のみです。行動方策全体の強化学習ではありません。相手の自律行動や共同資源への移動が交絡するため、発声の「成功」や因果的効果とは判定しません。

学習率0は距離予測と近接証拠の更新を止めます。視認回数・資源記憶・音の分類は更新されるため、完全な学習無効条件にはなりません。

## 発声と聴覚

発声は開き・共鳴の二つの連続特徴（0〜1）です。最初はランダムに探索し、既に発した形を65%で再利用し、±0.035の運動雑音を加えます。相手から聞いた音には伝達距離に応じた減衰と知覚雑音が加わります。

各個体が発声・聴覚それぞれのプロトタイプを保持し、近い特徴をオンライン平均でまとめます。聴覚の距離閾値0.18、発声0.14、最大16個という上限は実装上の仮定です。上限後は最も近い既存分類へ併合します。音の新奇性×音量は観察行動の効用へ最大0.35の加点となります。

分類は共有されず、音素・語・意味・ターンテイキングの規則はありません。相手の音を模倣する機能も未実装です。実際の音声波形の生成・再生は行いません。

## 更新順と版

全員がtの世界を知覚 → 個体内のフィードバック更新と選択 → 全員の行動を世界に同時適用 → 身体更新 → t+1の観察記録。画面の身体状態と、直前の判断に使われた知覚は1ステップ異なり、UIに判断入力のtを明記します。

乱数はシード/個体/ステップ/用途をキーにした `keyed-fnv-mulberry-v1`。同じ実装と実行環境で再現できます。ソース変更時はモデルの版を上げ、旧版のチェックポイントをそのまま新モデルへ移さないことを原則とします。

## v0.2.0の既定: 予測による安全性の効用

human 0.2.0では、全候補行動の効用に`predictedSafety`項を加えます。本人の行動別距離予測から、その行動後の危険度（現在の危険度計算と同じ式で、危害の推定率と距離から計算）の低下を見積もり、経験数/(経験数+8)/(1+分散)、警戒傾向、身体要求の余裕（1−最大要求）を掛け、gain=4、±0.2に制限して加算します。同じ相手への当該行動の経験が4件未満なら寄与ゼロです。各判断の`scores[].terms.predictedSafety`に値を残します。係数は未校正の工学的仮定です。

旧0.1.0（この項なし）は`decideLegacyHuman`と登録簿ID`human-0.1.0`で再現できます。`decideHuman`の第4引数に`() => 0`を渡すと寄与を無効にした対照になります（項のキーが残るため0.1.0の記録とは行動が同じでも判断記録の形が異なります）。登録簿は`packages/simulation/src/models.ts`、選択は`ExperimentConfig.model`（CLIは`--model`、UIは「人間モデル」）です。

制御課題の評価は[研究判断0003](../research/decisions/0003-prediction-to-policy.md)、通常worldの8条件比較は[研究判断0004](../research/decisions/0004-normal-world-m1.md)を参照してください。通常worldでは、資源を共有する配置で接触痛の起きるステップの割合を約0.04〜0.05から約0.01〜0.02へ減らし、近接の割合と平均距離はほぼ変わりませんでした。代わりに摂食・保温の選択が各4〜5%減り、身体要求の負担がわずかに増えます。これは二人とも同じモデルで判断する抽象worldでの工学的比較で、人間データとの校正はありません。

## 候補0.4.0: 聞いた音と距離変化の関連

`packages/human/src/sound-association.ts`の独立候補。既定0.2.0から分岐し、忘却候補0.3.0の変更は含めない。`soundAssociations[peerId][categoryId]`に平均・分散・経験数、`soundPending`に音を聞いたtick・相手・分類ID・距離を保持する。これらは既定モデルには生成しない任意拡張。

最近傍の同種個体に結びつく、正の音量の音が一つだけあるときに分類IDを記録。同じ相手を次tickにも視認したときだけ距離差±2を既存learningRateで指数更新する。学習率0、視認断絶、時刻の飛びでは更新しない。未知音は予測を使わず、新たな対応を学ぶ。カテゴリ上限16は既存分類に従う。相手数の上限や音予測の忘却はまだない。

4経験以上で、予測距離からの危険度変化×4×警戒×身体余裕×経験数/(経験数+8)/(1+分散)を±0.2に制限。危険度の増加予測を離隔に加算、接近から減算し、`scores[].terms.signalPrediction`に保存。他行動には0。接近速度項は既存の現在知覚による評価に残す。距離変化と音の相関であり、意図・語義・因果を推論していない。

`decideWithSoundOptions`のassociation/classification/attention/policyを独立制御でき、登録簿に各対照を用意。関連学習無効は既定関数へ委譲し完全一致。分類無効は既存カテゴリがあっても音の予測を使わず、新しいカテゴリも作らない。注意無効は観察効用の新奇音加点だけを止める。policy無効は記憶更新を続け効用寄与を0にする。

制御課題の[判断0010](../research/decisions/0010-sound-association.md)で対応と逆転を確認。選択行動は実行していないため自由worldでの利益は未検証。候補として明示選択でき、記録と再生には候補独自の版を残す。
