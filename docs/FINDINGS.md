# ここまでにわかったこと

専門知識のない読者向けに、Human World Lab の実験で確かめたことを平易にまとめます。すべて、内部の計算規則だけで動く二人の個体を、同じ条件と乱数シードで何度も走らせて比べた結果です。人間の心の再現を確認したものではありません。数値の出典は各判断記録（`research/decisions/`）にあります。

## 舞台と登場人物

40×28の抽象的な広場に、食料と暖かい場所が点在します。二人（AとB）は空腹・疲労・寒さを感じ、食べる・暖を取る・休む技能を最初から持っています。相手を「自分と似た何か」として見分けられますが、言葉も、あいさつの決まりも、相手の気持ちを知る手段もありません。二人は同じ計算規則で判断し、経験から次の3つだけを学びます。

1. 自分がある行動をとった後、相手との距離がどう変わったか。
2. 近くにいた相手と、体が触れる痛みが結びついたか。
3. 聞いた音にどんな特徴のまとまりがあるか。

## 発見1: 「近づくと危ないかも」の予測を使うと、ぶつかる回数が4分の1になった

旧モデル（0.1.0）は距離の変化を学んでも、発声以外の行動選択には使っていませんでした。「この行動をとれば危険が減りそうだ」という予測を全行動の評価に加えた新モデル（0.2.0）は、食料を共有する配置で、体が触れて痛みが起きるステップの割合を約4〜5%から約1〜2%へ減らしました。

面白いのは、遠ざかったわけではないことです。二人が4u以内にいる時間や平均距離はほとんど変わらず、至近距離だけを避けています。代わりに食事や暖を取る選択が4〜5%減り、身体の負担がわずかに増えました。「安全のために少し生活を後回しにする」という費用が数値で見えます。8つの条件と16のシードで確認し、既定モデルになりました。（判断記録 0003、0004）

## 発見2: 経験が同じ景色の見え方を変える。そして記憶を入れ替えると評価が反転する

相手の近くで痛みを受けた経験のある個体は、まったく同じ体の状態・同じ見え方でも、危険度を約0.4高く見積もり、離れる行動を強く選びます。実験者がその個体の「相手の記憶」だけを消すと差は完全に消え、痛みを受けた個体と受けなかった個体の記憶を入れ替えると、評価の向きがそのまま入れ替わります。違いは相手についての記憶だけから生まれています。（判断記録 0005）

## 発見3: 避け続けると、学び直す機会がなくなる

痛みをもたらした相手が無害になったあと、相手が近くに居続ける状況では、危険度の見積もりは約0.26下がります。ところが、食料が別々にあって相手を避けられる配置では、8回の実験のうち5回で一度も2.5u以内に近づかず、危険度はまったく下がりませんでした。少しでも近づいた回では、近づいた分だけ下がります。

一方、食料を共有する配置では空腹が回避を上書きし、二人は結局近づいて、強制的に近づけた場合とほぼ同じだけ警戒がほどけます。「避けられる環境は警戒を固定し、共有せざるを得ない資源は学び直しを生む」。これは計算規則から出てきた、しかし直感に合う結果です。（判断記録 0005）

## 発見4: 長い無害の経験は、危害への気づきを遅らせる

無害だった相手が急に痛みをもたらし始めたとき、60ステップの無害な経験がある個体は、経験のない個体より30ステップ後の危険度が約0.2低いままです。経験が240ステップならさらに約0.09低い。逆に、長く痛みを受けた相手が無害になっても、回復は遅れます。証拠が積み重なるほど、新しい証拠の重みは相対的に軽くなるためです。（判断記録 0006）

## 発見5: 「忘れる」の向きが、安心の記憶を蝕んでいた

現行の忘却は、証拠を「何も知らない状態（危害推定0.5）」へ戻します。すると、無害だとよく知っている相手でも、接触がなく見えているだけの期間が480ステップ続くと危険度が0.015→0.085へ上がってしまいます。安心の記憶が勝手に薄れるわけです。

「推定は保ち、確信の量だけ薄れる」忘却則に変えた候補では、この上昇が0になり、他の能力（更新の遅れ、回復、基礎能力、通常の生活）は変わりませんでした。ただしこの則では、危害の記憶も新しい無害の接触なしには薄れません。「許し」は忘却ではなく再接触からしか生まれない、という設計上の選択です。既定にするかはレビュー待ちです。（判断記録 0007）

## 反例として残したこと

- 「お腹が空いていると警戒がゆるむ」は、予測の項では成立しますが、評価全体ではほとんど効きません。警戒の大半は直接の危険度から来ています。
- 声を聞いた直後に声を出す場面は起きますが、音の新しさへの注意と好奇心で説明できます。呼びかけと返事が成立したとは判定していません。

## グラフで見る

[docs/digest/index.html](digest/index.html) は、この5つの発見を保存済みの研究結果（確認シード群の平均）からのグラフと解説で読める1ページのダイジェストです。ブラウザで開くだけで動きます（外部通信はフォントの読み込みのみ）。数値の元は `research/results/` と `research/evolution/cycles/` のJSONで、更新時はそこから再生成します。

## 自分で試すには

```bash
npm ci
npm run narrate -- --seed 42 --steps 400            # 一回の出会いを物語風に要約
npm run narrate -- --seed 7 --layout separate --mute  # 条件を変えて比べる
npm run dev                                          # 観察画面（「見どころ」「経験から判断へ」）
```

同じシードなら誰が実行しても同じ記録になります。違うシードで何が変わり、何が変わらないかを見るのが、この実験室の楽しみ方です。次の課題は[STATUS](STATUS.md)、実験の約束は[研究ループ](../research/LOOP.md)にあります。
