## 自動検証

`npm run test:model` の13件:

- 同じ条件・シードで完全一致、異なるシードで変化
- 個体の並べ替えに依存しない同時更新
- Bの内面だけの変更がAの現在の判断へ漏れない
- 視野外の個体と音源IDが知覚に漏れない
- 音の新奇性から注意への経路（意味ラベルなし）
- 遠い相手の無危害を証拠にしない
- 中断・再開と連続実行の完全一致
- 記録の再現検証、改変・版不一致の拒否
- 観察が状態と乱数を変更しない
- 同時摂食の公平な分配
- 400ステップで状態・位置の範囲を維持、実際に発声・学習
- 不正設定を早期拒否
- human/worldが公開契約以外のモデル層や通信に依存しない

TypeScriptの型検査とESLintは成功。UIのビルドとHTMLのサーバーレンダリングも検証しています。ブラウザ操作によるUI・アクセシビリティ・視覚QAと複数ブラウザ間の計算一致は未実施です。

## 初期比較: 好奇心の介入

再現コマンド: `npm run compare -- --seed 42 --steps 400`。既定の中央共有食料、二人の初期距離12u、その他既定値。各条件でシード42〜49。平均 ± 標本標準偏差。

| 二人の好奇心 | 平均距離 u | 距離4u未満の割合 | 発声回数（計） |
| --- | ---: | ---: | ---: |
| 0.15 | 3.608 ± 0.160 | 0.709 ± 0.045 | 22.5 ± 5.555 |
| 0.55 | 3.367 ± 0.352 | 0.762 ± 0.075 | 73.5 ± 10.156 |
| 0.90 | 2.975 ± 0.439 | 0.818 ± 0.105 | 165.5 ± 15.288 |

好奇心が発声と接近の効用を直接加点するため、この傾向には式に埋め込んだ効果があります。新しい人間科学上の発見や言語の創発とは解釈しません。中央資源に集まる効果も含みます。音あり/なし、資源配置、既定効用の除去、観察機会の差を統制する実験が次の課題です。

距離予測の誤差は相手を連続視認した遷移だけに定義されるため、視認機会が異なる条件での単純比較には注意が必要です。現在は有意差検定・信頼区間・人間データとの校正を行っていません。
