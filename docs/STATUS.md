# 現在地（2026-09-15）

## 動いているもの

既定モデルはhuman **0.2.0**。0.1.0の身体対処、同種個体の局所観察、危害の証拠、行動後の距離予測、連続音の試行と分類に加え、学習した行動別の距離変化から危険度の低下を見積もって全行動の効用へ加える項（予測効用）が既定になりました。CLIと観察UIは同じ二人の実行エンジンを使います。言葉の意味、社会、文化、生殖は未実装です。

契約 **0.2.0**・世界 **0.2.0**（2026-09-20）: 聞いた音に音源への相対位置（方向と距離）を加えました。既定モデルはこれを使わず、判断・測定値は変わりません。旧形式の記録は版不一致で読み込めません。

simulation **0.2.0**で人間モデルを名前で選べます（`packages/simulation/src/models.ts`の登録簿。既定`human-0.2.0`、旧既定`human-0.1.0`、候補時代のID`predictive-0.2.0-experimental.1`（0.2.0と同じ計算）、対照`predictive-ablated-0.2.0-experimental.1`）。CLIは`--model`、UIは「人間モデル」で選択し、記録にはモデルIDと版を残します。別のモデルの記録を再生することは拒否されます。simulation 0.1.0形式の記録は読み込めません（無言の移行はしない方針）。

実行時のLLMは使いません。これは未校正の探索モデルで、高精度な人間の再現を確認したものではありません。

## 中期の到達点

次の3か月程度は、二人が経験から関わり方を変え、最小限の合図の成立条件を再現・検証できる実験室を目指します。[中期目標と達成条件](MIDTERM_GOALS.md)にM1〜M4を定めました。M1（protocol、比較CLI、シード別結果、採否記録、モデル選択と版記録、既定化）は完了。M2は履歴介入実験（[判断0005](../research/decisions/0005-experience-history-m2.md)）を完了し、観察画面の時系列表示も追加しました。反応の途中変化の制御実験も完了し、M3の受信側準備診断へ進んでいます。

## M2: 経験履歴と記憶介入

`npm run study:history`（protocol `history-v1`）で、危害あり/なしの履歴、記憶の保持・消去・入れ替え、強制近接と自由行動（食料共有/分離）を実験者が操作し、既定0.2.0の現象を確認しました。開発6001–6008・確認7001–7008で7項目すべて達成。

- P1: 危害履歴は同じ身体・知覚で危険度（差約0.39〜0.42）と離隔対接近の評価差（約0.61〜0.66）を上げる。相手の記憶を消すと差は0、入れ替えると反転する。差は相手の記憶に由来する。
- P2: 危害がなくなり相手が近くに居続けると危険度は約0.26〜0.28下がる。食料が別で回避できる配置では、8シード中5シードで一度も2.5u未満に入らず危険度が変わらない（強制近接との差約0.22〜0.25）。食料を共有する配置では身体要求が回避を上書きし、約72ステップ近接して強制近接とほぼ同じだけ下がる。
- 反例として記録: 身体要求が高い（空腹0.8）と予測効用の項の履歴依存は小さくなるが、評価全体の履歴依存はほとんど変わらない。忘却は事前分布へ戻る向きなので、無害の記憶も接触がなければ薄れる。

これらは工学的な機構の確認で、人間の信頼・恐怖・愛着の再現ではありません。パイロットシード6101–6104と開発・確認シードは観察済みです。

観察画面の「経験から判断へ」（Codexが追加）で、個体と相手を選び、危害推定、行動別の距離予測・分散・経験数、効用内訳、次の知覚、接触痛・摂食量を時系列で追えます。observer専用のスナップショットで、人間の判断には戻しません。

## M2続き: 反応の途中変化と忘却則の候補

`npm run study:reversal`（protocol `reversal-v1`、[判断0006](../research/decisions/0006-reaction-reversal.md)）で、無害→危害・危害→無害の切り替えと、接触のない期間の忘却を既定0.2.0で測りました。開発8001–8008・確認9001–9008で5項目達成。無害履歴60の後は履歴なしより危害への更新が約0.18〜0.28遅れ、履歴240ではさらに約0.09遅れる。危害履歴の後の回復は履歴が長いと遅い。接触のない480ステップで無害の記憶の危険度は0.015→0.085に上がる（事前分布へ戻る忘却）。

この最後の性質を改善目標に、忘却則の候補**0.3.0-experimental.1**「推定を保ち、確信（証拠の総量）だけ薄れる」を`decideWithOptions`の`forgetting: "keep-estimate"`として実装し、改訂サイクル`forgetting-keep-estimate-m2`（prospective）→`forgetting-keep-estimate-m2-b`（評価器修正後の再評価、retrospective）で旧版と比較しました（[判断0007](../research/decisions/0007-keep-estimate-forgetting.md)）。gap-fadingは0.070→0.000、更新の遅れ・回復は差0.003以内、core-v1とworld-v1に悪化なし、寄与無効は一致。`retain-candidate`で保持し、**追加の履歴実験とレビュー後も代替候補として保持**しています。推定を保つ忘却では、危害の記憶も新しい無害の接触なしには薄れません。

## M3: 音と結果の関連利用の準備診断

`npm run study:signal`を追加。音と接近/離隔の対応を一貫させる条件、音なし、音回数を保った対応シャッフル、音分類記憶の消去を比較しました。開発10001–10008・確認11001–11008で、音分類と新奇音への注意は達成、対応を距離調整へ使う項目は未達（差0、必要0.05）です。語義を与えずに次の不足機構を切り分ける制御課題であり、送信者の合図獲得・二人の言語創発は未検証です。[判断0008](../research/decisions/0008-signal-readiness-m3.md)。

忘却候補は追加のhistory-v1比較で両群7項目を達成しました。既知シードの回帰確認です。二つの忘却則の科学的優劣は決まらないため既定0.2.0を維持し、候補を残します。[判断0009](../research/decisions/0009-forgetting-adoption-review.md)。

## M3: 自由worldでの最小合図の診断と発し手候補

`npm run study:signal-world`（protocol `signal-world-v1`、[判断0011](../research/decisions/0011-signal-world-m3.md)）で、二人が自由に動く通常worldで「聞いた音の種類→聞き手の次の行動」「相手との距離→出す音の種類」の結びつきを超過相互情報量で測り、音なし・でたらめ音の介入と比べました。発し手候補`signal-sender-0.5.0-experimental.1`（[判断0012](../research/decisions/0012-signal-sender.md)。出した音の種類ごとに相手の距離変化を学び、危険度の低下予測で音を選ぶ）も結果を見る前に登録して比較しました。

結果: 既定0.2.0、受信側候補、発し手候補、その対照のいずれも、開発・確認の両群で**合図は未成立**。聞き手の結びつきは全モデルで0付近（−0.014〜−0.002 bit、閾値0.03）、発し手の結びつきは発し手候補で0.013 bit（他は0.000〜0.007）と方向は仮説どおりですが閾値0.03に届きません。副作用はなし。原因の診断: 900ステップで一人あたり約100回の発声が最大16の分類に分かれ、種類ごとの経験が数件で予測の確信が上がらないこと、および聞き手が学べる構造そのもの（音の種類と発し手のその後の動きの対応）が発し手側に存在しないこと。学習の相互依存で両側が雑音から出発する「にわとりと卵」の状態です。

## M3続き: 状態連動の声（ユーザー指定）でも合図は未成立

所有者の判断（2026-09-20）で「発声の特徴が本人の状態に一定割合で連動する」初期能力を認め、[CONCEPT](CONCEPT.md)に記録しました。候補`voice-state-0.6.0-experimental.1`（連動＋発し手学習＋受信側学習）と対照を、signal-world-v1の第2ラウンド（未使用シード16001–16008・17001–17008）で測りましたが、全モデルで合図は未成立です（[判断0013](../research/decisions/0013-voice-state.md)）。

診断: この世界では声に漏れる状態がほとんど変化しません。発声時の危険度は中央値0.03（無害な近接で危害推定が0.02まで下がるため）、身体要求は0.2〜0.4の狭い範囲。音は9区分のうち2区分に約8割が集まり、聞き手が音を聞いた直後の行動も約95%が接近・離隔以外です。**伝える価値のある状態の差と、聞き手が知らない情報の非対称が、世界の側に存在しない**ことが原因です。初期能力の採用は維持し、次は世界と課題の設計に移ります。

## M3続き: 情報の非対称がある採餌課題（referential-v1）

聞いた音に**方向**を加え（契約0.2.0・世界0.2.0、音源定位の簡略化）、視界5u・食料3か所・二人を20u離した課題で、「声を手掛かりに食料へ向かう」かを測りました（[判断0014](../research/decisions/0014-referential-foraging.md)）。候補は、空腹で食料の記憶がないとき最も大きい声の方向へ探索する「盲目的な定位」（0.7.0-experimental.1）と、聞いた音の種類ごとに「その方向へ向かった後の空腹の変化」を学んで選ぶ「選択的な定位」（0.7.0-experimental.2）。

結果: 主要指標（空腹平均の改善）は全モデル未達で反証。しかし**声は食料への到達を早めています**（初回摂食まで既定202→定位147〜152ステップ、確認群261→135〜149）。空腹平均が改善しないのは、声を追って合流した二人が小さな食料を分け合い、片方なら足りた食料が二人では足りなくなるため。方向をでたらめにした対照は探索範囲が広がって最も空腹が低く、この課題では「情報共有の利益より資源競合の費用が大きい」ことがわかりました。

## M3続き: 声の方向は在処の手掛かりとして働く（referential-v2）

主要指標を初回摂食までの時間に変え、食料を十分な量にしたreferential-v2（[判断0015](../research/decisions/0015-referential-v2.md)）で、**声の方向が食料への到達を早めること**が、定位のある5モデルすべてで開発・確認の両群で成立しました（短縮は実行長の0.04〜0.12、約40〜110ステップ。方向をでたらめにすると消える）。これが本実験室で初めて事前登録の基準を満たした「声が手掛かりとして働く」現象です。ただし**声の種類は使われていません**（音の特徴をでたらめにしても変わらない）。どんな声も相手の方向を指し、方向だけで足りるため種類を区別する圧力がなく、食後の呼び声と探索中の声が音としても分かれていないためです。声を追って合流する費用（空腹・接触）も候補によって残ります。

## M3続き: 声の種類はまだ使われないが、聞き手は「この声の出所には食料がある」を学び始めた

referential-v2の第2・第3ラウンド（[判断0016](../research/decisions/0016-eating-coupling.md)、[0017](../research/decisions/0017-referent-learner.md)）で、「食べている状態が声に漏れる」連動（ユーザーが認めた状態連動の原則の拡張）と、聞いた声の出所を覚えて後で訪れたときに食料があったかで分類を評価する聞き手を試しました。どちらも種類依存は未達。診断で、(1) 初回摂食の指標は学習前に決まること、(2) 量1.0の食料は25ステップで尽き、食後の声が「ほぼ空の食料」から出続けるため聞き手が正しく「追う価値なし」と学ぶこと、が分かりました。

そこで世界0.3.0で食料が尽きると別の場所に現れる仕組みを加え、発見のたびに「知っている個体と知らない個体」が生じる課題referential-v3（[判断0018](../research/decisions/0018-referential-v3.md)）を作りました。主要指標は「一人が見つけた後、もう一人がその食料に着くまでの時間」。結果: 方向の手掛かりは3モデルで両群再現（到着の短縮0.13〜0.44、上限300ステップ比）。**種類依存は未達**。ただし事後診断で、候補の聞き手は食後の声の分類を「食料がある」と正に学んでいました（前の世界では同じ声を負に学んでいた）。二人の世界では、空腹の聞き手が聞く声は必ずもう一人のものなので、種類が方向に付け加える情報がなく、種類で選ぶ分だけ盲目的な追従より遅くなります。

## M3続き: 4人の世界で、声の種類の利用が事前登録のゲートを両群で越えた（成立、候補のまま）

研究コードを人数に一般化し、4人・食料3か所が移り変わる世界referential-v4（[判断0019](../research/decisions/0019-referential-v4.md)）を作りました。方向の手掛かりは3モデルで大きく再現（到着の短縮0.36〜0.65）。到着で測った種類依存は0付近でしたが、候補（出所評価＋食べている状態の声）は群がる費用を払わず（空腹は音なしと同じ、盲目的な追従は0.1悪化）、でたらめ特徴で空腹が悪化し、64個体すべてが食後の声の分類を「食料がある」と学んでいました。そこで種類の利用を「費用の回避」（でたらめ特徴 − 音あり の空腹 ≥ 0.03）で測るreferential-v5（[判断0020](../research/decisions/0020-referential-v5.md)）を未使用シードで登録・実行。**候補だけが種類依存を両群で達成**（0.032 / 0.038）し、確認群では4項目すべてを達成しましたが、開発群で空腹の副作用をわずかに外し（−0.028、閾値−0.02）、事前登録の成立条件は満たしていません。ゲートは変えず第2ラウンド（32001–32008 / 33001–33008）で再現を測ったところ、種類依存は再び両群で達成（0.049 / 0.078。2ラウンド4群すべて達成、対照は各1群）、空腹の副作用は開発群で達成・確認群で未達（−0.035）。4群の副作用の平均は+0.004で、8シードでは判定が偶然に左右されるため、第3ラウンドは16シード×2群で測ります。第3ラウンド（16シード×2群、34001–34016 / 35001–35016）で候補が**4項目を両群で達成**し、事前登録した呼称「声の種類を手掛かりに追う相手を選び、食料のない声を追う費用を避ける受け手側の合図利用」の成立を認めました。3ラウンド目での成立であること、候補のままで既定ではないこと、音の慣習の創発ではないことを[判断0020](../research/decisions/0020-referential-v5.md)に明記しています。

## M3続き: 経験と真似だけで、任意の「食料の声」が集団ごとに共有された（慣習の最小形）

生得の食後の声を外し、発し手が「自分の経験が食料と結びつけた聞いた声」を食べている時に真似て出す候補`convention-0.10.0-experimental.1`を、convention-v1（[判断0022](../research/decisions/0022-convention.md)）で測りました。聞き合える条件では全員の食後の声が一つに集まり（散らばり0.26→0.05〜0.13）、集まる先はシードごとに違う（生得の声は常に同じ領域）。**収束と任意性の2項目は両群で成立**——この実験室で初めて、どの音でもよいのに集団で共有される音、つまり慣習の最小形が生まれました。ただし聞き手がその音を食料の手掛かりに使う3項目は開発群でしか達成せず（確認群の種類依存−0.045）、5項目の成立条件は満たしていません。慣習の声は食べていない時にも出る既存の音から選ばれるため、手掛かりとしての鋭さが生得の声より落ちるのが診断です。

## M3: 慣習的な合図の最小形が成立（候補のまま）

convention-v2（[判断0024](../research/decisions/0024-convention-v2.md)）で、真似＋対比の候補`convention-contrast-0.10.0-experimental.2`が5項目（収束・任意性・形成後の種類依存・到着の短縮・形成後の空腹の副作用）を開発・確認の両群で達成しました。**教えなくても、集団ごとに違う任意の音が「食料の声」として共有され、形成された後は聞き手がそれを手掛かりに使い、集団全体の空腹が下がる**——この実験室で「慣習的な合図の最小形」と事前に定めた条件が初めて満たされました。対照（真似のみ・生得の声）はそれぞれ予測どおりの項目で落ちます。観察していない16シード×2群でも5項目すべてを再現しました（[判断0035](../research/decisions/0035-convention-replication.md)）。主張の範囲: 候補であり既定ではない。音は1つ、指示対象は食料だけ。語彙・文法・意図の再現ではなく、人間の言語の成立の再現でもない。形成後の窓で測る根拠と反証条件は結果を見る前に登録した（[判断0023](../research/decisions/0023-contrast.md)）。

## 次の作業

1. 語彙の最小形は未成立（[判断0025](../research/decisions/0025-lexicon.md)・[0026](../research/decisions/0026-transient-warmth.md)）。世界0.4.0で暖かい場所が移り変わる条件を作り、2文脈の候補を測ったが、暖かさの声は収束も区別もせず、寒さの利益もない。診断: 暖かい場所は見つけやすく情報の非対称がないため、声の種類を割り当てる圧力が生じない。暖かさを希少にした世界（lexicon-v2、[判断0027](../research/decisions/0027-scarce-warmth.md)）でも暖かさ側は未成立で、第2の指示対象の系統は、場所記憶による出所評価（[判断0031](../research/decisions/0031-memory-credit.md)）でも暖かさ側が未達で、4ラウンド連続の反証として本セッションでは打ち切った。その後、2つの文脈の声を互いに遠ざける産出規則（[判断0033](../research/decisions/0033-explicit-separation.md)）と、暖まる機会と非対称の両方を持つ中間の世界（[判断0034](../research/decisions/0034-mid-scarcity.md)）でも暖かさ側は未成立（6ラウンド、閾値は一度も緩めていない）。到達点は「1回の実行の中では暖かさの声も集まり、食料の声から0.2ほど離れる」段階。聴覚分類を細かくした候補（[判断0036](../research/decisions/0036-fine-hearing.md)）でも変わらず、7ラウンドで閉じた。反省: 特異性や区別の幾何学的な閾値は候補の規則と噛み合っておらず、一方で寒い聞き手が暖かさの声を使えていない（機能0付近）ことは独立に成り立つ。文脈の作り方を変え、**毒のある食料**（契約0.3.0・世界0.5.0: 見た目は同じで食べると健康を失う）で「良い食料の声」と「悪い食料の声」が分かれるかを測った（valence-v1、[判断0037](../research/decisions/0037-valence.md)）。候補`valence-0.12.0-experimental.1`は、両群で良い声と悪い声を対照より明確に分けた（区別0.283 / 0.213、1つの声の対照0.057 / 0.039。**同じ食べる文脈の中で結果の良し悪しに応じた2つの声が分かれて共有されたのは初めて**）が、確認群の区別は閾値0.25に届かず、聞き手の毒の利益は後ろ3分の1で0付近のため未成立。前3分の2の毒の摂食は半分以下に減っており、後ろで減らないのは「避けた毒の場所が尽きずに残り、生きた食料の枠を占める」世界設計の副作用と診断。食料が500ステップで腐って消える世界0.6.0で、同じ候補・同じ閾値・新しいシードの第2ラウンド（valence-v2、[判断0038](../research/decisions/0038-valence-rot.md)）を測ると、**良い声と悪い声の区別は両群で閾値を越えた**（0.264 / 0.272、対照0.02 / 0.04）が、毒の利益は負のまま（音があると毒の摂食が増える）。停滞の診断は反証され、コードの読み直しで原因を特定: 既定の知覚は毎ステップ見えている食料で場所記憶を上書きするため、「毒の場所の記憶を消す」候補は目の前の毒の食料をそのまま食べる。見えていても採らない**味覚嫌悪**の候補（`valence-aversion-0.12.0-experimental.2`）を測ると（valence-v3、[判断0039](../research/decisions/0039-taste-aversion.md)）、毒の摂食は声と無関係に約75%減った（個体学習として機能）が、毒に当たる機会が消えたため「毒に当たっている間」にしか出ない悪い声は形成されず、良い声の収束まで崩れた（誤警報の疑い）。悪い声の機会を「毒の場所の食料を見て嫌悪する」状態に広げた**嫌悪の声**の候補（`valence-disgust-0.12.0-experimental.3`。自分の悪い声と同じ分類を聞くと出所を避け、自分の良い声の分類は警告と扱わない）と、聞かない対照を、毒の尺度を食料単位に変えて測った（valence-v4、[判断0040](../research/decisions/0040-disgust-call.md)）。嫌悪の声は機会を取り戻し、確認群では候補が7項目中6項目（区別0.276、毒の利益0.455単位）を通したが、毎ステップ叫ぶ声の洪水（実行あたり900回超）が採餌を押しのけ、開発群では餓死（8実行中5件）で良い声の収束まで崩れて2項目。食料の半分が毒の世界は毒を避ける集団に過酷すぎ、餓死が結果を反転させる。控えた嫌悪の声（自分が毒に当たった場所だけ、50ステップに1回）、毒3つに1つの世界、「毒に当たる回数（個体×毒の場所）」の尺度で測ると（valence-v5、[判断0041](../research/decisions/0041-restrained-disgust.md)）、餓死は消え、確認群で**毒に当たる回数の利益が初めて正**（音ありで0.63回少ない。閾値1.0、開発群は負）に出た。良い声が人を食料へ集める副作用（1つの声の対照は音ありで毒に当たる回数が2倍）が悪い声の便益と混ざるため、同じ声を出して聞かない対照との**対比較**（聞き手の寄与だけ）と、生得の警戒声を持つ**上限対照**（この世界で声が防げる毒の上限）を評価器に加えて測った（valence-v6、[判断0042](../research/decisions/0042-ceiling-and-paired.md)）。候補は**産出側の4項目（良い声・悪い声の収束、任意性、区別0.41 / 0.33）を初めて両群で達成**——同じ「食べる」文脈の良い結果と悪い結果に別々の声が集団ごとに共有される、2つの価値を持つ声の最小形。しかし聞き手の寄与（対比較）は+0.5 / −0.9回で無く、上限対照（完全な警戒声）でも利益は0.13 / 0.88回。診断で原因を分離: 上限対照は**飢え**（空腹0.95以上の非常時が全時刻の11%で、知りながら食べる）、候補は**理解の不成立**（警告後の毒当たり12件中9件で自分の悪い声の分類が無い）。食料の量を6にし、パイロット4回で同時に生きている食料を7か所まで増やして飢えを消した世界（valence-v7、[判断0043](../research/decisions/0043-mirror-by-production.md)）では、**完全な警戒声を持つ上限対照が両群で毒に当たる回数を1.75 / 2.0回減らし、世界に「声で防げる毒」の余地があることが確定**した。一方、「自分が出した声」を理解の鍵にする候補は産出まで崩れた——状態連動の後の音を自分の声として再利用する実装が縮小写像になり、全員の良い声と悪い声が一点に集まる欠陥。状態連動の前の形で覚え、悪い声を良い声から離す修正版でvalence-v8を事前登録した（[判断0044](../research/decisions/0044-mirror-corrected.md)）。成立した慣習的な合図の**新参者への伝達**（[判断0028](../research/decisions/0028-transmission.md)・[0029](../research/decisions/0029-transmission-v2.md)）: 1500ステップ目に何も知らない個体に入れ替えると、その個体の食料の声は聞ける条件で在来の声の中に6〜9割落ち（聞けない条件は1割前後、対照は0）、確認群では5項目すべて達成。開発群では新参者の空腹の2項目を外し（そのシード群では聞けない新参者がたまたま食料を見つけやすかった）未成立。16シード×2群の第2ラウンドでも確認群は5項目達成、開発群は新参者の種類依存（0.018）だけ未達。**採用（産出の伝達）は2ラウンド4群すべてで成立**（0.47〜0.70、対照0.05以下）、新参者の理解面は示唆に留まる。世代の連鎖（[判断0030](../research/decisions/0030-generations.md)）: 1200〜2400ステップで最初の4人を順に入れ替えると、全員が2世代目以降になった後も聞き合える集団には収束した任意の声が残る（収束0.15、両群）が、その音は入れ替え前の声から0.03〜0.27漂い、系統の連続の閾値（0.15以内）には16シード中6シードしか届かない。窓を広げたgenerations-v2（[判断0032](../research/decisions/0032-generations-v2.md)）でも連続は0.115 / 0.125で、16シード中5シードしか元の音に留まらない。**慣習は個体を越えて残るが、漂う**——言語の変化に相当する現象として記録し、連続の系統は閉じた。
1. 受け手側の合図利用は成立（[判断0020](../research/decisions/0020-referential-v5.md)）。発し手側と慣習: 発し手が声の結果を学ぶと呼び声は減るが黙らない（[判断0021](../research/decisions/0021-caller-cost.md)。抑制0.27 / 0.26、閾値0.3未達。食べている状態はどの発声にも漏れるので、正直な合図は発し手が抑えても消えにくい）。次は発し手側に利益を与える世界（寒さの共有、判断0022）。音の目録が二人以上で収束する条件（模倣）、複数の指示対象（食料と暖かさ）での声の分化。
1. 発し手側の費用（[判断0021](../research/decisions/0021-caller-cost.md)）: 食後の声は他者を自分の食料へ呼ぶので発し手には費用。声の結果を学ぶ発し手は黙るかを測り、合図が安定するのに必要な発し手側の利益を世界に足す設計へ。
2. 成立した場合の次: 発し手側の選択（食後の声を出すか否かを相手の距離や自分の学習で選ぶ）と、音の目録が慣習として収束する条件（模倣）。現状の対応は生得の音響領域によるもので、慣習の収束ではない。
2. 模倣（相手の声に近い音を出す傾向）の候補設計。音の目録が二人で収束する条件を作る。
3. 忘却則は代替候補として維持。用途上の要件または実測に基づく比較で既定化を判断する。自由行動中の反応変化・混在モデルは継続課題。

性欲・生殖、発音能力と音素の発達、他者認知の精緻化は別の未決課題です。暗黙に初期設定へ追加しません。
