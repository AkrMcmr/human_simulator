# 中期目標: 二人が経験から関わり方を変える実験室

設定日: 2026-09-10。対象は次の3か月程度（2026年12月上旬に到達状況を見直す目安）。稼働量は未確定なので納期の約束ではなく、以下の達成条件を優先する。自動実行や定期通知の設定ではない。

## 到達したい状態

**内部ロジックだけで動く二人が、身体を維持しながら相手との経験から行動を変え、音による最小限の合図が成立する条件・成立しない条件を、第三者が再現して検証できる。**

合図の成立は挑戦目標とする。成立しない場合も、対照実験で原因候補を絞り、次の仮説を選べることを研究基盤の必達条件とする。「面白い出来事が起きた」だけで達成とはしない。

現在は既定human 0.1.0、距離予測を効用へ反映する候補0.2.0-experimental.1が制御課題で支持された段階。以下は未来の目標で、実装済み機能ではない。

## M1: 通常の世界で学習の効果と副作用を測れる

最優先。今の候補を通常worldへ明示的に接続し、二人とも内生的に判断する実験を作る。

- 資源配置2条件×初期距離2条件×身体要求2条件、計8条件以上を事前登録する。具体的な値、実行長、seed数、主要指標、許容悪化幅は結果を見る前にprotocolで固定する。
- 同じ条件・シードで旧版、候補、追加寄与無効版を比較する。新しい開発用と未使用確認用のシードを分ける。
- 健康・身体要求の累積負担、資源利用、近接/回避、予測誤差、行動分布を記録する。近接が多いこと自体を良い結果とは定義しない。
- 既存core-v1を維持し、通常worldでの改善と副作用から採用/保留/棄却を判断する。候補を採用すること自体は必達条件ではない。
- モデル指定、版、保存・再開・再実行が整合し、異なるモデルで記録を誤って再生しない。

成果物: protocol、比較CLI、シード別結果、採否記録。最初の作業はprotocol作成。

進捗（2026-09-10）: [`world-v1`](../research/protocols/world-v1.json)、`npm run study:world`、[結果](../research/results/world-v1-validation.md)、[判断0004](../research/decisions/0004-normal-world-m1.md)、`ExperimentConfig.model`によるモデル選択と版記録を揃え、候補は開発・確認の両群で主要効果と副作用の条件を達成した。所有者の承認でhuman 0.2.0として既定化。片方だけ0.2.0の混在条件は未実施。

## M2: 相手との経験による違いを説明できる

同じ現在の身体・知覚に対し、異なる経験履歴が行動へどう影響するかを、記憶への介入を含めて検証する。

- 危害を受けた履歴/受けなかった履歴、相手の反応の途中変化を比較する。これは実験条件であり、本人へ敵味方ラベルを渡さない。
- 個体別の記憶を保持・消去・入れ替える対照で、差が履歴に由来するか調べる。安定した追跡IDを与える簡略化も明記する。
- 予測、確信度の代理量、効用の内訳、実際の結果を追跡し、警戒の固定化や更新の遅れを評価する。
- 少なくとも二つの事前登録した現象について、複数シードの結果と反例を示す。人間の「信頼」「愛着」を再現したとはまだ呼ばない。

成果物: 履歴介入実験と、観察画面で経験→予測→判断→結果をたどれる表示。M1の比較・記録基盤を利用する。

進捗（2026-09-10）: [`history-v1`](../research/protocols/history-v1.json)、`npm run study:history`、[結果](../research/results/history-v1-validation.md)、[判断0005](../research/decisions/0005-experience-history-m2.md)で、履歴（危害/無害）×記憶介入（保持/消去/入れ替え）と、危害後の更新（強制近接/自由行動の食料共有・分離）の二つの現象を事前登録し、開発・確認シードで確認した。反例（身体要求は予測効用の項だけを弱める、忘却は事前分布へ戻る）も記録。

進捗（2026-09-11）: 観察画面の「経験から判断へ」で経験→予測→判断→結果を追跡可能に。相手の反応の途中変化は[`reversal-v1`](../research/protocols/reversal-v1.json)（[判断0006](../research/decisions/0006-reaction-reversal.md)）で更新の遅れ・回復・忘却を確認。忘却則の候補（[判断0007](../research/decisions/0007-keep-estimate-forgetting.md)）が改善ゲートを達成し候補保持。M2の成果物は揃い、既定化レビューを残してM3へ進める。観察画面の時系列表示も追加済み（危害推定、行動別予測、効用、接触痛・摂食、次の知覚）。相手の反応の途中変化は未実施。

## M3: 最小限の合図の成立条件を検証する

最初の課題は「声を手掛かりに相手との距離を調整する」とする。現在の距離予測に接続しやすく、語彙や食料の指示を先に埋め込まずに調べられるため。これは開発上の課題選択で、人間の言語起源についての主張ではない。

- 音に固定の意味、呼びかけと返事の規則、伝達成功ラベルを与えない。新たに必要な注意・記憶・発声の仮定は個別に記録する。
- 音あり、伝達なし、音と状況の対応をシャッフル、関連学習なしを比較する。音量/頻度など意図しない手掛かりも対照の設計で扱う。
- 聞き手の反応が音への介入で変わること、発し手が予測する反応に応じて発声を変えること、その関係が未使用試行でも維持されることを別々に測る。
- 単なる音分類や発声頻度の増加は合図成立と数えない。判定指標と必要な差の大きさを実験前に固定する。
- 未成立なら、感覚の区別・音と結果の学習・行動選択への利用のどこまで確認できたかを残す。成功するまで課題や閾値を変えない。

成果物: 最小合図のprotocol、対照実験、成立/未成立と理由の報告。M1を前提にし、M2の履歴と観察機能を利用する。

進捗（2026-09-16）: 制御課題の受信側診断（[判断0008](../research/decisions/0008-signal-readiness-m3.md)）と受信側候補（[0010](../research/decisions/0010-sound-association.md)）に続き、自由worldの評価器[`signal-world-v1`](../research/protocols/signal-world-v1.json)と発し手候補（[0011](../research/decisions/0011-signal-world-m3.md)、[0012](../research/decisions/0012-signal-sender.md)）を事前登録して実行。全モデルで合図は未成立。確認できた段階は「音の分類」「新奇音への注意」「制御課題での音と結果の関連学習と利用」まで。自由worldでは両側が学べる構造がなく、発し手の状態と音の連動を初期能力として認めるかが設計相談になった。

進捗（2026-09-20）: 所有者が状態連動の声を初期能力として認め（[判断0013](../research/decisions/0013-voice-state.md)）、候補を第2ラウンドの未使用シードで測ったが未成立。原因は世界の側にあり、危険度も身体要求もほとんど変化せず、伝える価値のある状態差がない。次は情報の非対称がある課題（referential-v1）の設計。→ 同日に実施（[判断0014](../research/decisions/0014-referential-foraging.md)）。音源定位を加えた課題で、声は食料への到達を早めたが、資源競合の費用で空腹平均は改善せず。主要指標を到達時間に変えたreferential-v2（[判断0015](../research/decisions/0015-referential-v2.md)）で、声の方向が到達を早める現象を両群で確認。種類の利用は未成立。→ 食べている状態の連動（[判断0016](../research/decisions/0016-eating-coupling.md)）、出所を訪れて評価する聞き手（[判断0017](../research/decisions/0017-referent-learner.md)）、食料が移り変わる世界referential-v3（[判断0018](../research/decisions/0018-referential-v3.md)）を同日に実施。種類依存はいずれも未達だが、v3では聞き手が食後の声を「食料がある」と正に学ぶことを確認。二人の世界では種類が方向に付け加える情報がないと診断し、次は3人以上の世界。→ 4人の世界referential-v4/v5（[判断0019](../research/decisions/0019-referential-v4.md)・[0020](../research/decisions/0020-referential-v5.md)）で、種類の利用（費用の回避）が候補だけ両群でゲートを越えた。8シードの2ラウンドは片群で副作用を外し未成立、16シードの第3ラウンドで両群4項目を達成し**成立**（候補のまま、慣習の創発ではない）。M3の「最小限の合図の成立条件」のうち受け手側は到達。発し手が費用を学んでも呼び声は消えない（[判断0021](../research/decisions/0021-caller-cost.md)）。真似で任意の食後の声が集団ごとに共有される慣習の最小形は成立（[判断0022](../research/decisions/0022-convention.md)）。対比を足し形成後の窓で測ると、聞き手の利用と集団の利益まで5項目が両群で成立（[判断0024](../research/decisions/0024-convention-v2.md)）。**M3の「最小限の合図の成立条件」は候補について到達**。残るのは複数の指示対象（語彙）と既定化の判断。

## M4: 人間モデルとしての根拠と共同開発を一段進める

M1〜M3と並行して進める。

- 学習・反転学習・注意などから、人間の行動データと比較可能な現象を最低一つ選ぶ。一次資料を調査し、対象者、課題、測定値、利用条件、モデルとの違いを記録する。
- 適切な利用可能データがある場合は、校正用/評価用を分け、少なくとも一つの単純な代替モデルとの比較を実施する。取得できない場合は理由と必要データを明記し、実測検証済みとはしない。
- 本リポジトリの測定値を再現する手順を維持する。別の開発者またはLLMが新規checkoutから一つの実験を再現し、小さな仮説変更と比較結果を引き継げた記録を一件残す。文書を置いただけではこの実地確認を達成済みとしない。
- 各機構の根拠を「ユーザー指定」「工学的仮定」「文献由来」「実測比較済み」で区別する。

成果物: 根拠台帳、実測比較または具体的な不足データ記録、第三者の再現・変更記録。

## 範囲と進捗判断

この期間は二人の学習と相互作用に集中する。国家・民族・戦争・ロマンスの大規模シミュレーション、生殖・世代交代、現実の広告効果の推定、リポジトリ分割は後続段階とする。必要性が生じた場合は目的と優先順位を記録して見直す。

順序はM1→M2→M3。M4の文献調査と再現性確認は並行可能。各段階の終わりに、達成条件、反証された仮説、残る不確実性を[STATUS](STATUS.md)へ更新する。進捗はコード量や機能数ではなく、検証できる問いが増えたかで判断する。

12月時点の見直しでは、合図の成否に加え「どの学習機構を、どの証拠で次に改善するか」を選べることを重視する。日程に合わせて成功基準を緩めない。
