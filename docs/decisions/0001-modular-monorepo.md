# ADR 0001: モノレポと分離した実験実行

状態: 初版で採用 / 2026-09-08

最初は人間・世界・観察UIの境界が変わるため、同時変更を一つのコミットで検証できるモノレポとする。

| パッケージ | 責務 |
| --- | --- |
| contracts | 観測、行動、物理作用、診断用の公開データ |
| human | 生理、主観的なリスク推定、記憶、発声の試行、選択、学習 |
| world | 地形・資源・音の伝達・運動と外界の相互作用 |
| simulation | 時間、全員の行動の収集、再現可能な乱数、記録・復元 |
| experiments | 二人の初期条件、比較条件、観察指標 |
| observer | 保存された観察データの表示用変換 |

appは観察用Webアプリ、cliは画面なしの実験コマンド。両方が同じsimulationを使う。humanとworldは互いの実装をimportしない。contractsは他のパッケージをimportしない。

初版はTypeScript。モデルにはブラウザ・Node・Reactの依存を入れない。Nodeの型除去機能でCLIとテストを実行する。機構を数値実験しやすく、同じ関数をWebでも使えるための初期選択であり、人間の理論上の制約ではない。

## 状態の所有者

世界は位置、速度、外気、資源、発声の物理イベントを所有する。人間は身体の内部状態と記憶を所有する。runnerは世界が返す物理作用をhumanへ渡し、身体を更新する。UIがこれらを直接変更することはない。

全員が時点tの観測から行動を決めた後、世界がまとめて適用する。モデル内の会話順番は設定しない。更新順序の不変性をテストする。

## 分割の時期

他プロジェクトから利用される、入出力が安定する、公開範囲やリリース周期を分ける、といった必要が生じた段階で独立リポジトリへ切り出す。
