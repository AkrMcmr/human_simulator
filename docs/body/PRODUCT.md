# 製品化・公開・ライセンス・倫理

この文書は公開可能な製品にするための方針を定める。法律上の判断（ライセンスの適合、規約の有効性、各国の規制）は専門家への相談が必要で、ここに書くのは相談の前提となる設計上の選択である。

## 配布物

| 配布物 | 形態 | 内容 |
| --- | --- | --- |
| コアライブラリ | npm パッケージ（`@<scope>/body-*`。scope は未決） | contracts、anatomy、morph、kinematics、dynamics、motor、physio、damage、face、surface、runtime、io |
| 身体資産 | 別パッケージまたはリリースの添付 | 基準メッシュ、リグ、ブレンドシェイプ、LOD、最小テクスチャ。ライセンス表示を同梱 |
| エンジンアダプタ | three.js: npm / Unity: UPM パッケージ / Unreal: プラグイン / Godot: アドオン / Blender: アドオン | 読み込み・同期・描画。コアの挙動を含まない |
| CLI | npm パッケージ | 生成、書き出し、検証、記録の再現 |
| 文書 | 静的サイト | API リファレンス、忠実度表、既知の限界、チュートリアル |
| 検証スイートと参照結果 | リポジトリ | T0〜T4、protocol、集計結果 |

## 版管理

- セマンティックバージョニング。契約（操作名・単位・形式）の非互換変更で主版を上げる。
- 解剖データ、各計算層、資産、動力学後端にそれぞれ版を持ち、記録 `human-body/run` に全部を残す。
- 公開版ごとに `FIDELITY.md` の表を固定し、どの軸がどのラベル（U/E/R/M）かを変更履歴に残す。
- 長期サポート版を置くかは利用者が増えてから決める。

## 第三者資産とデータの利用可否

製品に含める、または導出に使うものの棚卸し。「含める」は再配布、「導出」は係数だけを計算して元データを含めないことを指す。ライセンスの最終確認は公開前に行い、ここでは設計上の採否を書く。

| 名称 | 種類 | 利用条件（設計時点の理解） | 採否 |
| --- | --- | --- | --- |
| ANSUR II（2012） | 人体計測データ | 米国政府の公開データとして利用可能 | 導出に使う。元データは含めない |
| CAESAR | 3D 人体計測データ | 商用ライセンスが必要 | 使わない |
| SMPL / SMPL-X 系の体型モデル | 統計的体型モデル | 非商用ライセンス。商用は別契約 | 使わない（学術比較の参照に留める） |
| MakeHuman 1.1 以降の資産 | 基準メッシュ・リグ | CC0（アプリケーション本体は AGPL だが資産は CC0） | 基準メッシュの第一候補。採用前に対象ファイルの CC0 表示を確認 |
| 整形外科の可動域表（AAOS 系、AMA Guides） | 数値表 | 出版物。数値そのものの引用可否を確認 | 出典付きで導出値を保存。本文は転載しない |
| de Leva 1996、Dumas 2007 | 体節慣性の論文 | 論文の数値の引用 | 出典付きで導出値を保存 |
| Rajagopal 2016 などの OpenSim モデル | 筋骨格モデル | モデルファイルのライセンスを個別に確認 | L3 の参考。経路データの再配布可否を確認してから |
| Fukuchi 2018 の歩行データ | 歩行計測データ | CC BY 4.0 | 検証に使う。集計値のみ保存 |
| CDC 成長チャート、WHO 成長標準 | 成長曲線 | 公的機関の公開データ | 導出に使う |
| ISO 7250-1、ISO 8996 | 規格 | 規格文書は有償。定義の参照は可 | 定義を参照。本文は転載しない |
| MuJoCo | 物理エンジン | Apache 2.0 | 動力学後端の候補 |
| Rapier | 物理エンジン（Rust/WASM） | Apache 2.0 | 動力学後端の候補 |
| glTF 2.0、VRM 1.0 | 形式仕様 | 公開仕様 | 採用 |
| ARKit 52 形状名 | 命名規約 | 名称の互換のみ | 名称を使う。Apple の資産は含めない |
| Unity Humanoid、Unreal Mannequin、Mixamo | ボーン命名 | 名称の互換のみ | 対応表を持つ。各社の資産は含めない |
| FBX SDK | 書き出しライブラリ | Autodesk のライセンス | 直接組み込まず、Blender 経由または glTF からの変換を既定にする |

新しい資産・データを加えるときはこの表に追記し、「使わない」としたものを無言で使わない。

## 倫理・安全方針

利用規約と技術的な設計の両方で担保する。規約だけに頼らない。

| 項目 | 方針 | 技術的な担保 |
| --- | --- | --- |
| 実在人物の再現 | 実在の個人を再現・識別する用途を禁止する | 顔・体型パラメータは統計分布のパラメータであり、写真やスキャンから個人を復元する機能を提供しない |
| スキャンの取り込み | 本人の同意のある計測値のみを `morph.fromMeasurements` に渡すことを求める | 計測値は ISO 7250 の数値のみを受け付け、画像・点群は受け付けない |
| 生体認証 | 生成物・計測値を認証や追跡に使うことを禁止する | 識別に使える精度の個人特徴を出力しない |
| 未成年の身体 | 成長モデルは教育・医療訓練・年齢相応の表現のためのもの。性的描写への利用を禁止する | 初版の配布資産は成人のみ。子どもの資産を含める場合は別の配布単位にし、用途制限を規約と資産メタデータ（VRM の利用条件など）に明記する |
| 損傷・暴力の表現 | 損傷モデルはゲーム・訓練・安全評価のための近似であり、現実の加害の計画や医療判断に使えるものではないと明記する | 医療精度の主張をしない。「既知の限界」に記載 |
| プライバシー | 利用者が作った身体仕様・記録は利用者のもの。製品はネットワーク送信をしない | コアに通信機能がない（NFR-01） |
| 多様性 | 体格・顔のパラメータは連続値で、人種・民族カテゴリを入力に持たない | NFR-08 |
| 誤用時の対応 | 規約違反の報告窓口と対応手順を公開する | 公開前に整備 |

## セキュリティ

- 外部ファイルの読み込みはスキーマ検証と上限（NFR-06）。実行可能コードを含む形式を扱わない。
- 依存ライブラリの脆弱性を定期的に確認する。
- 署名付きリリースと資産のハッシュを公開し、記録の manifest と照合できるようにする。

## サポートと保証

- 保証は免責（Apache 2.0 の条項）。医療・安全上の判断への利用は非目標として明記する。
- 問い合わせは公開リポジトリの issue で受ける。商用サポートは需要があれば別途。
- 既知の限界と忠実度表を各版で公開し、問い合わせの前に参照できるようにする。
