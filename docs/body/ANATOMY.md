# 解剖・生理モデル

この文書は `body-anatomy` に入れるデータと、各計算層が採用するモデルの方針を定める。数値は**設計時点の目安**で、根拠区分（U / E / R / M）を付ける。R（文献由来）であっても、本リポジトリで実測比較を終えるまで M にはならない。出典は書誌とURLで参照し、本文やデータを転載しない。

## 骨格

### 三段階の骨格表現

| 表現 | ボーン数の目安 | 用途 | 根拠 |
| --- | --- | --- | --- |
| Rig-Core | 約 22〜25（VRM 1.0 の必須ヒューマノイドボーン相当。指を除く） | ゲームの既定リグ。Unity Humanoid / VRM / Mixamo との互換の最小単位 | E（互換性の都合） |
| Rig-Full | 約 70（Core + 両手指 30 + 脊椎の分割 + 足趾 + 眼 + 顎） | 把持、表情、姿勢の細かな制御。既定の計算骨格 | E |
| Anatomical | 約 200（成人の 206 骨から癒合骨をまとめた視覚・教育用） | 医療訓練・可視化。計算には使わない | R（解剖学の標準的記述） |

計算は Rig-Full で行い、Rig-Core は Rig-Full からの射影として常に導出可能にする。Anatomical は Rig-Full に追従する表示専用の層とする。

### 脊椎の扱い

成人の仙骨より上の椎骨は頸椎 7、胸椎 12、腰椎 5 の 24 個（R）。Rig-Full では計算量と制御性のため、頸部 2 節（上位・下位）、胸部 2 節、腰部 2 節の 6 節へ集約し、各節に回転 3 自由度を与える（E）。全 24 椎骨への配分は Anatomical 層で補間する。

### 関節の種別と自由度

| 種別 | 自由度 | 例 | 備考 |
| --- | --- | --- | --- |
| 球関節 | 回転 3 | 肩（肩甲上腕）、股 | 肩は肩甲骨・鎖骨の連動を別途持つ |
| 蝶番 | 回転 1 | 肘（腕尺）、指節間、膝（近似） | 膝は実際には転がり滑りを伴う。L2 では 1 自由度＋従属並進で近似（E） |
| 車軸 | 回転 1 | 前腕の回内外（橈尺）、環軸関節 | |
| 楕円・顆状 | 回転 2 | 手首、中手指節 | |
| 鞍 | 回転 2 | 母指の手根中手 | |
| 平面 | 微小な滑り | 椎間、足根 | 集約節で近似 |

Rig-Full の総自由度は約 100（指 20〜25 × 2、脊椎 18、四肢・頭・眼・顎で残り）となる見込み（E）。研究用全身筋骨格モデルが 37 自由度程度で歩行を再現している（R: Rajagopal ら 2016）ことから、歩行・姿勢の検証は下肢・体幹の約 40 自由度で十分と見込み、指と表情は別に検証する。

### 可動域

各自由度に `{ min, max }`（ラジアン）と、年齢・性別・損傷による調整係数を持つ。初期値は整形外科で使われる正常可動域の表（R: AAOS 系の可動域表、AMA Guides などの一般に参照される値）から取り、出典を列に残す。以下は代表例で、実装時に表全体を `body-anatomy/rom.json` にまとめる。

| 関節・運動 | 目安（度） | 根拠 |
| --- | --- | --- |
| 股関節 屈曲 / 伸展 | 0〜120 / 0〜30 | R |
| 膝 屈曲 | 0〜135 | R |
| 足関節 背屈 / 底屈 | 0〜20 / 0〜50 | R |
| 肩 屈曲 / 外転 | 0〜180 / 0〜180 | R |
| 肘 屈曲 | 0〜150 | R |
| 前腕 回内 / 回外 | 0〜80 / 0〜80 | R |
| 手関節 掌屈 / 背屈 | 0〜80 / 0〜70 | R |
| 頸部 屈曲 / 伸展 / 回旋 | 0〜50 / 0〜60 / 0〜80 | R |

可動域違反の扱い（拒否か丸めか）はコマンドごとに指定できる（[OPERATIONS](OPERATIONS.md#可動域違反の扱い)）。受動関節特性（可動域端での弾性・減衰）は L2 で導入し、係数は E とする。

## 体節の質量・慣性

体節ごとの質量比、重心位置比、回転半径比を文献の体節慣性パラメータから与える。

- 第一候補: de Leva (1996) による Zatsiorsky–Seluyanov パラメータの調整値（R）。若年成人の男女別。
- 第二候補: Dumas, Chèze, Verriest (2007) の調整値（R）。慣性テンソルの非対角成分を含む。
- 子ども・高齢者への拡張は成長・加齢モデルで補正し、E と明示する。

受け入れ条件は FR-DYN-01（全身質量の一致、立位重心高が身長の約 55〜57%）。

## 人体計測と体格生成

### 入力パラメータ（BodySpec）

| 項目 | 型・範囲 | 備考 |
| --- | --- | --- |
| `sex` | `"female" \| "male" \| "custom"` | 計測回帰の選択に使う。`custom` は回帰の混合比を指定 |
| `ageYears` | 0〜100 | 成長・加齢モデルの入力。初版の資産は成人のみ（未決事項） |
| `statureM` | 1.2〜2.2 | 身長 |
| `massKg` | 25〜200 | 体重 |
| `proportions` | 座高比、脚長比、腕長比、肩幅比、骨盤幅比（各 −3〜+3 z値） | 省略時は回帰の中央値 |
| `composition` | 体脂肪率、筋量指数（z値） | 体表変形へ |
| `face` | 顔パラメータ群（z値） | FR-MORPH-04 |
| `seed` | 整数 | 未指定の項目を分布から決めるときの乱数シード |

人種・民族のカテゴリは入力に持たない（NFR-08）。地域集団の計測分布を使う場合は「どの計測データセットの分布を参照するか」をデータソースIDで指定し、カテゴリラベルを体型の原因として符号化しない。

### 計測の定義と回帰

- 計測項目の定義は ISO 7250-1 に合わせる（R）。
- 参照分布は ANSUR II（2012、米陸軍の公開人体計測データ、約 6,000 名・93 項目。公開データとして利用可能。R）を第一候補とし、身長・体重・性別から各体節長・周径を予測する回帰を `body-anatomy` に持つ。回帰係数は計算して保存し、元データは同梱しない。
- 軍人集団の偏り（年齢・体力）を既知の限界として記録し、一般集団への外挿を主張しない。他の公開計測データが利用できる場合はデータソースとして追加し、記録に残す。

### 体表メッシュ

- 基準メッシュは再配布可能なものを使う（候補: MakeHuman 1.1 以降の CC0 資産。SMPL 系は商用再配布に制約があるため採用しない。[PRODUCT](PRODUCT.md#第三者資産とデータの利用可否)）。
- 骨格寸法への追従は、ボーン長のスケーリングと、周径・体組成のブレンドシェイプで行う。関節部の破綻を補正ブレンドシェイプ（姿勢依存）で抑える。
- L4 の軟部組織変形は位置ベース動力学を候補とし、初版では扱わない。

## 筋モデル（運動 L3）

- Hill 型三要素モデル（収縮要素、直列弾性要素、並列弾性要素）を関節トルク生成の基礎にする（R）。
- 筋腱単位の配置は、公開されている全身筋骨格モデルの構成（R: Rajagopal ら 2016 は下肢 80 筋腱単位、上体はトルク駆動）を参考にし、ライセンスを確認したうえで経路データの再配布可否を決める。
- 筋力の年齢・性差は文献のスケーリング係数で与え、E として版を付ける。
- L2 までは関節トルク上限と受動特性で近似し、筋モデルは研究用途の任意層とする。

## 筋疲労

三区画モデル（活動・疲労・休止の区画間遷移。R: Xia & Frey-Law 2008）を既定とし、関節ごとの最大トルク倍率として motor と dynamics へ返す。全身疲労（physio の疲労区画）と局所筋疲労を分け、どちらを使うかを忠実度で選ぶ。

## 生理（physio）

| 下位系 | 状態変数 | モデルの候補 | 根拠 | 時間尺度 |
| --- | --- | --- | --- | --- |
| 代謝 | 代謝率（W）、累積エネルギー（J） | 安静時代謝 + 活動代謝。活動代謝は機械的仕事率 / 効率、または運動種別の MET 値 | R: ISO 8996 | 秒〜時間 |
| 体温調節 | 深部温、皮膚温、発汗率、ふるえ | 二節点モデル（Gagge ら 1971）相当 | R | 分〜時間 |
| 心拍・呼吸 | 心拍数、換気量 | 運動強度への一次遅れ追従 | R（追従の形）、E（係数） | 秒〜分 |
| 水分 | 体水分欠乏（kg） | 発汗 + 呼気 − 摂取 | R（収支）、E（性能低下閾値） | 時間 |
| 疲労 | 全身疲労区画 | 三区画モデルの全身版 | R（形）、E（係数） | 分〜時間 |
| 睡眠・概日 | 睡眠圧、位相 | 二過程モデル | R（形）、E（係数） | 日 |

出力は生理変数（SI 単位）と、運動性能への係数（最大トルク倍率、反応遅れ、可動域倍率）に分ける。認知モデルへ渡す「感覚」（疲労感、温冷感、渇き）は変数からの単調写像で、本人のものだけを渡す。

## 損傷・回復（damage）

初版は**工学的仮定**で、実測比較は行わない。文献から組織耐性の目安を調べて根拠を更新する。

| 要素 | 内容 |
| --- | --- |
| 入力 | 接触力・圧力・持続時間、関節トルク・可動域超過、累積荷重 |
| 判定 | 部位ごとの閾値表（E）。打撲、捻挫・靭帯損傷、骨折、裂傷、脱臼を種類とする |
| 機能低下 | 種類・重症度 → 可動域倍率、最大トルク倍率、痛み強度、荷重回避の重み |
| 痛み | 部位・強度・時間減衰。イベントと問い合わせの両方で出力 |
| 回復 | 種類別の回復曲線（E）。治療介入は外部コマンドで表現 |
| 外部設定 | 任意の損傷状態を直接設定・解除できる（FR-DMG-05）。実験条件として記録 |

## 成長・加齢

- 2〜20 歳の身長・体重中央値とパーセンタイルは CDC 成長チャート、0〜5 歳は WHO 成長標準（R）を参照する。
- 体節比率の年齢変化（頭身比など）は文献値で補間し、E として版を付ける。
- 可動域・筋力の加齢変化は文献のスケーリングで与える（E）。
- 子どもの身体の配布資産に含めるかは未決事項（[CONCEPT](CONCEPT.md#未決事項)）。含める場合は利用規約で用途を制限する。

## 顔

- 正準は FACS のアクションユニット（AU）。ARKit 52 ブレンドシェイプとの相互変換表を持つ（E）。
- 眼球は左右各 2 自由度（水平・垂直）+ 瞳孔径。頭と眼の協調（前庭動眼反射・サッケード）は E の制御則。
- 瞬き間隔はシード付き乱数で生成し、分布は文献値を目安にする（R→E）。

## データの保存形式

`body-anatomy` の各表は JSON で保存し、各行に `source`（書誌・URL）、`basis`（U/E/R/M）、`notes` を持つ。表の版は `anatomy.version` で管理し、値を変えたら版を上げる。元データセットの本体は同梱せず、導出した係数と導出手順（スクリプト）を保存する。
