# 検証と忠実度の主張

「現実の肉体に近い」をどう測り、どこまで言ってよいかを定める。親リポジトリの研究ループ（仮説と閾値を先に固定する、開発用と確認用のデータを分ける、結果を見てから基準を緩めない）を引き継ぐ。

## 主張ラベル

仕様・係数・資産・公開文書のすべての「現実準拠」の記述に、次のどれかを付ける。

| ラベル | 意味 | 公開文書での表現 |
| --- | --- | --- |
| U: ユーザー要件 | 依頼者が定めた条件。現実性の主張ではない | 「本製品の方針として」 |
| E: 工学的仮定 | 実装者が置いた値・式。文献も実測比較もない | 「近似」「仮の値」 |
| R: 文献由来 | 公開文献・規格の値や式を採用。本リポジトリでの比較は未実施 | 「文献 X の値に基づく」 |
| M: 実測比較済み | 本リポジトリの検証スイートで参照データと比較し、事前に決めた基準を満たした | 「参照データ Y に対し誤差 Z 以内」 |

軸（形態・運動・生理・応答）とレベルごとに現在のラベルを `docs/body/FIDELITY.md`（実装開始後に作成）へ表として記録し、製品説明はその表から生成する。表にない主張を宣伝文に書かない。

## テスト階層

| 階層 | 内容 | 実行頻度 | 合格条件 |
| --- | --- | --- | --- |
| T0 再現性 | 同じ `spec`・コマンド列・シード・版で、チェックポイントのハッシュが一致する。異なる刻み分割（1 刻み × N と N 刻み × 1）で結果が一致する。コマンドの投入順を入れ替えても結果が一致する | 毎コミット | 完全一致 |
| T1 契約・形式 | スキーマ検証、単位の欠落なし、版の不一致で拒否、上限超過で拒否、glTF / VRM の検証ツールを通過 | 毎コミット | 違反なし |
| T2 解剖学的制約 | 可動域内の姿勢だけが受理される。ボーン長比が参照分布の範囲。メッシュの自己交差なし。スキンウェイトの正規化 | 毎コミット | 違反なし |
| T3 力学的妥当性 | 外力なしでエネルギーが増えない。全身質量・重心高・慣性が表と一致。接地の貫通なし。静止立位の保持。力積と運動量変化の一致 | 毎コミット（短い）、夜間（長い） | 事前に決めた許容誤差 |
| T4 実測比較 | 参照データセットとの比較（下表）。校正に使ったデータと評価に使うデータを分ける | 版を上げるとき | 事前登録した指標と閾値 |
| T5 知覚評価（任意） | 人が見て自然かの評定。忠実度の証拠にはせず、製品品質の参考値として別に記録する | 公開前 | 合否を付けない |

T0〜T3 は `npm run test:body` 相当のコマンドでまとめ、T4 は protocol を `research/body/protocols/` に置いてから実行する。

## 参照データと比較指標（T4）

| 軸 | 参照 | 指標 | 開発 / 確認の分け方 |
| --- | --- | --- | --- |
| 形態 | ANSUR II（公開人体計測）、ISO 7250 の定義 | 生成した体節長・周径の、同じ身長・体重・性別での参照パーセンタイル帯との一致率 | 計測項目を半分に分け、回帰の推定に使った項目と評価に使う項目を分ける。または被験者 ID で分割 |
| 形態（成長） | CDC 成長チャート、WHO 成長標準 | 年齢別の身長・体重中央値との差 | 年齢を交互に分ける |
| 運動（可動域） | 整形外科の正常可動域表 | 表の全項目で上下限が範囲内 | 表そのものが基準なので分割なし。複数の表の不一致を記録 |
| 運動（慣性） | de Leva 1996、Dumas 2007 | 体節質量比・重心比・回転半径比の差 | 二つの表を校正・評価に分ける |
| 運動（歩行） | 公開歩行データセット（例: Fukuchi ら 2018 の健常者の歩行運動学・動力学、CC-BY） | 速度別の歩幅・歩行率、矢状面の股・膝・足関節角度の時系列との平均二乗誤差、床反力の形 | 被験者を開発 / 確認に分ける |
| 生理（代謝） | ISO 8996、活動別代謝の文献 | 歩行・走行・安静の代謝率の範囲内率 | 速度条件を分ける |
| 生理（体温） | 二節点モデルの原著と後続の検証データ | 定常環境での深部温・皮膚温の収束値 | 環境条件を分ける |
| 応答 | 当面なし（E のまま） | – | 文献の組織耐性値を調べ、使える指標が見つかったら登録する |

参照データの本体は同梱せず、取得手順・ライセンス・前処理スクリプトを `research/body/` に置く。ライセンスが再配布を許す集計値だけを `research/body/results/` に保存する。

## 事前登録の手順

T4 を実行する前に、`research/body/protocols/<name>.json` に次を固定し、コミットする。

- 対象の軸・レベル・層の版
- 参照データの出典・取得日・前処理
- 開発 / 確認の分割方法
- 指標の定義と閾値、許容される悪化幅（旧版との比較がある場合）
- 比較する対照（例: 慣性を一様にした版、可動域制約なしの版）

結果は `research/body/results/` に JSON と Markdown で保存し、判断記録を `research/body/decisions/` に残す。閾値未達は未達として記録し、閾値を変える場合は新しい protocol として登録する。

## 対照条件

忠実度の寄与を示すときは、親リポジトリの「寄与無効の対照」と同じく、上位レベルを無効化した版と同じシードで比較する。

- 可動域制約なし vs あり（姿勢の妥当性）
- 一様な体節質量 vs 文献の体節慣性（転倒・バランスの違い）
- 生理なし vs あり（長時間の運動性能）
- 損傷なし vs あり（歩容の非対称）

対照との差が出ることは、現実に近いことの証明ではない。実測比較（T4）と区別して書く。

## 禁止事項

- 見た目の良さ、アニメーションの滑らかさ、LLM や人の「もっともらしい」という評価を、忠実度（M）の証拠にしない。
- 確認用データを一度見たら、以後は回帰チェックとして扱い、新しい確認データと混同しない。
- 結果を見てから閾値・指標・分割を変えない。変えるなら新しい protocol として登録する。
- 医療・安全上の判断に使えると示唆しない。
