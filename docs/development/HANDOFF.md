# 作業引き継ぎテンプレート

この内容をPR本文や作業記録へコピーします。秘密情報は含めません。

- 目的・ユーザーが許可した範囲:
- GitHubブランチ/基点コミット:
- ローカルだけの変更とコミット:
- 読んだ設計・研究判断:
- 既定モデル/候補モデル/評価器の版:
- 変更ファイルと理由:
- protocol・シード（未使用か観察済みか）:
- 実行したコマンドと終了結果:
- 基準版との差・許容幅を超えた悪化:
- 結果ファイル・ハッシュ:
- 採用/候補/保留と理由:
- 未解決事項・失敗した試み:
- 次の一手:
- GitHubへの反映状態・公開画面への反映状態:

「テスト済み」だけで済ませず、どのコマンドで何を確認したか、未実施のものは何かを短く残します。他の作業者が終わった検証を無意味に繰り返さず、必要な続きから始められる情報を優先します。
